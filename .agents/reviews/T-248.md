## What it adds

Settings → Appearance gets a **Typography** tab (between Theme & layout and Colours):

- **Fonts:** note and interface font pickers (moved from Theme & layout) list the vault's
  own fonts first (“In this vault”), then installed ones. **Import font…** copies a TTF,
  OTF, WOFF or WOFF2 (≤ 25 MB) into `Attachments/Fonts` through a new native
  `import_font` command, so the vault carries it to other computers. Each file becomes an
  `@font-face` family named after the file (`src/lib/fonts.ts`, `src/app/vaultFonts.ts`),
  kept in step with the file tree.
- **Text size** (moved), **letter spacing** (−0.05 to +0.2 em) and **line height** (1.1 to
  2.6) for note text, as `--note-letter-spacing` / `--note-line-height`, with Reset buttons
  and a live sample.
- **Bionic Reading:** a CodeMirror decoration (`src/features/editor/bionic.ts`) bolds the
  start of each word on rendered lines. Lines with the cursor or a selection stay plain,
  code/URLs/HTML/comments/math/frontmatter are skipped, and the Markdown file never changes.
- `Field`, `FontSelect` and `SectionProps` moved to `src/features/settings/parts.tsx` so the
  new tabs can live in their own files.
