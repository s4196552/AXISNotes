# Review: T-109 — Command palette and quick switcher: recents, icons, highlighted matches, note commands, Note#heading

**Verdict:** approve (self-review by Claude, the lead, per the 2026-10-17 agreement)

Findings N1 and N2 of the 2026-10-20 UX review, built to mockup M3, as part of batch 2 (N1, N2, N4, N5, N7) the human picked. Reviewed `git diff main...agent/claude/T-109` in full.

## What changed

- **Picker** (shared by the palette, switcher, template, move and theme pickers): optional Lucide icon per item, section headings ("Recent", "All commands", "All files") shown while the query is empty, matched letters highlighted (`fuzzyIndices`, the same rule as `fuzzyScore`), a key-hint footer, and hooks for the switcher's `#heading` mode (`onQueryChange`, `matchQuery`, `canCreate`).
- **Command palette:** every command has an icon (`commandIcons.ts`); the last 5 commands run are listed first under "Recent". Commands can declare `available()`; unavailable ones are hidden and their shortcuts do nothing.
- **New commands** (`noteCommands.ts`, for the file in the active tab, hidden when none is open): Rename note (focuses the title field; grids and canvases ask for a name), Move note to… (a folder picker, vault root included), Duplicate note ("Name copy"), Delete note (asks, then the OS trash, as the tree does), Copy link to note (`[[Name]]`), Pin to Home (adds to Home's first Pinned widget, or adds one), Reveal in File Explorer. Also Choose theme… (a picker of the built-in themes, current one marked).
- **Reveal in File Explorer:** new backend call `revealEntry(path)` (`reveal_entry` in `commands.rs`): resolves inside the vault (no escapes), then `explorer /select,"<path>"` on Windows, `open -R` on macOS, the folder via `xdg-open` on Linux, launched with an argument list (no shell). `""` opens the vault folder. The in-memory backend says it needs the desktop app.
- **Quick switcher:** lists grids and canvases as well as notes, with a type icon each; recently opened files (the last 12, not the open one) come first under "Recent", the rest by name. `Note#heading` lists that note's headings (outside code blocks) and opens at the chosen one; `#` alone uses the open note.
- Recents are kept per vault in this device's localStorage (a convenience, never vault data).
- **T-107 follow-up:** renaming a `.txt` note from its title no longer adds `.md`.

## Findings (most severe first)

1. **Minor, accepted:** section headings only show with an empty query. While typing, results are ranked by match quality, so the mockup's "This note / App" groups weren't kept.
2. **Minor, accepted:** subsequence matches highlight scattered letters (typing "mo" marks the M of "Make a diagram"). It shows exactly why an item matched.
3. **Minor:** Reveal in File Explorer can't be exercised in the browser preview (no file manager); it was built and `cargo check`ed on Windows, not clicked in the desktop app.
4. **Minor, accepted:** the palette is labelled "Reveal in File Explorer" on every platform.
