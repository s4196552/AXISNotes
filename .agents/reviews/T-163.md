# T-163 review: AI block in Basic blocks, with model and effort picker

**Verdict: approve** (Claude self-review, 2026-11-05)

## What changed

- `src/features/editor/quickCommands.ts`: new **AI** command, second in Basic blocks ("Ask AI, then insert its answer here"). It removes the typed trigger and opens an AI block on that line.
- `src/features/ai/aiBlock.ts`: a CodeMirror extension (`aiBlocks(path)`).
  - A state field holds the open blocks and maps their positions through edits.
  - A block-widget decoration renders the React block. It sits in place of a blank line, or under a line with text.
  - The widget ignores editor events, so its inputs work normally.
  - When the editor closes, running requests are cancelled and block state is dropped.
- Nothing is written to the file until the user clicks Insert.
- `src/features/ai/AiBlockView.tsx`: the block UI.
  - Prompt (Enter runs; Shift+Enter adds a new line) and a "Reads: <note>" chip. It also has a "Reads: selection" chip when the block was opened over a selection.
  - Shows the destination estimate (tokens and cost) and asks for confirmation above the threshold.
  - Streams the answer, with Stop.
  - Done actions: Insert, Replace selection, Copy, Retry, Discard, and "Keep prompt" (a collapsed `> [!ai]-` callout above the answer). Escape discards.
  - The note is sent by path through `attach`, so the Rust layer reads it and applies the folder rule, as Ask AI already does.
- `src/features/ai/ModelPicker.tsx`: a "model · effort" chip.
  - The menu has Quick/Balanced/Deep, "Default · <provider · model>", and each usable provider's models (from `aiListModels`, cached for the session).
  - When the plan's rule is `local`, cloud providers' models are disabled with "This note allows local models only". Rust still enforces the rule.
- `src/features/ai/aiBlockStore.ts`: a zustand store for block state, so a block keeps its prompt and streaming answer if CodeMirror recreates its DOM. It also remembers the last model/effort per vault, in `localStorage` (this device only).
- `src/features/commands/{registry,commandIcons}.ts`: app command "AI block at the cursor". It opens a block with the current selection as context, from the command palette or a user-assigned shortcut.
- `src/features/ai/ai.css`: block, chip and menu styles from theme tokens.
