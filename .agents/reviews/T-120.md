# Review: T-120 (Ctrl + mouse wheel zooms only the part under the pointer)

**Verdict:** approve

Human request (2026-10-21): "Ctrl + Scroll wheel should only resize whatever the mouse is hovering on."

## Change

- `src/app/zoom.ts`: four parts of the window zoom on their own: left panel, tab bar, main view, right panel
  (`data-zoom-area`). Ctrl + wheel steps the part under the pointer through the same zoom steps, applied as CSS
  `zoom` plus `--area-zoom`, saved per device (`axisnotes.areaZoom`), with a status-bar notice ("Main view 125%
  (Ctrl + 0 resets)"). Outside those parts (dialogs, status bar) the wheel does nothing but still blocks the browser's
  page zoom. With no vault open, the welcome screen is the whole window, so the wheel zooms the app as before.
  Ctrl + = / − stay whole-app; Ctrl + 0 (Reset zoom) resets the app and every part.
- `src/App.tsx`, `src/features/tabs/TabBar.tsx`: mark the four parts.
- `src/styles/app.css`: a zoomed side panel keeps its on-screen width (`width / --area-zoom`); the canvas and the
  graphs undo the zoom (`zoom: 1 / --area-zoom`), since they have their own zoom and pointer maths.
- `src/features/settings/Settings.tsx`: the Zoom hint explains the wheel.
- Tests in `src/features/settings/appearance.test.tsx`: wheel over one part zooms only it, saves it, notifies; outside
  parts nothing changes; Ctrl + 0 resets; welcome-screen wheel still zooms the app.

## Findings

None blocking.

- The status bar is not a zoom part (its 24 px row would clip larger text); the wheel does nothing there.
- Already-open dialogs/menus aren't zoomed by a part's zoom unless rendered inside it; acceptable.

## Checks

- `pnpm lint`, `pnpm typecheck`: pass. `pnpm test`: 80 files, 667 tests pass (a first full run had timing failures in
  `media.test.tsx` and `pageHeader.test.tsx`; both pass alone and in the clean full rerun).
- Real Chromium (headless Edge, same engine as WebView2) on the preview build:
  - Ctrl + wheel over the main view: main 125%, other parts 100%, widths unchanged; left panel 110% keeps 260 px.
  - Clicking mid-word in the zoomed CodeMirror editor puts the cursor at exactly that character.
  - Right panel at 150%: the local graph keeps its 278×200 box and 1:1 canvas.
  - Canvas in a 150% main view: Excalidraw stays at its own 100% with note cards and overlays in the same places.
  - Ctrl + 0 returns everything to 100%.
- The built-in browser pane couldn't open the preview: port 1720 is on Chromium's unsafe-port list
  (ERR_UNSAFE_PORT); the preview moved to 1820.
- No Rust changes.
