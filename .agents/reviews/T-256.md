## What it adds

- An **AI access button** right after a note's title (`src/features/ai/NoteAiAccess.tsx`).
- **Icon:** shows whether AI may read the note:
  - a faint sparkle for any AI;
  - an accent chip for local models only;
  - a red crossed-out bot for never.
- **Tooltip:** says when the rule comes from the folder or from the note's `ai-access`
  property.
- **Menu:** sets the note's own rule: "Same as its folder (…)", Any AI, Local models only or
  Never.
  - It is the same per-path `ai.folders` rule as the file tree's AI access menu and
    Settings → AI → Folder privacy, so the Rust layer enforces it on every request.
  - Changes are recorded for undo (`changeSetting`).
  - A stricter `ai-access` property in the note still applies, and the menu says so.
- **Setting:** Settings → AI → Folder privacy → "Show the AI access button beside note
  titles" (`ai.titleButton`, on by default).
- **Layout:** the title field now sizes to its text (`field-sizing: content`), so the button
  sits next to the name.
