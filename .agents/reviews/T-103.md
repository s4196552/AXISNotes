# T-103 review: Import notes from Notion, Obsidian, Evernote and Markdown

**Verdict:** approve

## What changed

- `src-tauri/src/import/` (Rust; the Obsidian-only `mod.rs` rewritten, five new modules):
  - `source.rs`: reads a folder, a `.zip` (including Notion's zip of `Part-N.zip` zips) or a single file. Entries are read on demand, never unpacked under their own names. Entries go through `enclosed_name`. Hidden files, `__MACOSX` and `node_modules` are skipped. Limits: 200k entries and 512 MB per file.
  - `plan.rs`: where each file goes. Notion IDs are stripped, names sanitized for Windows, and names made unique per folder ignoring case. A page, its subpage folder and its table share one name. The Markdown link rewriter turns links to notes into full-vault-path wikilinks (no alias inside table rows) and gives attachments correct relative paths. It also rewrites `notion.so` URLs whose ID is in the export, skips code blocks and code spans, and counts links to files missing from the export.
  - `tables.rs`: RFC 4180 CSV parsing, `.axgrid` output (bold header row, and a leading `=` kept as text) and Markdown tables (first column linked to row pages). Notion row properties become YAML frontmatter, but only for names that are database columns.
  - `html.rs`: a forgiving HTML/XML tokenizer and tree builder, and an HTML→Markdown converter covering Evernote `div` lines, emphasis (including `style` spans), to-dos, lists, quotes, code, tables, links and images.
  - `enex.rs`: notes and resources from `.enex`, an MD5 for `<en-media hash>`, and ENEX date conversion.
  - `mod.rs`: `inspect` (counts, warnings, and "looks like" another kind) and `run` (a new unique folder, progress callback, report). Notion pages drop a first `# Title` that only repeats the page name.
- `src-tauri/src/{commands,lib}.rs`: `inspect_import(kind, source)` and `import_notes(kind, source, target, options)`, which emits `import://progress` at most every 100 ms and rescans the index once. `import_obsidian` is removed.
- `src/ipc/*`: `ImportKind`, `ImportPreview`, `ImportReport`, `ImportProgress`, `importNotes` (listens for progress while the call runs) and `pickImportFile`. The memory backend writes sample notes into a unique folder for the browser preview.
- `src/features/import/`: an "Import notes" dialog with one row per app, each with its one-sentence export instructions and pickers (`sources.ts`). Then a preview (counts, warnings, "Import it as X instead", target folder, and for Notion, databases as grids or Markdown tables), a progress bar, and a summary (counts, links updated, warnings, skipped files, Obsidian settings offer).
- Entry points renamed: palette "Import notes (Notion, Obsidian, Evernote, Markdown)…" (same command id), About "Import notes…", the Getting started item, and the starter guide note.
- `e2e/specs/phase6.e2e.ts`: the Obsidian test uses the new commands, plus a new Notion test (unzipped export → IDs dropped, link rewritten and resolved in the editor, grid written).
- `docs/DECISIONS.md`: the decisions, the deferred sources, and why no dependency was added.

## Findings

None blocking. Fixed before commit:

1. `plan.rs`: `a.md` and `a.txt` in one folder both mapped to `a.md`. A same-name sibling is now named on its own (`a 2.md`). Covered by the Markdown zip test.
2. Notion pages link to a database's view CSV, which is skipped for the `_all` table. Links to the view now go to the table.
3. Notion's opening `# Title` duplicated the title AXISNotes shows. It's dropped only when it equals the page name.
4. Clippy (`-D warnings`, as CI runs it): an unused helper was removed, and `rewrite` took too many arguments (now a `Link` struct).
5. Lint: dialog constants moved to `sources.ts` (react-refresh rule). The `<select>` was unstyled (themed now), and the picker buttons had ragged widths (fixed column).

Accepted, low:

- Importing no longer offers the vault root, and an existing folder name gets `… 2`. This supersedes T-032's skip-if-exists behaviour, which the task asked for ("never overwrite; resolve clashes uniquely").
- Inside Markdown tables, wikilinks have no alias (a `|` would split the cell), so they show the full path.
- Wikilinks that existed in Markdown sources (Logseq, Roam, Bear) resolve by name as before. If sanitizing changed a page's name (e.g. `a:b` → `a-b`), a wikilink to it won't resolve.
- The import runs on an async command thread, like the Phase 6 import did. Large imports emit many watcher events, which the index rescan makes redundant.
