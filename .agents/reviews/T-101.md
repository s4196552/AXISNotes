# Review: T-101 — Dashboard quick add and smarter planning

**Verdict:** approve (self-review by Claude, the lead, per the 2026-10-17 agreement)

Reviewed `git diff main...agent/claude/T-101` in full (8 files, ~750 lines added, about half of them tests).

## What changed

- **Quick add.** The Today's tasks widget has an "Add a task" box, and the Day schedule has a time field plus a text box. Both write into the daily note, creating it from the daily template through the new `ensureDailyNote` (`src/features/commands/actions.ts`); `openDailyNote` now calls it. Writes go through `editNote`, so an open editor takes the change (and its undo history), and a closed note is written with the on-disk change check. The new pure helper `appendToNote` (`dashboardModel.ts`) decides where a line goes:
  - a task fills the template's empty `- [ ] ` first, else goes after the last task;
  - a timed line goes after the last timed line;
  - otherwise after the last list under the last heading, else at the end;
  - frontmatter and code blocks are skipped, and CRLF is kept.
- **7-day tasks.** A Today / 7 days switch, saved per widget as `options.range` (normalized; unknown options are dropped). The week view groups tasks under Overdue / Today / Next 7 days and shows upcoming dates.
- **Schedule.** Previous / Today / Next buttons show any day's daily note and the tasks due that day. When viewing today, a red "now" line sits between items and earlier items fade. The clock ticks every 30 s only while today's schedule is shown.
- **Calendar.** A small count on days with open tasks due, scoped to the dashboard's folder, also in the day's accessible name. The sidebar calendar is unchanged (`marks` is optional).
- **Midnight.** `useDay` moves "today" on at midnight and on `visibilitychange` (waking from sleep). Its timer and listener are cleared on unmount.

## Findings (most severe first)

1. **Fixed during review:** `dashboardModel.ts` `appendToNote`. A scripting slip had put literal newlines into its string literals; Prettier caught it before any test run.
2. **Minor, accepted:** `Dashboard.tsx` `TasksWidget`/`ScheduleWidget`. Quick add is hidden on a folder dashboard whose folder doesn't contain the daily notes, because a task added to the daily note wouldn't show there. Those dashboards keep the existing hint ("give a task in this folder a time…").
3. **Minor, accepted:** the calendar widget now loads the task list (to mark due days), so a calendar-only dashboard does one `listTasks` per index change. That is the same cost the tasks and schedule widgets already had.
4. **Minor, accepted:** the count badge sits in the day cell's top-right corner and can touch two-digit dates on very narrow widgets; it stays readable.
