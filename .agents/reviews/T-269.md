## Findings

1. (Fixed during build) `backend.resolveLink` resolves notes only, so pages are now
   resolved with `resolveMedia`, the attachment resolver images use: by name, or `./`
   relative to the note.
2. (Fixed during build) A first draft sized frames with an inline `<style>` element. It
   would have leaked across embeds, so it is now a per-frame `style.height`.
3. (Checked, no change) Security is unchanged from T-190:
   - The sandbox string and `referrerPolicy` are the same, and the page tab and the embed
     share one component.
   - Messages are accepted only from that frame's window while it has focus.
   - The test asserts there is no `srcdoc`. `pages.rs` and the CSP aren't touched.
   - `tauri.conf.json` `frame-src` already allows `axispage`.
4. (Known gap) The height is set, not measured, and a frame can't size itself without
   page cooperation. This is left as a follow-up rather than changing `pages.rs`.

config and WebView2 profile, driven over the DevTools port with no OS input.

- `Bio/Study.md` showed the flash-card and mind-map cards, and

- Clicks sent over CDP didn't reach the page's own button, which sits in an
  out-of-process frame. That is a limit of the test, not the app; page interaction was
  established in T-190.
