# T-270 review: Bionic Reading test waits for the parse

**Verdict:** approve (Claude, self-verified under the 2026-11-10 rule)

## Problem

`bionic.test.ts` › "decorates rendered lines only, never code…" failed intermittently
under load: it bolded `inl`, `co`, `fen` and `co` inside code. The helper built an
`EditorState` and read `syntaxTree(state)` straight away. A new state parses for only a
few milliseconds, so on a busy machine inline and fenced code weren't parsed yet and looked
like prose.

The app was not affected: `bionic.ts:93` rebuilds decorations when the syntax tree changes,
so a late parse is redrawn.

## Fix

The helper now calls `ensureSyntaxTree(state, len, 5000)` before the selection update.
`LanguageState.tree` is fixed per state (see `@codemirror/language`), so the finished tree
reaches the next state through that update. The test only, no app code.
