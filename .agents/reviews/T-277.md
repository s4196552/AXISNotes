**Verdict: approve** (Claude, builder's own verification under the 2026-11-10 rule)

## Findings

1. Fixed during verification: `src/features/graph/useSigma.ts:28` (and `GraphView.tsx`, `AsciiBackdrop.tsx`, `AppColorPicker.tsx`) read `--fg` as a raw string. With Main text on, that string is `light-dark(…)`, so the local graph's node labels went blank in the preview. These readers now use `cssColor`, which paints a hidden probe to get the resolved color. After the fix, the preview showed the label in the main text color.
2. Note: `src/app/appearance.ts` puts `MAIN_TEXT_CSS` at specificity 4 × `:root` (5 with the scoped surfaces), above `appColorsCss` (3–4). A test compares the two.
3. Note: `src/app/config.ts` imports `./styles`, which imports `./config`. `styles.ts` reads `DEFAULT_CONFIG` only inside functions (`defaultLook`), so the import cycle is safe at load.
4. Nit: Settings still opens on Theme & layout by default; Styles is the page's first tab.
