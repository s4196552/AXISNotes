## Findings
1. Fixed before commit — `src/app/store.ts` (`onEntryRenamed`/`onEntryRemoved`): a
   fallback for callers that set `activePath` directly overwrote the newly active tab's
   path with `null` when the active note was trashed. The fallback now only applies when
   `activePath` didn't come from a tab. Covered by a UI test.
2. Fixed before commit — `src/features/tabs/tabs.css`: tabs shrank to ~70 px even with
   room to spare, because the strip sized itself to the tab text. Tabs now set a 190 px
   width as well as basis (seen in the preview).
3. Fixed before commit — `src/features/tabs/TabBar.tsx`: dragging a tab set
   `text/plain`, so dropping it on the editor would insert the file path. It now sets only
   `application/x-axis-path`. (After the native E2E run; drag isn't covered by E2E.)
4. Fixed before commit — lint: kind icons are rendered with `createElement` from a fixed
   table, and the helpers moved to `tabInfo.ts` so fast refresh keeps working.
5. Low, accepted — switching tabs remounts the editor, so undo history is lost per tab
   (cursor and scroll are restored). See handoff.
6. Low, accepted — `src/features/editor/Editor.tsx`: remembered cursor/scroll is keyed by
   path, so it doesn't follow a rename (the note just opens at the top).
7. Note — the E2E "restart" test reloads the front end instead of relaunching the app:
   each WebDriver session gets a fresh WebView2 profile (a sentinel key didn't survive
   `reloadSession()`), so local storage can't persist across sessions in tests.

Existing callers of `activePath`/`mainView`/`openFile` were left unchanged (mirrored from
the active tab). Diff stays within the brief's files plus `Picker.tsx` (Ctrl+Enter) and
`src/test/setup.ts` (clears saved tabs between tests).
