## What it changes

A **comprehension heatmap**: how well the user knows a topic, a rounded square per unit.

- **Topics** are sets of vault notes and folders, saved with the levels in
  `.axisnotes/comprehension.json` (format and reasons in `docs/DECISIONS.md`). Units are each
  note, or each section (the note's top headings, skipping a lone title heading at any
  level, e.g. "## Module 3: …"); a note without headings is one square.
- **The card** (`HeatmapCard.tsx`): title and counts, Notes/Sections switch, big numbers
  (% mastered = Good + Best, items covered), the grid (a column per note labelled "M10",
  "W01"…, or columns of 7 in Notes mode), a No data / Bad → Best legend, a Daylio-style row
  of counts over coloured bars, and Set levels / Practise weak spots. Gray and the five
  levels are theme tokens `--heat-0…5` (`light-dark()`, greys in E-ink).
- **Squares:** hover or focus shows the name, level, where it came from and the last result;
  click opens the note at the section; arrows move, Enter opens, 1–5 set and 0 clears a
  level. Set levels turns clicks into painting the chosen level (levels set by hand have a
  dot). A section without data shows its note's level (lighter); a note shows the average of
  its sections.
- **Where it lives:** a tab view (command "Open comprehension heatmap"; tab path = topic id),
  and a ```` ```heatmap ```` block (`title:`, `unit:`, `source:` lines) that renders in notes
  while the cursor is outside it; the card loads only when a note has one. "Insert
  comprehension heatmap in this note" and "Copy as block" make blocks.
- **Input:** "Add from vault…" picker, dragging from the file tree, the tree's "Add to
  comprehension heatmap…" (single and multi-selection), "Upload notes…/Upload folder…" and
  dropping files/folders from Explorer on the view. Disk imports go through a new native
  command `import_study_notes` (Markdown only, folder layout kept, hidden items and links
  skipped, free names, at most 2,000 notes / 16 levels).
- **Levels from skills:** Practice test and Flash cards pages now post
  `{axisnotesStudy: {kind, items: [{source, correct}]}}` when finished; the app accepts it
  only from the page's own frame while focused, once per result, and only for notes the page
  was made from (a `axisnotes-sources` meta the app adds when saving study pages) that AI may
  read. Teach me may return `comprehension: [{source, level}]`; malformed entries are dropped
  without failing the lesson.
- **AI rules:** the heatmap sends nothing to AI. "Practise weak spots" runs Practice test via
  `runSkillOnPicked` (AI: never notes left out, Rust enforces local-only). Results are never
  recorded for AI: never notes; squares of such notes say "AI: never".
