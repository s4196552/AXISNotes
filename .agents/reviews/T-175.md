# T-175 review: AI skills that any model can run

**Verdict: approve** (Claude self-review, 2026-11-06). Merged together with T-173 and T-174, which it is built on.

## What changed

- `src/features/skills/skills.ts`: the skill format. A skill is a `SKILL.md`:
  - YAML frontmatter with `name` and `description`, as in the Agent Skills layout, plus AXIS's `title`, `output` (`markdown` / `html` / `chat` / `files`) and `reads` (`note` / `folder`)
  - then the instructions, which become the system prompt for whichever provider and model the block uses
- Skill sources:
  - Built-ins are in `builtinSkills.ts`, written as SKILL.md text.
  - Vault skills are `Skills/<name>/SKILL.md` notes. They're re-read when the vault's SKILL.md notes change, and again when a skill runs, so edits apply at once. A vault skill replaces a built-in of the same name.
- The six built-in skills:
  - **Mind map** (`/mindmap`): a Mermaid `mindmap` block, used like any answer (Insert, Open as draft).
  - **Practice test** (`/test`): a self-contained HTML quiz with feedback, score and retry, no network.
  - **Flash cards** (`/flashcards`): a self-contained HTML deck with flip, shuffle, known/again and progress in `localStorage`.
  - **Grill me** (`/grill-me`): a back-and-forth in the block, one question at a time by design-tree branch. "Wrap up" asks for the decisions summary, and Open as draft keeps the transcript.
  - **Handoff** (`/handoff`): a handoff document with fixed sections.
  - **Teach me** (`/teach`): reads every note in the starting folder (minus "AI: never" ones) as its memory. It returns JSON with `Progress.md`, a lesson note and an interactive lesson page.
- Checking output (`skillRun.ts`):
  - HTML is extracted from the reply.
  - Teach files must be plain `.md`/`.html` names, at most 12, each at most 512 KB, with no repeats.
  - An unusable reply gets one retry with the problems quoted.
- What each output offers:
  - **Web page:** Open in browser (via a draft), Save next to the note (`<note> - <skill>.html`, then opened), or Open as draft.
  - **Teach:** a list of files marked new or "replaces the current one". "Save to <folder>" writes them and opens the lesson note, and "Try the practice page" opens the page.
- Where skills appear:
  - A **Skills** section at the end of the command menu, with each skill's icon, description and `/name`. Choosing one opens an AI block with a "Skill: …" chip (removable) and an optional prompt.
  - Commands: "Copy the built-in AI skills into the vault (Skills folder)" and "Make an AI skill from this note".
- `docs/DECISIONS.md`: new entry for T-173 to T-175.

## Findings

No blocking findings. Notes:

1. How well HTML pages and Teach JSON come out depends on the model. Small local models may need the retry or fail. The error says why, and nothing is written until the user saves.
2. Exporting or importing skills as one file isn't built. They're plain folders, so copying the `Skills` folder works.
3. Quick Chat doesn't run skills yet. They run from the editor's command menu.
