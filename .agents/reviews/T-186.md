# T-186 review: AI skills on files and folders picked in the tree

**Verdict: approve** (Claude self-review, 2026-11-07). Built on T-185.

## Why

The user: "Allow users to use AI skills when selecting multiple files/folders, to make skills like tests." Their screenshot shows twelve weekly Java notes picked in the file tree.

## What changed

- File tree menu (`FileTree.tsx`):
  - With several items picked, the menu now has an **"AI skill on 12 items"** group above Delete.
  - A single folder's menu has **"AI skill on "School""**.
  - Each skill is listed with its icon.
  - Teach me is offered only for a single folder, which it uses as its workspace.
- `src/features/skills/skillOnFiles.ts`:
  - `pickedNotes(paths)` collects the picked notes and every note inside picked folders, in natural order (W01 … W13).
    - Notes under "AI: never" are left out and counted.
    - At most `MAX_FOLDER_NOTES` (100) notes are kept. Rust still checks every attached note, so a note that slips through fails closed.
  - `commonFolder(paths)`: the deepest folder holding everything picked.
  - `runSkillOnPicked(skill, paths)` makes a draft for that folder.
    - The draft is titled, for example, "Practice test - 12 notes", with "Made from [[W01 …]], …" listing the sources.
    - It queues an AI block with the skill and the picked notes, then opens the draft.
    - If nothing may be read, it shows a notice instead.
- `aiBlock.ts`:
  - `AiBlockSpec.sources`.
  - `queueAiBlock(path, spec)`: a new block that appears when that note's editor opens, using T-185's parking.
- `skillRun.ts`:
  - `skillAttach` reads `sources` when given.
  - `homeFolder(path)`: a draft's results go to the folder it was made for, not the hidden drafts folder.
  - `savePageNextTo` names a draft's page after the draft, for example `Bio/Practice test - 2 notes.html`.
- `SkillResult.tsx`, `AiBlockView.tsx`:
  - Results (page, files, drafts) use `homeFolder`.
  - The Reads chip says "Reads: 12 notes".
  - The block's request includes `sources`.
- `filetree.css`: the labelled skill group in the menu.

## Findings

None blocking. The draft can be saved like any draft (Save, choosing a folder), or discarded. What a model makes from many notes depends on its context size. At 100 notes, a small local model may not fit them all, and the provider's error says so.
