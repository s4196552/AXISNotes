What changed: language-tagged inline code now closes with exactly two backticks:
`` `Java`String greeting = "Hello, World!";`` ``. The closer is the regex `CLOSE = /``(?!`)/g` in `scan()` (`src/features/editor/inlineCodeLanguage.ts:40`, used at `:86-90`). It matches the next two backticks, or the last two of a longer run, so a lone backtick may now sit inside the code (`` `js`a = `b`;`` `` → code `` a = `b`; ``). While only one closing backtick has been typed, the span counts as still open (`openCode` → "tagged"), so the typing rules keep leaving the code alone until the second one.
