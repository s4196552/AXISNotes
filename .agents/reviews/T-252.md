## Finding (from the native check of T-248 before publishing 0.3.96)

Fonts imported into the vault (T-248) never loaded in the desktop app: the window's
Content-Security-Policy had no `font-src`, so it fell back to `default-src 'self'` and
blocked every `@font-face` URL on the asset protocol (`securitypolicyviolation: font-src
http://asset.localhost/…`; `document.fonts.load` → NetworkError). Unit tests and the browser
preview (no CSP, memory backend) could not show it.

## Fix

- `src-tauri/tauri.conf.json`: `font-src 'self' asset: http://asset.localhost data:` — the
  same sources `img-src`/`media-src` already allow for vault files.
- `src/lib/fonts.test.ts`: asserts the CSP lets fonts load from the asset protocol (fails
  without the fix, passes with it).
