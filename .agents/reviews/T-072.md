## Round 1, against main

Verdict: changes-requested

## Findings

1. **High — `src/features/updates/updates.ts:49`: Installing can discard unsaved edits.** This inherited T-066 change is included in `main...HEAD`. Installation calls the backend without saving open documents or checking unresolved conflicts; the backend then calls `app.exit(0)`. For example, clicking “Install and restart” while a note has an unresolved external-edit conflict permanently loses the editor’s unsaved version. Flush pending saves and block installation when unsaved content remains.

2. **Medium — `src/ipc/tauriBackend.ts:99`: Switching materials does not clear the previous effect.** The pinned Tauri implementation applies non-null effects without clearing existing Windows effects. Blur uses the accent-policy API, while Mica uses separate DWM attributes. On Windows 11, selecting Mica and then Blur leaves Mica enabled, so the result depends on previously selected effects. Clear existing effects before applying a different material, serialize transitions, and test transitions between these material families. The current E2E assertion that IPC returns `"ok"` cannot detect this.
