# T-179 review: API key pasted into the endpoint box

**Verdict: approve**

## Problem

The user reported "OpenAI: provider unavailable: builder error" on Test connection after pasting a key. `ai-settings.json` showed the key saved as the provider's `baseUrl`, so reqwest could not build a request from it. That file is plain text, so the key was also on disk unencrypted.

## Change

- `settings.rs`: `endpoint_problem` (empty, or `http(s)://host…` in visible ASCII) and `looks_like_key`. `clear_bad_endpoints` clears invalid endpoints.
- `service.rs`: on start, invalid endpoints are cleared and the file is rewritten at once, so a leaked key leaves the disk. `save_settings` trims endpoints and refuses invalid ones, with a message naming the API key box. `set_key` refuses keys with whitespace, control or non-ASCII characters inside; surrounding whitespace was already trimmed.
- `transport.rs`: reqwest builder errors now give a readable message instead of "builder error".
- `AiSettings.tsx`: the endpoint field has a visible "Endpoint" label. A key-shaped value pasted there is not saved: it is moved into the key box with a message to press Save key.

## Findings

None blocking.
- Low: `looks_like_key` is mirrored in TypeScript and Rust. The Rust check is the enforcement and the UI only redirects, so if they drift the worst case is a clear error from the backend.
- Low: non-ASCII (IDN) endpoint hosts are refused. Users can enter the punycode form.

## Tests

- `cargo test`: 175 passed, 2 ignored (existing). New: `a_key_pasted_as_the_endpoint_is_refused_and_cleared_from_disk`, `keys_with_spaces_or_line_breaks_inside_are_refused`. `cargo fmt --check` clean.
- `pnpm lint` and `pnpm typecheck` clean. `AiSettings.test.tsx`: 9 passed, including the new endpoint-to-key-box test.
- Full `pnpm test`: 9 failures in unrelated files (editor, Mermaid, packs, colours) under full parallel load. Re-run with 2 workers, all passed except `code.test.ts`, which passes alone on this branch and on `main`: a load-related flake.

The label uses `--fg-muted`. Screenshots timed out because the window wasn't drawing, so this was verified through the DOM.
