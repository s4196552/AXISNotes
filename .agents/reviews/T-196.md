## Findings (most severe first)

1. **Accepted, fixed properly in T-197:** a follow-up's history isn't covered by the privacy rule, which only comes from file paths. Locking the note, folder and selection while a conversation is open (`locked` in `src/features/ai/AskAi.tsx`, `chatting` in `AiBlockView.tsx`) prevents the obvious path: unticking a local-only note and asking a cloud model. T-197 adds a request rule floor (`atLeast`) carrying the conversation's strictest rule, so the guarantee doesn't depend on the UI.
2. **Resolved:** with five or six buttons the Ask AI footer squeezed its labels and pushed Ask off the dialog in the app. The footer now wraps (`ai.css`, `.ask-ai-footer`); checked again in the app.
3. **Accepted, fixed in T-197:** attached notes are inserted before the newest question, after the history, so the cached prefix doesn't keep growing across turns. T-197 moves them right after the system prompt.
4. **Note:** `AnswerText` adds a "\n" text node between blocks so plain text, copies and screen readers keep line breaks; it isn't rendered.
