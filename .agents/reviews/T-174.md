# T-174 review: AI drafts and web pages

**Verdict: approve** (Claude self-review, 2026-11-06)

## What changed

- `src/features/drafts/drafts.ts`: drafts are files the AI makes, kept in the vault's hidden `.axisnotes/drafts/` folder.
  - Being hidden keeps them out of the file tree, search, links and the watcher.
  - `createDraft` writes one under a free, safe name and opens it.
  - `saveDraft` moves it into a folder under a free name, carries icons and open tabs along, and forgets its suggested folder. It's an ordinary `renameEntry`.
  - `discardDraft` moves it to the OS trash, never a hard delete.
  - The folder a draft was made for is remembered per vault (`localStorage`, this device) as the default save target.
- `DraftBanner.tsx`: above a draft note or page, "Draft. The AI made this…", with Name, Folder (every vault folder), Save and Discard. A note saves its pending edits first.
- `.html` and `.htm` files are a new `web` file kind, with a globe icon in the tree and tabs.
  - `WebFileView.tsx` shows the page's name and size, Open in browser, and Show in folder.
  - Pages never run inside the app, where they could reach the app's own IPC.
- `open_in_browser` (Rust) opens a vault `.html`/`.htm` file with the system opener.
  - Any other extension is refused, so it can't launch programs.
  - It has a Rust test for the extension check.
  - The browser preview opens a blob URL in a new tab instead.
- "Open as draft" is added to the AI block and Ask AI.

## Findings

No blocking findings. Notes:

1. Drafts aren't cleaned up on their own. They stay in `.axisnotes/drafts/` until saved or discarded. A Drafts list or cleanup could come later.
2. `explorer <file>.html` on Windows opens the default browser. macOS uses `open` and Linux `xdg-open`.
