# T-262 review: Matt Pocock's skills in the command menu

**Verdict:** approve (Claude, self-verified under the 2026-11-10 rule)

## What changed

- Matt Pocock's 26 bundled skills are listed in the Ctrl+/ menu (Skills tab, "Matt Pocock"
  section, library icon, an icon per skill) without writing anything to the vault.
- The menu uses a small generated index (`packs/mattPocockIndex.ts`); the 150 KB pack is
  still imported only when a skill runs (`freshSkill` → `loadBundled`), which adds its
  reference files and the skills it names from the pack.
- Settings → AI → Skills: a "Show in the command menu (Ctrl+/)" switch per collection
  (`config.ai.hiddenCollections`); bundled rows have no Remove button. Once a collection is
  added to the vault its vault copies are used, and one removed there doesn't reappear.
- Collection metadata moved to `collectionSkills.ts` (pure) so `skills.ts` can list bundled
  skills without a circular import; `skillId`/`SKILLS_DIR` moved to `skillId.ts` (re-exported).
