# Review: T-119 (AXISNotes's own update window, branded installer)

**Verdict:** approve

Human request (2026-10-21): "Add our current color palette and logo to make a custom download/update UI."

## Change

- `src-tauri/src/updater.rs` (new): updater mode. `updates_install` copies the running executable to
  `%TEMP%/AXISNotes-update/AXISNotes-updater.exe`, writes `update-job.json` and starts the copy with
  `--axis-updater <job>`, then quits. In that mode `run()` builds only an "updater" window (same embedded pages,
  `window.__AXIS_UPDATER__`, own WebView2 data folder) with three commands: `updater_job`, `updater_install` (installer
  `/S /UPDATE`, waited on a blocking thread) and `updater_finish(open)`. If the copy can't start, the old passive
  installer runs instead.
- `src/main.tsx`, `src/features/updates/{UpdaterWindow.tsx,updaterSteps.ts,updater.css}`: the window, in the dark
  palette with the logo in an accent-lit tile, versions (old → new), an indeterminate accent bar, status line and
  release notes; on failure, the reason plus Open AXISNotes / Close. Runs its steps once even under StrictMode.
- `src-tauri/capabilities/updater.json`: the updater window may drag itself (core:default + start-dragging).
- `src-tauri/tauri.conf.json`, `src-tauri/installer/*.bmp`, `scripts/installer-art.py`: installer icon, sidebar
  (welcome/finish pages) and header art for fresh downloads, generated from the app icon and the dark tokens.
- `docs/DECISIONS.md`: entry, including Pillow (dev-only, HPND/MIT-CMU).

## Findings

None blocking.

- The update window first appears on the update *after* the release that adds it (the installed version runs the
  install). Noted in the decision log.
- The installer's silent mode closes a still-running `axisnotes.exe` itself (Tauri NSIS `CheckIfAppIsRunning`:
  `IfSilent kill`); the updater copy has a different name, so it isn't closed. Install mode is `currentUser`, so no
  elevation prompt.
- The NSIS wizard pages with the new art weren't opened by hand; the generated `installer.nsi` defines
  `INSTALLERICON`, `SIDEBARIMAGE` and `HEADERIMAGE` from the new files, and the images were checked visually.

## Checks

- `pnpm lint`, `pnpm typecheck`: pass. `pnpm test`: 81 files, 669 tests pass (2 new for the window).
- `cargo clippy --all-targets`: clean. `cargo test`: 156 passed, 2 ignored (3 new: job args, missing job,
  failing installer).
- Release build (`pnpm tauri build --bundles nsis`): succeeds.
- Real WebView2, release exe copied as `AXISNotes-updater.exe`, with stand-in installers (batch files):
  - Success: Updating AXISNotes, 0.3.19 → 0.3.20, notes, "Installing the update…", then "Done. Opening AXISNotes…",
    reopens the given app and exits.
  - Failure (exit 2): "The update didn’t install", "The installer stopped with error 2. Your notes are safe…",
    Open AXISNotes / Close; Close exits the process.
  - The same exe without the flag starts the normal app (welcome screen).
