# Review: T-155 Back/Forward buttons

**Verdict: approve**

## What changed

- `src/features/tabs/NavButtons.tsx` (new): Back and Forward arrows at the start of the tab row. They follow the active tab's existing history (`tabs.ts` `back`/`forward`), are greyed out when there is nowhere to go, and name the destination ("Back to Biology", with the remappable `go-back`/`go-forward` shortcut in the tooltip). Right-click either one for its list of places, nearest first; picking one jumps straight there. The mouse's side buttons (4/5) go back/forward anywhere in the window, with the webview's own handling prevented.
- `src/app/tabs.ts`: `go(s, steps)` walks several places at once (used by the history menu). `src/app/store.ts`: `goHistory(steps)`.
- `src/features/tabs/TabBar.tsx`, `tabs.css`: mount and style the buttons.

## Findings

No blocking findings.

1. Minor, `src/features/tabs/NavButtons.tsx:110`: the history menu closes on an outside click, blur or a pick, but not on Escape. The tab context menu behaves the same, so this is consistent with the existing menus.
2. Note, `src/features/tabs/NavButtons.tsx:31`: the side-button listener is on `window`, so it also fires over the canvas and grid. That is intended (browser behaviour), and it only exists while a vault is open (the tab bar is mounted).
