## What it adds

- **Settings → AI → Skills** (`src/features/settings/SkillsSettings.tsx`) lists every skill in
  its command-menu group, with:
  - **Customise** on built-ins, which copies one into `Skills/` to edit;
  - **Remove** on vault skills, which moves the folder to the trash after asking;
  - **New skill**, with a name, what it does, how it answers (Markdown, web page or chat),
    whether it reads the note or its folder, and instructions. It writes
    `Skills/<name>/SKILL.md`;
  - **Import skill…**, for picking a skill's `SKILL.md`, for example from
    `~/.claude/skills`.
    - The native `import_skill` copies its Markdown/text files into `Skills/<folder>`.
    - Limits: that folder and one level down, at most 40 files of 512 KB each, and never
      scripts.
  - **Copy the built-in skills to edit**.
- **Skill collections → Matt Pocock's skills**, bundled from github.com/mattpocock/skills
  (MIT, commit `5863806d…`).
  - It holds the 26 engineering and productivity skills (not `setup-matt-pocock-skills`) and
    their reference files.
  - It is loaded only when added, and writes to `Skills/Matt Pocock/` with `LICENSE.md`.
  - Each skill runs as an AI chat on the note, under its own "Matt Pocock" group.
  - `grill-me`, `handoff` and `teach` get a `-pocock` suffix so they sit beside AXISNotes' own.
  - Adding again only fills in missing files, so edits are kept.
- **Running vault skills:**
  - A skill's reference files, and the skills it names ("call the Skill tool with …"), go with
    its instructions, up to 60,000 characters.
  - A note tells the model it can't run tools: it should ask the user, or say what to do
    instead.
- `collection:` in a SKILL.md groups skills in the command menu and Settings.

## Findings

Fixed during review:

- **Privacy:** reference files and named vault skills travel as instructions, so they would
  have bypassed AI access rules.
  - They are now included only when any AI may read them (folder rule and `ai-access` mark).
  - A test covers a reference file under a local-only rule.
- **Wording:** the page said to "type /". The command menu is Ctrl+/ (a typed `/` is off by
  default since T-065), so it now says Ctrl+/.
- **Titles:** "Tdd" and "Pr" are now "TDD" and "PR".
