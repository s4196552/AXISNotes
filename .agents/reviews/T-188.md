**Verdict: approve** (Claude self-review, 2026-11-07)

## Why

The user wants code coloured green, yellow, orange, red, violet or blue, in both single-line and multi-line code. Their example used the language-tag syntax from T-150 and T-152, `` `green`dog2.sit();`` ``, and a fenced Java class.

## What changed

- `src/features/editor/codeColors.ts` (new):
  - `CODE_COLORS`: green, yellow, orange, red, violet, blue, with `purple` as an alias for violet.
  - `codeColor(name)` matches any letter case.
  - `codeColorClass(c)` gives `cm-tint-<colour>`. The name avoids the syntax token classes `cm-code-keyword` and similar.
- `inlineCodeLanguage.ts`:
  - The tag in `` `tag`code`` `` may be a colour as well as a language. A colour is checked first, so no language alias can shadow it.
  - `TaggedCode` has `language | null` and `color | null`.
  - A coloured span gets the tint mark and no syntax highlighting.
  - Hiding the tag and the closing backticks off the cursor's line works as before.
- `livePreview.ts`, fenced code:
  - With a colour as the info string (` ```green `), the code lines get the tint class.
  - The language label is left off, so "green" isn't shown as a language.
  - The fences show and hide as before.
- `code.ts`: after ` ``` `, the suggestions also offer the six colours (detail "code colour").
- `editor.css`:
  - `.cm-tint-*` set `--code-color` with `light-dark()`, for example green `#2b8a3e` / `#69db7c`.
  - The tint applies to the span or line and everything inside it (`!important` over token colours).
