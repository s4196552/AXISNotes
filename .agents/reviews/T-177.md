# T-177 review: Agent UI fixes

**Verdict: approve** (Claude self-review, 2026-11-06)

## What changed

- **Quick Chat icon off centre** (`src/features/agent/agent.css`, `.agent-chat-button`): the app-wide `button` style (`src/styles/app.css:33`) gave the 30 px round button `padding: 6px 12px`. That left almost no content box, so the 16 px icon sat 6 px right of centre. The button now has `padding: 0` and `box-sizing: border-box`, and its icon is a block. Measured in the preview: button centre and icon centre are both at x 80, y 170.
- **Antenna cut off** (`AgentFigure.tsx`, `agent.css`): the built-in figure was scaled by `size / 112`, but its art is 134 px tall (a 104 px face plus the 30 px antenna and dot). At the default size the dot was drawn above the Agent's window and clipped. It now scales by `size / 134`, so the whole figure fits inside the Agent's box. The default figure is about 16% smaller, with the same window size.
- **Icon in the wrong colours in dark mode** (`agent.css`): the Agent's colour variables were set only on `.agent-figure`. The Quick Chat icon sits beside it, not inside it, so it always used the light fallbacks (a pale button under a dark Agent). The variables are now also set on `.agent-window-root` and `.agent-inline`.
- **In-page Agent dragged to the top edge** (`AgentBridge.tsx:246`, browser only): the drag clamp ignored the 40 px Quick Chat row, so the row could be dragged off the bottom of the window. It now counts the row.

## Findings

No blocking findings.

1. With Quick Chat open, the Agent stays at the left of the wider window instead of above the panel's centre. This is deliberate: the window grows right from its top-left corner, so centring would make the Agent jump sideways.
2. Users' own images per state are not affected by the scale change, which only applies to the built-in figure.
