# T-203 review: Middle-click opens in a new tab everywhere

**Verdict: approve**

Reviewer: Claude (self-review). I read the full diff of `agent/claude/T-203` against `main`.

## Findings (most severe first)

1. **Resolved: a graph crash.** The new Ctrl+click check read `event.original` on every node click, and `src/features/graph/useSigma.ts` crashed when Sigma sends a click without the original event. It now treats that event as optional; caught by `graph.test.tsx`.
2. **Resolved: the file tree's dashboard icon.** A capture-phase `stopPropagation` would also have blocked the icon's own click, so it keeps its own handler: a click stops at the icon, and Ctrl+click opens a new tab. A middle-click on a folder that has a dashboard opens it in a new tab through the row's own `onAuxClick`.
3. **Note:** `openOnClick` cancels the wheel's mousedown, so Windows' auto-scroll doesn't start. It also stops the auxclick from bubbling, so a row inside another clickable doesn't open twice.
4. **Accepted:** the quick switcher, the palette and outline headings are unchanged; see the handoff.
