## Findings

1. Fixed before commit — `src/features/graph/GraphView.tsx` (`TreeControls`): the root
   field picked a note as soon as the typed text equalled any note's name, so typing a
   name that is a prefix of another ("UX" before "UX rapid") would jump the field to a
   full path mid-typing. A suggestion (full path) is still picked at once; a typed name
   is picked on Enter or blur. Test added.
2. Fixed before commit — `src/features/graph/TreeView.tsx`: the effect that moves DOM focus
   ran on every layout change, so an index refresh or a root change could pull focus out of
   the root field back into the tree. Focus now moves only for arrow-key navigation, and
   the focused node lights its path only while the tree has focus.
3. Fixed before commit — `src/features/graph/TreeView.tsx`: the empty state returned
   before the container's ref was attached, so a tree that started empty (no notes yet)
   never got its wheel-zoom listener. The container now always renders.
4. Fixed before commit — `src/features/graph/useSigma.ts`: sigma threw "Container has no
   width" when the view mounted while the window was minimized (seen in the preview), and
   the graph then never drew. Now `allowInvalidContainer` plus the existing resize
   observer. An empty graph no longer runs a pointless simulation or freezes an empty
   bounding box.
5. Low, accepted — `src/features/graph/forces.ts`: physics runs on the main thread (the old
   ForceAtlas2 used a worker above 400 nodes). Mitigated: ≤120 ms pre-tick, coarser
   Barnes–Hut and faster cooling above 1,500 nodes, stops when cool, pauses when hidden.
   Not benchmarked on a 5,000-note vault; recorded in DECISIONS and the handoff.
6. Low, accepted — `src/features/graph/useSigma.ts` (`release`): if the mouse is released
   outside the canvas, sigma may not report `upNode`/`upStage`, leaving the node pinned
   until the next release on the graph.

Diff touches only the files in the brief (`src/features/graph/**`, package files, docs,
`.agents`). No store or command-registry changes, so no overlap with T-085.
