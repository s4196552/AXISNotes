# T-180 review: App colours in their own Settings section

**Verdict: approve** (Claude self-review, 2026-11-07)

## Why

App colours (T-178) shipped in Settings → Appearance, below the theme list, so the user couldn't find it after updating to 0.3.60. The user asked for it to get its own section.

## What changed

- `src/features/settings/Settings.tsx`:
  - New section **Colours** (`colours`, Paintbrush icon), listed right after Appearance in the Settings nav.
  - It renders the same App colours field, with the same hint (including the Translucent note) and the same `AppColorPicker`. The value still writes to `appearance.appColors`, so saved colours carry over unchanged.
  - The field is removed from Appearance.
  - Settings search still finds it, since search renders every section.
- Comments in `src/app/appColors.ts`, `src/app/config.ts` and `AppColorPicker.tsx` now point to Settings → Colours.
- Tests:
  - `appColors.test.tsx` opens the `colours` section.
  - The section-count test expects 14.
