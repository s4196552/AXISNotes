# T-184 review: Markdown or HTML for every AI skill (and the AI block's missing styles)

**Verdict: approve** (Claude self-review, 2026-11-07)

## Why

The user asked for both an HTML and a Markdown option for every skill. While checking it in the preview, I found that the AI block opened without its stylesheet. This explains the user's earlier Mind map screenshot, with plain buttons, a bare text box and chips stacked one per line.

## What changed

- `src/features/skills/skills.ts`:
  - `SkillFormat` (`markdown`, `html`, `both`), `formatsOf`, `defaultFormat` and `FORMAT_LABELS`.
  - Every skill offers Markdown and HTML. Teach also offers Both, which is its default. A skill's default is its own `output`.
  - `withFormat(skill, format)` returns the skill as it runs in that format:
    - Its instructions keep the shared part plus that format's `## Format: Markdown / HTML / Both` section of the SKILL.md.
    - A note or page skill's `output` becomes `markdown` or `html` to match, so the existing run, check and result code works unchanged.
    - A skill without format sections (for example the user's own) gets a general Markdown or HTML instruction, only when run in the format it wasn't written for.
    - A chat skill stays a chat. Its format only decides how the conversation is kept.
- `builtinSkills.ts`: all six skills rewritten with a format-neutral shared part and their own sections.

| Skill | Markdown | HTML |
| --- | --- | --- |
| Mind map | Mermaid `mindmap` block (as before) | Interactive page: SVG or CSS tree, folding branches, Expand/Collapse all |
| Practice test | Numbered questions, each answer in a folded `[!success]- Answer` callout | Interactive quiz page (as before) |
| Flash cards | One folded `[!question]-` callout per card (click to flip) | Flip-card page (as before) |
| Grill me | Conversation kept as a Markdown note (as before) | Conversation kept as an HTML page |
| Handoff | Markdown document with [[wikilinks]] (as before) | Page with a table of contents and a next-steps checklist |
| Teach me | Progress.md and a lesson note with folded answers, no .html | Progress.md and the whole lesson as an interactive page |

Teach me's **Both** gives Progress.md, a lesson note and a practice page, as before.

- `ai/aiBlockStore.ts`: block state `format`.
- `ai/AiBlockView.tsx`:
  - A segmented **Markdown | HTML** switch (**Both | Markdown | HTML** for Teach), labelled "Format", next to the skill chip.
  - Switching format clears a finished page or file list made in the other format.
  - Runs use `withFormat` on the freshly read skill.
  - Removing the skill resets the format.
  - **Imports `./ai.css`.** Before this, only Settings → AI, Ask AI, Fix text and the diagram maker loaded it, all lazily. An AI block opened before any of those had no styles.
- `skills/skillRun.ts`: `transcriptHtml`, the Grill me conversation as a self-contained page built locally, not by the model.
  - All text is escaped.
  - `**bold**`, inline code and `-` lists are converted.
  - It follows light and dark mode.
- `skills/SkillResult.tsx`: `ChatActions` takes `format`. In HTML, Open as draft makes an `.html` draft.
- `ai/ai.css`: `.ai-format` switch styles.

## Findings

None blocking. What a model makes in the newly added formats (for example a Mind map page, a Markdown test) depends on the model, as before. The existing one retry for a missing page still applies to every HTML run.
