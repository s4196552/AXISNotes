# Review: T-106 — Folder dashboards show only their contents, as modules

**Verdict:** approve (self-review by Claude, the lead, per the 2026-10-17 agreement)

The human asked that sub-dashboards (folder dashboards) show only that folder's contents, in module format. Reviewed `git diff main...agent/claude/T-106` in full (`src/features/dashboard/**` and `e2e/specs/dashboard.e2e.ts`).

## What changed

- **New Contents widget** (`type: "contents"`, wide by default):
  - one module per direct subfolder: its icon, name, file count and latest change; clicking the header opens that folder's dashboard, and its 4 most recent notes at any depth are listed, with "N more";
  - one "Notes" module listing the files directly in the folder by name;
  - an empty folder says so.
  - Rows and headers open on click; Ctrl+click or middle-click opens a new tab. Custom folder icons are used.
- **Folder dashboards default to Contents only.** `defaultDashboard(folder)` gives a folder `[contents]`, Home keeps calendar/tasks/schedule/pinned, and Reset uses the folder's own default.
- **Existing folder dashboards:**
  - one made before this change and never customized (exactly the old four default widgets, with no title, options, size or pins) now reads as the Contents layout, and the first save stores it;
  - any folder dashboard the user changed is left alone;
  - Home is never changed.
- Contents can also be added to Home or any dashboard from Customize → Add a widget. The other widgets can still be added to a folder dashboard if the user wants them.
- Model helpers `folderContents` (direct subfolders and files, by name with numeric sorting) and `recentInside` (one folder's subtree, not the whole vault).

## Findings (most severe first)

1. **Minor, accepted:** the upgrade only recognises the untouched old default. A folder dashboard the user had customized keeps its Home-style widgets; they can Reset it to get Contents.
2. **Minor, accepted:** the "Notes" module lists every file in the folder, so a folder with hundreds of loose files gives a long module. Subfolder modules are capped at 4 rows.
