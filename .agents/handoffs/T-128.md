# T-128 — Rounded modular panes

## Built

Implemented the human-approved layout and screenshot: 18px pane corners, 8px outer inset and 8px gaps beside visible docked sidebars. Main content (including tabs) and both sidebars are separate outlined panes; the status bar stays outside. Geometry is shared across themes through an internal PANE_LAYOUT constant exposed as shell CSS variables.

Glass and Liquid Glass keep their palette, fonts, native/window opacity and surface effects; only their duplicate shell spacing and pane-corner rules were consolidated into the common layout. No appearance settings, defaults, stored configuration, user theme files, menus, dialogs or controls were restyled. New and existing vaults use the same layout automatically.

Window controls align inside the inset top-right corner (welcome screen remains outside this shell rule). Resize handles stay fully inside the clipped edge. Resize limits account for the outer insets and gaps while leaving a 320px main pane. Gaps disappear independently with their sidebars.

Compact overlays reset grid-area to auto so their 8px inset is measured from the shell instead of an already-inset grid cell. Native measurements caught the first implementation at x/y 16px instead of 8px; the corrected rebuilt app passes the original geometry assertions.
