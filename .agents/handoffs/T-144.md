# T-144 - Context menus stay inside the window

Built by Claude on agent/claude/T-144 from main 448b15d, at the human's request: when right-clicking in the sidebar's file view, move the menu up when it would go past the screen, then check and test it. (T-143 is the Settings search task, handed to its own session.)

## Behaviour

- File tree right-click menu, tab right-click menu and tab-group editor: open at the pointer when they fit; otherwise above (or left of) the pointer; otherwise against the window edge; and when taller than the window, from the top with scrolling.

## Files

src/app/menuPosition.ts (new), src/app/menuPosition.test.ts (new), src/features/filetree/FileTree.tsx, src/features/tabs/TabBar.tsx, docs/DECISIONS.md, task coordination.

## How to test

`pnpm vitest run src/app/menuPosition.test.ts`. In the app: make the window short, right-click a note low in the file tree; the whole menu stays visible.

## Known gaps

The installed app runs at the native window size, so behaviour there was not checked separately from the Vite preview. No WDIO run.
