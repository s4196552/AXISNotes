# T-067: more themes (Darker, Minimal, Glass, High contrast, Retro)

The human asked for "a darker, minimalist, glassmorphism (like apple), high contrast, and retro theme. Iterate until it looks professional and unique."

## What was built

- **Five built-in themes** (`src/styles/themes.css`), chosen in Settings → Appearance:
  - **Darker:** near-black OLED surfaces, soft violet accent, white headings.
  - **Minimal:** warm white, monochrome ink accent, hairlines; links are told apart by a quiet underline (new `--link` token); grey default callouts.
  - **Glass:**
    - frosted floating panes (sidebar, note, links pane) with gaps between them over a soft gradient wallpaper;
    - one layer of glass under the note;
    - a Finder-style blue pill for the open file;
    - blurred dialogs and menus;
    - follows the OS light/dark.
  - **High contrast:** black, white and yellow. Links are underlined, `==highlights==` are black on yellow, and focus rings are 3 px.
  - **Retro:**
    - cream paper and ink lines;
    - rust accent and mustard selection;
    - monospace UI with Georgia note text;
    - hard offset shadows on dialogs, menus and real buttons;
    - a classic-Mac pinstriped title bar behind the vault name.
- **Tokens** (`src/styles/theme.css`):
  - new: `--bg-elevated`, `--app-backdrop`, `--link`, `--heading`, `--scrim`, `--scrollbar`, `--radius-sm/-/md/lg` and `--shadow-pop/-modal`;
  - feature CSS now uses them instead of fixed radii and shadows. The defaults reproduce the old look exactly (5 px radii became 4 px).
  - Thin, theme-coloured scrollbars everywhere.
  - The OS dark fallback now applies only without `data-theme`.
- **Theme tiles** (`ThemePicker.tsx`, `themePicker.css`):
  - Each built-in tile is a live miniature drawn with its own tokens (`[data-theme-preview]`); "Match system" shows light and dark halves, and user themes get "Aa" tiles.
  - The tiles are native radios, named by label and described by the note.
- **Graph colours follow the theme.** `applyAppearance` fires `axisnotes:theme-changed`, `onThemeChange` adds the OS light/dark change, and both graphs rebuild via `useThemeVersion`. This also fixes the old light/dark staleness.
- **`effectiveMode` knows each theme's mode**, so Toggle theme, the canvas and Mermaid pick the right light/dark.

## How it was checked

- The themes were iterated visually in the browser preview (demo vault plus a sample note with headings, tasks, a callout, code, a table and highlights), at 1440×900 and at 1:1.
- Fixes made along the way:
  - **Glass:**
    - The editor no longer double-layers the glass.
    - The light variant is more translucent.
    - The file pill replaced the outline box.
    - Sigma-safe `rgba()` colours.
  - **Minimal:** link underline; lighter default callout.
  - **High contrast:** underlined links; readable highlights.
  - **Retro:** hard shadows limited to real controls (they first boxed every calendar day and toolbar icon).
  - **Tiles:** grid specificity; the selected row in the miniatures.
  - **Graph:** colours went stale on theme change.
- Tests:
  - `themes.test.tsx` checks `data-theme` for each built-in, the user-theme CSS, `effectiveMode`, `onThemeChange`, that each theme block defines every colour token, and the tiles (names, descriptions, previews, saving).
  - `pnpm test`: 275 pass. Lint, types and Prettier are clean. No Rust changes.
  - Full E2E on the built app: 8/8 spec files (53 tests) pass, including the theme switch through a tile. That build predates the folder-colour fix below, which is covered by unit tests and checked in the preview.
- **Found while iterating, outside the themes:** graph nodes in folders always drew black, because sigma can't parse `hsl()`. `folderColor` now returns hex.

## Known gaps

- Glass's frosted panes need `backdrop-filter` (WebView2/WebKit both support it).
- System fonts only. Retro falls back to Consolas/Courier where Cascadia Mono or IBM Plex Mono is missing; Glass uses SF Pro on macOS and Segoe UI Variable on Windows.
- Excalidraw canvases only switch light/dark; they don't take on the theme colours.
- The `==highlight==` and callout-type colours stay fixed except where a theme overrides them (High contrast, Minimal).
