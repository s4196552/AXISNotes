# T-208 — Ctrl+Q in notes and sidebars

## Behavior

Ctrl+Q runs “Expand or collapse current block or sidebar item.” Put the caret on a block title or inside its contents. The nearest foldable block wins, including nested lists, headings, fenced code, toggle lists and foldable callouts. Existing Markdown toggles keep their saved marker. Ordinary folds are view state. Editable block embeds use their existing revision-checked save path. Read-only self-embeds can toggle locally.

In Files, the selected folder toggles. From a file inside a folder, the command selects and collapses its parent so the next press can reopen it. In the right sidebar it operates on Calendar, Outline or Local graph. The command uses the focus from before the command palette opened and can be reassigned in Hotkeys.

## Changes and checks

The command registry and modal dispatcher route the shortcut to the focused context. Editor toggles and embedded editors, file tree rows, and right-sidebar section focus handling implement the targets. Regression coverage is in src/features/editor/foldArrows.test.ts and e2e/specs/context-fold.e2e.ts. The native test uses a disposable vault and checks the actual Markdown after toggling a referenced block.

Run the project type checks, lint, Vitest and Rust checks. Run the new desktop spec against a build with the current web assets and a WebDriver matching WebView2.
