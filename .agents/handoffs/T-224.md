# T-224 — Selected logo on the Windows taskbar

Implemented in `.worktrees/T-224`, branch `agent/codex/T-224`, based on main `9978504` (0.3.85).

## Root cause and correction

Tauri 2.11.6's `setIcon` routes through tauri-runtime-wry 2.11.4 `WindowMessage::SetIcon` to Tao 0.35.3 `set_window_icon`, which sets **ICON_SMALL only**. Tao exposes a separate taskbar setter for **ICON_BIG**, but this Tauri API does not call it. T-219's probe fell back to a small/class icon, so it proved the small icon changed without establishing the taskbar's large icon. Its earlier taskbar verification was too permissive.

Reproduced against the exact optimized 0.3.85 executable: the tightened native regression fails with **Window has no explicit Big icon**. The same test passes against this implementation. Microsoft's [WM_SETICON contract](https://learn.microsoft.com/en-us/windows/win32/winmsg/wm-seticon) distinguishes the two icon sizes.

## Behaviour and files

- `src-tauri/src/taskbar_icon.rs`: a main-app-only native command validates fixed 256×256 RGBA, creates an independently owned Win32 icon and sets ICON_BIG on the main UI thread. Converts RGBA to BGRA with a bounded 1-bit transparency mask. Retains the new HICON while Windows borrows it, destroys the previous owned HICON only after replacement, and releases the last one at shutdown. Never destroys Tauri's small or shared/class icons. Existing non-Windows small-icon behavior remains; the additional operation is a validated no-op there.
- `src-tauri/src/lib.rs`: registers the command and its lightweight ownership state.
- `src/ipc/tauriBackend.ts`: keeps the existing Tauri small-icon operation and then updates the taskbar icon with the same decoded pixels; still closes the temporary Tauri image on success/failure.
- `src/ipc/tauriBackend.test.ts`: both native operations, error propagation/image cleanup and invalid-size rejection.
- `e2e/window-icon.ps1`: explicit Big/Small selection with **no fallback** to another icon type. Read-only, selects the exact test executable; never frees an app-owned HICON.
- `e2e/specs/logos.e2e.ts`: verifies actual Big icon pixels for both bundled designs, matching Big/Small pixels, reload persistence, original reset, imported custom image and malformed command rejection.

Built-in and uploaded logos use the existing selector; the saved selection is reapplied on startup/reload/vault changes. Running-window/taskbar branding only: application identity, executable resources, installed/pinned shortcut artwork and taskbar pinning are preserved. No dependency, permissions change, polling or background process was added. Uses three documented User32 APIs through a small Windows-only FFI module.
