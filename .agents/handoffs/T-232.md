# T-232 — Markdown live preview editing

- Up and Down navigate visible text rows, including soft-wrapped rows. Ctrl
  uses the same movement and Shift extends the selection. Rendered widgets
  and folded content are skipped until their source is visible.
- Smart lists continue on a filled bullet, numbered item or task. Enter on
  an empty item exits to the current blank line or outdents to the parent
  list. New task items start unchecked.
- Mermaid diagrams use the same side and corner handles as images. A
  completed drag writes `width=<pixels>` to the opening fence info without
  changing the diagram source. The editor scales the SVG proportionally.
- **Ctrl+/** → **Quote** inserts `> [!NOTE] QUOTE` followed by
  `> Contents` and selects the placeholder. **Turn into** uses existing
  text as the body.

The changed implementation and tests are confined to the Markdown editor,
its Mermaid preview, and the native smoke test. Run
`e2e/specs/markdown-editing.e2e.ts` against a Windows development build to
check the live editor in WebView2.
