# T-017 handoff: `.axcanvas` canvas

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-017`

## What was built
- **`src/lib/canvas.ts`**: the `.axcanvas` format. It is Excalidraw JSON: parsed leniently, serialized stably, with deleted elements and unused files dropped. It also defines the `axis:<path>` card links.
- **`src/features/canvas/`**:
  - `Canvas` embeds Excalidraw (lazy-loaded through `loadExcalidraw` from the `./excalidraw` seam module) and autosaves through `useFileDocument`. It shows a conflict/removed banner and opens read-only when the file can't be parsed.
  - Note cards can be added from a picker ("Add note card") or dropped from the file tree. Card links open the note.
  - `NoteCard` shows a live preview of the note that follows edits.
  - A custom main menu and welcome screen replace Excalidraw's defaults, so there is no Excalidraw branding or "saved in your browser" text.
- **Offline fonts**: a Vite plugin (`vite.config.ts`) serves and copies Excalidraw's fonts, and `EXCALIDRAW_ASSET_PATH` points at them.
- **Rust**: canvases are indexed for search (text elements), and `rename_with_links` retargets card links in every canvas.
- **App, tree and commands**: `.axcanvas` opens in `Canvas`, "New canvas here" is in the tree menu, and there is a "New canvas (whiteboard)" command.

## How to test
- `pnpm test`: 147 tests, including canvas format (3) and Canvas (5) with a fake Excalidraw.
- `cargo test`: 37 tests, including canvas search and card rename.
- Manual: in `pnpm dev`, open `School/Study board`. Draw, add a card, drag a note from the tree, and click a card's link icon.

## Known gaps
- Canvases are not backlink sources yet. A note doesn't list the canvases that show it.
- The CSP compatibility of Excalidraw inside the real Tauri webview still needs checking in T-019's E2E run.
- Images are embedded in the canvas JSON.
