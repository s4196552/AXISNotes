# T-086 handoff: Obsidian-style graph and a tree layout

## What was built

- **Graph | Tree switch** in the graph view toolbar (remembered per device).
- **Graph (Obsidian-style):** live d3-force physics that settles and stops by itself;
  drag a node and its neighbours follow; a settings panel (gear) with **Filters** (orphans,
  unresolved links), **Groups** (query → colour, first match wins), **Display** (arrows,
  text fade threshold, node size, link thickness) and **Forces** (centre, repel, link
  force, link distance), plus **Animate** and restore-defaults buttons. Display and group
  changes don't move anything; force changes reheat the same simulation; filter and theme
  changes keep each note's position.
- **Tree:** a left-to-right tree like a decision tree. Follows **Links**, **Backlinks** or
  **Folders**, 1–6 levels. Root is the chosen note, else the open note, else the
  most-linked note; pick it in the root field (suggestions, or type a name and press
  Enter), use the crosshair for the open note, or right-click any node. Columns per level
  with headings and alternating bands, elbow connectors with arrowheads, the path to the
  hovered/focused (else open) note in the accent colour, `+n` for links shown elsewhere or
  past the depth, collapsible subtrees, pan (drag), zoom (wheel, buttons), Fit. Keyboard:
  roving tab stop, ↑/↓/Home/End move, ←/→ collapse/expand or go to parent/child, Enter
  opens.
- Sigma mounts even into a zero-size container (minimized window) and draws when resized.

## How to test

`pnpm test src/features/graph`. In the preview (`axis-T-086`, port 1486), open the graph
view (left sidebar button): drag nodes, open the gear panel and move sliders, add a group
like `tag:x`; switch to **Tree**, change the root/direction/depth, hover a deep node,
collapse a subtree, right-click to re-root.

## Known gaps

- Physics runs on the main thread; a 5,000-note vault settles in a few seconds with the
  view open. Not measured against the old ForceAtlas2 worker.
- The tree's sibling order is alphabetical (the graph's edges are sorted in Rust, so the
  order of links inside a note isn't available).
- Tree settings (root) aren't remembered across opening the graph view; direction and
  depth are.
- No new command-palette entry for the tree (T-085 is editing the command registry); the
  Graph | Tree switch is in the view.
- Native E2E not run; `e2e/specs/blocks.e2e.ts` uses only `.graph-count`, the canvas test
  id and `__sigma`, all unchanged.
