# T-143 - Search settings

Built by Claude on agent/claude/T-143 from main 448b15d, at the human's request ("Add search features in settings"), handed over from the session that designed it.

## Behaviour

- A "Search settings" box at the top of the Settings section list, focused when Settings opens.
- Typing shows every section stacked under its name with only matching settings visible (rows, list items such as keyboard shortcuts, built-in command checkboxes); they work in place. All words must match the setting's text, its group heading, the setting holding it, or the section name; the section name alone shows the whole section. "No settings match" when nothing is left.
- AI, Web clipper, Updates and Icon & image packs are not opened by a search (they load live data); they appear as "Open …" rows when a keyword matches (e.g. "api key", "pairing", "emoji") and open that page.
- Escape clears the search, then closes Settings. Clicking a section in the list leaves the search.

## Known gaps

Matches aren't highlighted. A section's loose text (e.g. the Keyboard shortcuts filter box, Quick commands intro) shows with any matching setting in that section. Live sections are matched on a fixed keyword list, which needs updating if their settings change. No native WDIO run.
