# T-205 — Skill saving and desktop tab regressions

The human assigned the fixes from the 0.3.80 review and requested a follow-up check for user-facing bugs. The task branch is ready for Claude verification.

## Changes

- Teach me preserves folders that collide with a generated filename. Before updating an existing text file, it recycles a private copy of the previous contents and writes the update with the revision read from disk. File-tree Undo and Redo group the files from each save attempt. A retry skips files already written, including files the user has since edited.
- Grill me retains its strictest privacy rule for planning, sending follow-ups, and saving the transcript. The source controls lock once a conversation starts. Switching formats keeps a separate Markdown and HTML path. Saving again in the same format updates that file. Discard closes after the saved files have been removed and keeps the conversation available if removal fails.
- The Windows UI check found a stale status-bar error after a successful lesson retry. The error now appears inside the affected block and clears when the outstanding files are saved.
- Tab tests read the editable note title using its input value. The task board lists the changed files. Regression coverage is in the skill component tests.
