# T-005 handoff: Integration and E2E (Phase 0)

**Built by:** Claude. **Branch:** `agent/claude/T-005`

## What was built
- `e2e/`: WebdriverIO + tauri-driver suite against the real debug build and a temp vault (9 tests):
  open vault, open note with live preview, autosave to disk, external edit right after autosave, atomic save by another editor,
  files created outside the app, nested folder + note creation, 1 MB note responsiveness, F2 rename.
- `AXIS_OPEN_VAULT` startup env var (Rust `setup`).
- Watcher fixes found by E2E (mtime-based self-write suppression; rename/remove classification) + 3 new Rust tests.
- Editor: only a rename *away* from the note shows the "moved or deleted" banner (+1 test). Memory backend: `emitChanges`.
- CI: `e2e-linux` job (tauri-driver + WebKitWebDriver under Xvfb).

## How to test
```
pnpm e2e:build
pnpm e2e
```
Windows needs msedgedriver matching WebView2 in `~/.axis-e2e/msedgedriver-<version>/` (or `AXIS_MSEDGEDRIVER`).

## Known gaps
- The `e2e-linux` CI job has not run yet (no GitHub remote); it is unverified.
- Drag-and-drop and trash are covered by unit tests only (WebDriver drag-and-drop and native confirm dialogs are unreliable).
