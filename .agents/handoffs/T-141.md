## What changed

- Settings → AI → Provider type → **ChatGPT plan (Plus / Pro)** → **Add provider** → **Continue with ChatGPT**. This is separate from OpenAI API keys; other providers retain existing API/local options.
- The system browser runs the official public-client flow. Rust handles ephemeral loopback callbacks, state, nonce, PKCE, issued-client reuse, stable installation identity, JWKS/RS256 signature and identity checks, explicit plan scopes, expiry, serialized/cross-process-locked refresh, cancellation and disconnect. Credentials never reach IPC or web storage.
- OAuth records use native OS-keychain chunks sized for Windows' UTF-16 credential limit. A generation manifest is published last; prior entries are removed on replacement/disconnect. Existing API keys remain in their original namespace. Reserved subscription namespaces cannot be configured as API-key provider IDs.
- Subscription endpoints are fixed to OpenAI, never classified as on-device, and preserve the current source privacy/token checks. The connected account supplies model choices. Streams require response.completed; partial responses and plan-limit failures are errors.
- Selecting a subscription prevents all API-key fallbacks, including missing credentials, disabled providers, discovery failures and quota errors. Browser previews refuse real plan operations and never fabricate a connection.
- Manage usage opens ChatGPT's controls for plan/credit limits. The provider may use credits enabled in those controls; AXISNotes does not silently switch to separate API-key billing.

## Boundaries / known limits

- Existing Notes privacy rules are retained; this task does not implement the future suite's exact provider/model allowlists or repair its pre-existing missing-rule semantics.
- ID-token verification supports RS256 from OpenAI's published RSA signing keys; an unsupported algorithm fails closed.
- Use Disconnect before removing a connected provider to attempt server-side session revocation. Removing the provider clears local credentials; the registered client can still be managed in ChatGPT Settings.
- UI smoke does not authorize a real account or contact a paid provider. Two ignored native tests and existing build chunk-size/driver-version warnings remain.
