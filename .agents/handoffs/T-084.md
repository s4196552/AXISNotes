# T-084 handoff: welcome-screen ASCII art from the three-cusp star design

## What was built
- `asciiField.ts` now describes the user's design (`.agents/briefs/T-084-reference.svg`):
  the three-cusp star (tips (960,110), (1410,880), (510,880), every side curving through
  (960,620)) sampled as a polygon in a 1920×1080 frame; `starMask` = the reference's
  elliptical radial fade (centre at 58 % of the star's height, stops 1 / 0.85 / 0.35 / 0)
  × a 12-unit smooth edge (the reference's blurred mask); `tintPosition` / `tint` = the
  warm-to-cool gradient (`#d6c7b2` → `#b5ada2` → `#94a0b8` at 26/22/28 %), with a darker
  version of the same hues for light themes; `cover` scales the frame to cover the screen;
  `isLightColour` reads `--fg`; glyphs are letters and digits (a few capitals).
- `AsciiBackdrop.tsx` lays out the visible cells once per size/theme change (batched by
  fill style) and draws them; the text scales with the star like the SVG (12.5 px at
  1920 wide, never below ~7 px). Motion is a slow shimmer: 2 % of the glyphs change every
  120 ms; the star stays still. Unchanged from T-080: decorative, theme changes live, one
  still frame under reduced motion (followed live), paused while hidden, disposed on
  unmount. The theme's own background stays (the SVG's `#111110` fill isn't copied).
