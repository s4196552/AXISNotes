# T-199 handoff: Edit with AI, reviewed change by change

## What was built
- Fix writing has a "Your instruction" mode, also opened from the command palette as "Edit with AI (your instruction)". The edit is reviewed change by change, as Fix writing already does.
- Big rewrites are reviewed line by line, light edits word by word.
- AI blocks opened on a selection get "Review as edit": the answer becomes a reviewed replacement for the selection.

## Files
- `src/features/ai/{FixText.tsx,fixPrompt.ts,AiBlockView.tsx,ai.css}`, `src/lib/diff.ts`
- `src/features/commands/{actions,registry,ui}.ts`, `src/features/editor/Editor.tsx`
- New tests: `src/features/ai/{editWithAi,reviewAsEdit}.test.tsx`

## How to test
- `pnpm exec vitest run src/features/ai/editWithAi.test.tsx src/features/ai/reviewAsEdit.test.tsx`
- In the app: select some lines, run "Edit with AI", type an instruction, untick a change, Apply.

## Known gaps
- The 40-change and half-the-text thresholds for line review are fixed.
