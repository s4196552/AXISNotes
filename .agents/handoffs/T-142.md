# T-142 - Heading colour presets

Built by Claude on agent/claude/T-142 from main b253a1a, at the human's request: "allow users to customize header colors just add preset of color themes".

## Behaviour

- Settings → Appearance → Heading colours: Theme default (as before), Accent, Rainbow, Amber, Ocean, Forest, Berry. Each tile previews H1–H3 in its colours; choosing one recolours every heading (and toggle heading) by level at once, lighter in dark themes.
- Saved as `appearance.headingColors` in `.axisnotes/config.json`; unknown values fall back to Theme default. The note title keeps the theme's heading colour.
