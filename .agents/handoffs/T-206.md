# T-206 — Sidebar AI chat and selection context

## Built

- Added an AI chat tab to the right sidebar, alongside Note details. The chat follows the focused editor and includes its unsaved text. When text is selected, the request contains that passage, and the sidebar shows its exact text. Markdown `==highlights==` are kept in the AI context.
- Added editor right-click actions to ask about the selection or note, or attach it to chat. These stage the context and question for the user's Send action. Copy, cut and paste remain available in the menu.
- Added Ask and Suggest edit modes with the existing provider/model picker. An edit produces a diff with individually rejectable changes. Only Apply approved changes mutates a note. The edit checks the original document and vault and uses the owner edit service, preserving editor Undo and on-disk revision checks.
- Requests retain source references and the strictest privacy floor across the conversation. Native AI planning and execution enforce source policies and model allowlists. Derived edits retain the output's privacy mark. Model choices reuse the device-local AI settings.
- Chat code loads on demand. Hiding the chat cancels its active run. Conversation text stays in memory during the current app session and is cleared when the vault changes.
