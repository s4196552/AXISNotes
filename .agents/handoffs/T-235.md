# T-235 — Rendered diagrams and Quote title

Mermaid diagrams in the Markdown editor render as borderless graphics.
Hovering the graphic exposes its resize handles. Click the graphic to
edit its Mermaid source. Moving the caret outside the block restores
the graphic. The width still saves in the note.

**Ctrl+/** → **Quote** inserts `> [!NOTE] TITLE` followed by
`> Contents` and selects the body placeholder. **Turn into** keeps the
line's text as the body.

The editor regression tests check source visibility, the existing
resize workflow, and the exact Markdown produced by Quote.
