# T-238 — Emoji and icon picker

Type `:` in a note to open emoji, built-in Lucide icons and icons from the
current vault's packs. Search by name and select a result to insert it inline.

**Add icon…** opens the image picker and copies the selected file into the
vault's **My icons** pack. The picker refreshes after importing so the file
can be used again. Existing packs imported through Settings appear under
**Your icons**.

Emoji remain Unicode text. Icons use Markdown image references to either
a built-in Lucide name or an image in the vault's icon packs. Click a rendered
icon to edit its source. The file is served as an image through the existing
vault asset protocol.

Run `e2e/specs/emoji-command.e2e.ts` against the Windows development build.
The native test uses the path a file dialog would return when exercising the
real import command. The pack unit test exercises the **Add icon…** action
with a simulated file chooser.
