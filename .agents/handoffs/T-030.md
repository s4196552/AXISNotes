# T-030 handoff: Web clipper endpoint, image embeds

**Built by:** Claude. **Branch:** `agent/claude/T-030`

## What was built
- `src-tauri/src/clipper/`:
  - `Clipper`: config in `clipper.json`, a pairing code, token hashes, and a request handler that `tests.rs` exercises without HTTP.
  - `tiny_http` server lifecycle.
  - `render.rs`: clip → note path, content and attachment.
- `src-tauri/src/clipper_commands.rs`:
  - Commands `clipper_status`, `clipper_set_enabled`, `clipper_set_folder`, `clipper_start_pairing`, `clipper_cancel_pairing`, `clipper_revoke`.
  - Event `clipper://clipped`.
  - `AXIS_CLIPPER_PORT` override.
- `Vault::write_bytes`. The asset protocol is enabled and scoped to the open vault.
- Frontend:
  - `ClipperSettings` (Settings → Web clipper) and `useClipNotices`.
  - `backend.fileUrl`.
  - `src/lib/attachments.ts` and an image widget in `embeds.ts`.
  - `ImageView` / `UnsupportedView`, and `docKind` gained `image` / `other`.

## How to test
- `cargo test clipper`: 9 tests covering pairing, limits, origin checks, auth, pages, selections, screenshots, dedupe, no vault, bad input, folders, and a real HTTP round trip.
- `pnpm test`: `attachments.test.ts` and the image embed test.
