# T-016 handoff: formula engine and grid view

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-016`

## What was built
- **`src/lib/formula/`**:
  - A Pratt parser with Excel precedence.
  - An evaluator with Excel error values that uses formula.js (MIT) for its functions.
  - `.axgrid` parse and serialize, whole-sheet recalculation with cycle detection, row/column shifting (`#REF!` on delete) and `offsetFormula` for paste.
- **`src/features/grid/`**: the grid view.
  - Row virtualization and sticky headers.
  - Keyboard editing (Sheets-style) and a formula bar.
  - Range selection (mouse drag and Shift) with a sum/average/count readout.
  - TSV copy, cut and paste, plus internal paste with formula offsets.
  - Insert and delete rows/columns, bold and alignment, column resize (double-click to reset), undo/redo, and "Add 100 rows".
- **`src/features/files/`**: `useFileDocument` (load, autosave, conflict and removed handling) and `DocBanner`, which T-017's canvas will reuse.
- **Integration**:
  - `.axgrid` files open in `Grid` and show in the tree without their extension, with a sheet icon.
  - "New grid here" in the tree menu, and a "New grid" command.
- **Rust index**: grids are indexed with their cell text as the FTS body (formulas excluded) and their stem as the title. They are linkable as `[[X.axgrid]]`, get their links rewritten on rename, and are skipped as unlinked-mention sources.
- **Flake fix**: link decorations use the tree returned by `ensureSyntaxTree`.

## Known gaps
- Editing starts from key events, so IME composition can't start an edit directly (press F2 or Enter first).
- There is no point-and-click reference insertion while typing a formula.
- There is no number formatting (currency, decimals) yet.
