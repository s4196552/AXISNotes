# T-198 handoff: Suggest tags, title and links

## What was built
- Command palette: "Suggest tags, title and links" for the open note. A cheap model proposes up to 5 tags (preferring the vault's), a clearer title, and links where the note mentions other notes without linking them.
- Answers are validated, with one retry. Each suggestion has a checkbox; only ticked ones are applied:
  - tags go into the frontmatter;
  - links replace the first plain mention;
  - the title is a rename that updates links.

## Files
- New: `src/features/ai/{suggest.ts,SuggestDialog.tsx,suggest.test.tsx}`.
- Changed: `src/features/ai/ai.css`, `src/features/commands/{registry,ui,Modals}`.

## How to test
- `pnpm exec vitest run src/features/ai/suggest.test.tsx`
- In the app: open a note that mentions other notes by name, run the command, Suggest, untick something, Apply selected.

## Known gaps
- Only the first plain mention of each suggested link is linked.
- Candidates are found by exact name or alias (case-insensitive), not by meaning.
