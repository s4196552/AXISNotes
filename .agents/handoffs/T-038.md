# T-038 handoff: Rename to AXISNotes

**Built by:** Claude. **Branch:** `agent/claude/T-038`

## What was built
- **User-facing names:** "AXISNotes" in `tauri.conf.json` (productName and window title), the UI, the extension and the Rust error messages. About shows "AXISNotes by AXIS".
- **Identifier:** `app.axis.axisnotes`. The old app folders are copied on startup (`src-tauri/src/migrate.rs`).
- **Vault folder:** `.axis/` → `.axisnotes/`, migrated in `Vault::open`.
- **Keychain service:** `AXISNotes`, with a lazy move from `AXIS` (`ai/keys.rs`).
- **Program:** `axisnotes.exe` (Cargo `axisnotes` / `axisnotes_lib`), and the npm name is `axisnotes`.
- **Tests:** 3 new Rust tests (vault folder move, app-folder copy, identifier matches the config).

## How to test
- `cargo test`: 91.
- `pnpm test`: 264.
- `pnpm e2e:build && pnpm e2e`.
- Open a vault that has `.axis/`: it becomes `.axisnotes/`, with its settings kept.

## Known gaps
- The keychain move can't be unit-tested without a real keychain; it runs on the first key lookup.
- The old app folders (`app.axis.desktop`) are left as a backup and can be deleted by hand.
