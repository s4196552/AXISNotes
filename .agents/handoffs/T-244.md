# T-244 handoff — AXIS Hub bento layout

## What was built

- **Featured row.** The first group (Favorites, unless reordered) leads as large coloured
  launch tiles once it has apps: icon top-left, uppercase name and kind bottom-left, menu
  and drag handle in the corner on hover. Up to 8 tiles, then "+N more". An empty first
  group stays in the grid with an add button, so a new library isn't an empty row.
- **Bento grid.** Every other group is a tile: colour dot, uppercase name and count (opens
  the group), menu. Its apps are rounded icons that open with **one click** (before, a group
  was a mosaic you had to open first). Groups inside show as folder icons with four mini
  icons; "+N" opens the rest. A group with one app shows it large; more than four spans
  two columns. The grid ends with a dashed **New group** tile.
- **Right-click edits** whatever is under the pointer: an app icon or launch tile (edit
  shortcut), a group tile or the featured row (edit group).
- **Tile colours come from the app's icon** (its colourful pixels, sampled once per icon);
  apps without an icon keep the palette colour from their name.
- **Group pages** show apps as the same large coloured tiles, and subgroups as bento tiles.
- **Toolbar**: one row with search, sort ("My order"), Group and Add; Library/Packs is a
  small segmented control by the title. In narrow panels the buttons drop their labels,
  tiles go two per row, and wide tiles stop spanning.
- Colours come from the Notes theme tokens (`--cell`, `--cell-stroke`, `--icon-bg`), so
  light and dark both work.

## How to test

`pnpm vitest run src/features/hub` (6 tests). In the app: Home → AXIS Hub widget, or the
right panel's AXIS Hub tab. Click an icon to open it; right-click to edit; drag icons onto
another group; open a group and drag tiles by the corner handle.

## Known gaps

- The featured row is always the first group; there is no separate "pin" flag (the library
  format is unchanged).
- Icon colour sampling reads data-URL icons only (all icons Hub stores are data URLs).
