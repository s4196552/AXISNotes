# T-237 — Typed colon opens the emoji picker

Type `:` at the start of a note line or after a space to open the emoji
picker. Type a keyword to filter the results, then choose an emoji to insert
it. The trigger is configurable in **Settings → Quick commands**.

`src/features/editor/quickCommands.ts` now matches the configured emoji
trigger with an empty or partial query. A command menu explicitly configured
with the same trigger takes precedence where it matches. Times such as
`10:30` remain plain text, and `::status` still completes a property.

Run `e2e/specs/emoji-command.e2e.ts` in a Windows development build to
check immediate activation, filtering, insertion and property completion.
