# T-033 handoff: Onboarding and settings polish

**Built by:** Claude. **Branch:** `agent/claude/T-033`

## What was built
- `src/app/recentVaults.ts`: recent vaults, the reopen-last preference and the one-time "getting started" flag.
- `WelcomeScreen`: recent vaults, an example-notes option and an Obsidian hint. `starterNotes.ts` holds the example notes.
- `GettingStarted` (modal `getting-started`, palette command): shown once for a newly created vault.
- Store: `createVault(parent, name, files)` writes the starter notes. App startup reopens the last vault.
- Remappable shortcuts:
  - `commands/hotkeys.ts` (parse, format, match, override).
  - `registry.shortcutOf` / `commandForEvent` use the overrides.
  - `HotkeysSettings`, and config `hotkeys`.
- Settings: Keyboard shortcuts and About sections, and opening straight to a section (`{ kind: "settings", section }`).

## How to test
`pnpm test`: `hotkeys.test.tsx`, `onboarding.test.tsx`.
