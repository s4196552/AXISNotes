# T-032 handoff: Obsidian import

**Built by:** Claude. **Branch:** `agent/claude/T-032`

## What was built
- `src-tauri/src/import/`:
  - `import_obsidian(vault, source, target)` copies files, never overwrites, reports what it skipped, and reads the Obsidian settings.
  - `canvas.rs`: JSON Canvas → Excalidraw JSON.
  - Tests use a synthetic vault.
- Commands `inspect_import` and `import_obsidian`; the latter rescans the index afterwards.
- `ImportDialog` (palette: "Import from Obsidian…"): pick a folder, preview it, choose the target folder, import, then see the report and optionally adopt the templates and daily-note settings.
- `obsidianSyntax.ts`: styling for `==highlight==`, `%%comment%%` and callouts.

## How to test
- `cargo test import` and `pnpm test` (`ImportDialog.test.tsx`, `obsidianSyntax.test.ts`).
- Phase 6 E2E (T-036) imports a seeded Obsidian vault in the real app.
