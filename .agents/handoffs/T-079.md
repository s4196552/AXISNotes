# T-079 handoff: the logo in Getting Started; its styles load with it

## What was built
- `Logo` has a `decorative` prop that sets `alt=""` (for places where text beside it names the app).
- The Getting Started dialog header shows the pearl logo (18 px, decorative) in place of the rocket icon.
- Getting Started imports `../ai/ai.css` itself (as `DiagramMaker` already does), so its header
  border, padding, right-aligned close button and footer are styled on first open, not only after Ask AI has loaded.
- NewTab: **no logo, by decision.** NewTab is a minimal, Obsidian-style list of three actions seen on
  every empty tab; a logo there would add a large mark to a working surface the user sees all the time.
  The logo already appears on the welcome screen, in About and now in Getting Started.
- Redone on today's `main`: the first version sat uncommitted in `axis-release-0.3.0` (on `agent/claude/T-079`,
  which is still checked out there, so this work is on `agent/claude/T-079-main`). Its empty-main-view part was dropped,
  since T-085 replaced that screen.

## Files
`src/app/Logo.tsx`, `src/features/vault/GettingStarted.tsx`, `src/features/vault/onboarding.test.tsx`.

## How to test
`pnpm dev`, reload, then Ctrl+P → "Getting started" without opening Ask AI first: the header has the logo,
a bottom border and the close button on the right; the footer has a top border.

## Known gaps

  (`src/features/handwriting/HandwritingDialog.tsx`) use the same `ask-ai-header`/`ask-ai-footer` classes
