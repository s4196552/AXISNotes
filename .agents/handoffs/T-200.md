# T-200 handoff: Ctrl+Z / Ctrl+Y in the file tree

## What was built
- An undo and redo history for sidebar actions (`src/features/filetree/undo.ts`):
  - renames and moves;
  - deletes, restored from the OS trash through the new `restore_entries` command;
  - new notes and folders, and pasted copies (taken back only while unchanged);
  - order;
  - icon, colours, AI access and allowed models.
- Batches are one step.
- Keys: Ctrl+Z, Ctrl+Y and Ctrl+Shift+Z, in the tree and wherever focus isn't in text, the editor or a dialog.

## Files
- **Rust:** `vault/mod.rs` (`restore_from_trash`, plus a Windows test that uses the real Recycle Bin), `commands.rs` (`restore_entries`), `lib.rs`.
- **TypeScript:** `filetree/undo.ts` (new), `undo.test.tsx` (new), `FileTree.tsx`, `RowColors.tsx`, `icons/IconPicker.tsx`, `ai/AllowedModels.tsx`, `commands/noteCommands.ts`, `ipc/{types,tauriBackend,memoryBackend}.ts`.

## How to test
- `pnpm exec vitest run src/features/filetree`
- `cargo test vault::`
- In the app: rename, delete and drag in the tree, then press Ctrl+Z and Ctrl+Y.

## Known gaps
- macOS can't restore from the trash through the `trash` crate, so undoing a delete there shows a message instead.
- Renames from the command palette ("Rename file") and changes made outside the sidebar aren't recorded.
- The history isn't kept across restarts.
