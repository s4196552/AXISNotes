# T-201 handoff: AI skill results saved at once, with the AI icon

## What was built
- Skill results are saved straight into the vault, with no draft step:
  - pages go next to the note;
  - Teach files go into the folder (a replaced file goes to the trash first);
  - Grill me is saved after every reply and kept updated;
  - skills on picked files create a note in their folder.
- Each saved file, and each skill folder AXISNotes creates, gets the 🇦🇮 icon.
- Saved files are recorded for Ctrl+Z in the file tree.

## Files
- `src/features/skills/{aiIcon.ts (new),skillRun.ts,skillOnFiles.ts,SkillResult.tsx,skills.ts}`
- `src/features/ai/{AiBlockView.tsx,aiBlockStore.ts}`
- tests: `skills.test.tsx`, `copyable.test.tsx`

## How to test
- `pnpm exec vitest run src/features/skills`
- In the app: run Flash cards in a note. The page appears next to the note with the AI icon, without asking.

## Known gaps
- Ask AI, plain AI blocks and Quick Chat still offer drafts; they aren't skill results.
- If a Grill me file was edited by hand, the next reply overwrites it.
