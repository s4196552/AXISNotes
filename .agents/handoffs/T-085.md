# T-085 handoff: notes as tabs, like Obsidian

## What was built
- **Tab model** (`src/app/tabs.ts`, pure functions): tabs hold a note path and a view
  (note, graph, tasks, time) plus their own back/forward history (50 entries). Open in
  the active tab or a new one (pinned tabs open beside themselves), new / close / close
  others / close to the right (pinned tabs spared), activate, cycle with wrap-around, go
  to N / last, back / forward, reorder, pin, reopen closed (20 kept, empty tabs aren't),
  follow renames (tabs, history and closed list), drop trashed or missing files, and
  save / restore (bad data → one empty tab).
- **Store** (`src/app/store.ts`): `tabs` plus actions for all of the above. `activePath`
  and `mainView` mirror the active tab, so existing callers are unchanged; `openFile` and
  `openLink` take `{ newTab }`; `setMainView` changes the active tab's view (so "back to
  note" in the graph/tasks/time views returns to the tab's note). Tabs are saved per vault
  in local storage (`axisnotes.tabs:<root>`) and restored when the vault opens; tabs for
  files that no longer exist are dropped once the tree is listed.
- **Tab bar** (`src/features/tabs/`): icon (custom icon, else file kind or view), title,
  close button (a pin on pinned tabs), middle-click closes, double-click on the empty
  strip or "+" opens a new tab, drag to reorder (with a drop marker), context menu (Close,
  Close others, Close tabs to the right, Pin/Unpin), ←/→/Home/End between tabs, Delete
  closes. `tablist`/`tab`/`tabpanel` roles. The side-panel buttons sit at the row's ends.
- **New tab** view: Create new note, Open a note, Close tab, with their shortcuts.
- **New-tab opening**: Ctrl/Cmd+click or middle-click in the file tree, middle-click on
  a link in the editor, Ctrl+Enter / Ctrl+click in the quick switcher.
- **Commands** (remappable): New tab Ctrl+T, Close tab Ctrl+W (refuses pinned tabs with a
  notice), Next/Previous tab Ctrl+Tab / Ctrl+Shift+Tab, Go to tab 1–8 Ctrl+1–8, last tab
  Ctrl+9, Go back / forward Ctrl+Alt+← / →, Reopen closed tab, Pin/unpin tab, Close
  other tabs.
- **Editor**: remembers each note's cursor and scroll when its editor closes (this
  session, 200 notes) and restores them on return, unless a link asked for a target.

## How to test
- `pnpm lint && pnpm typecheck && pnpm test`: see the review for results. New: 15 model
  tests and 12 UI tests (bar, keys, shortcuts, pins, menu, custom icon, file-tree clicks,
  renames, trash, restore with pruning, views in tabs, cursor restore).
- Preview: opened Welcome, Ctrl+clicked notes into new tabs, pinned Welcome from the menu,
  Ctrl+G put the graph in the active tab.
- Native E2E (`pnpm e2e --spec e2e/specs/tabs.e2e.ts`, real debug build): 5 passing —
  middle-click opens a tab; Ctrl+Tab, Ctrl+T, Ctrl+W, Ctrl+2; rename follows; pin from the
  menu; tabs, pin and active tab come back after the front end reloads. Screenshots in
  `.agents/qa/T-085/`.

## Known gaps
- Switching tabs remounts the editor: cursor and scroll come back, **undo history
  doesn't** (Obsidian keeps it). Keeping every tab's editor alive would cost memory.
- Graph, tasks and time report open in the active tab rather than their own tabs.
- No split panes, tab groups or stacked tabs.
- Restoring after a *real* restart isn't covered by E2E: each WebDriver session gets a
  fresh WebView2 profile, so local storage starts empty there (checked with a sentinel
  key). The reload test covers the same restore code.
- Opening the same note in two tabs gives two independent tabs (as in Obsidian).

## Decisions for the lead
- "Reopen closed tab" has no default shortcut: Obsidian's Ctrl+Shift+T is already "Open
  tasks". Remap either in Settings → Hotkeys.
