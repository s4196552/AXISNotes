# T-022 handoff: AI settings UI

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-022`

## What was built
- **IPC**: AI types and the `ai*` backend methods. The Tauri backend streams `ai://delta`, filtered by run id.
- **`src/ipc/memoryAi.ts`**: an in-memory mirror of the Rust rules (privacy, keys, task defaults, fallback, token cap, log) that streams an echo answer, for tests and browser dev.
- **Settings → AI** (`src/features/ai/AiSettings.tsx`):
  - Providers: add, rename, enable/disable, remove. There is an endpoint field, a key field (password input that is write-only, with keychain status shown), and "Test connection".
  - Models per task: a provider, plus a model picked from the live list. Handwriting warns when the model can't read images.
  - Fallback order: add, reorder, remove.
  - Effort and limits: default effort, the confirm threshold and the token cap.
  - Folder privacy rules, written to the vault's `.axis/config.json`.
  - Request log: a toggle and a table of recent requests.
- **File tree**: the context menu offers "AI access: inherit / never / local models only". Folders and files with a rule get a badge (a lock for never, a drive icon for local-only) with a screen-reader label.

## How to test
- `pnpm test`: 173 tests, including AiSettings (5) and the file tree AI rule (1).
- Manual: in `pnpm dev`, open Settings → AI.

## Known gaps
In browser dev mode, providers "answer" with an echo; only the desktop app calls real providers.
