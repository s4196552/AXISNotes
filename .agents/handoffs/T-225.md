# T-225 — Ctrl+Shift+Q for the whole note

Implemented in isolated `.worktrees/T-225`, branch `agent/codex/T-225`, based on main `9978504`. Assigned-agent verification is complete; status **approved**. No merge, publication, release bump or installation was requested or performed.

## Behaviour and changes

- Ctrl+Shift+Q expands every collapsed block in the active note if any are closed; with everything open, it collapses all foldable blocks, including nested and offscreen headings/lists. Ctrl+Q retains its existing nearest-block/sidebar behaviour.
- Registry command `toggle-page-folds`, labelled “Expand or collapse all blocks in current note,” appears in the palette and Hotkeys settings with the normal remapping support. The platform modifier is Cmd on macOS. Repeat keydown events are ignored.
- `contextFold.ts` targets the active note pane even from an embedded editor or sidebar. It ignores input fields, dialogs and disconnected views. Other panes and embedded source notes are independent and are not rewritten by the page command.
- `toggles.ts` batches persisted toggle/callout markers in one independently undoable edit, maps ordinary fold coordinates after marker insertions, and moves a hidden selection to its enclosing title when collapsing. Ordinary heading/list/code folds remain view state. Read-only toggle effects can now flip multiple blocks in one transaction without modifying text.
- `foldArrows.test.ts` and `contextFold.test.ts` cover mixed state, nested headings/lists/code, implicit markers, coordinate mapping, Undo, read-only views, offscreen outline blocks, pane targeting and focus exclusions. `context-fold.e2e.ts` retains both original Ctrl+Q scenarios and adds native whole-page keyboard/palette, marker persistence and embedded-source preservation checks.

## Limits / handoff

This is the active note's own content, not a recursive edit to embedded references or other tabs/sidebar sections. Markdown headings/lists/toggles use full-document structure.
