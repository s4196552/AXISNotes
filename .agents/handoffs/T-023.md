## What was built
`src/features/ai/AskAi.tsx` is the Ask AI dialog. Open it with Ctrl+J, the "Ask AI about this note" command, or the ✦ button in the note header.
- **Context:** the open note is attached by path (Rust reads it, so the folder's privacy rule always applies). An editor selection is sent as quoted text and declared as a source.
- **Before sending:** a live destination line shows the provider, model, a badge when it runs on this device, the estimated input tokens and cost, and a note when the notes are local-only. Requests above the confirm threshold ask first.
- **While and after running:** the answer streams with a Stop button (which cancels in Rust). The result line shows which provider and model answered, the token counts, and whether a fallback was used. The answer can be copied, inserted at the cursor, or appended to the note.
- **Refusals:** blocked requests show "Not sent: …". The authoritative refusal comes from the run, so it is recorded in the request log.

## How to test
- `pnpm test`: 177 tests, including Ask AI (4).
- Manual: in `pnpm dev`, add an Ollama provider in Settings → AI, open a note, and press Ctrl+J (browser dev echoes the question back).

## Known gaps
- Answers are shown as plain text, not rendered Markdown.
- The dialog holds one question and answer at a time; it isn't a chat history.
