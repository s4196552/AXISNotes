# T-241 — Markdown editing interactions

- Click the copy button in the top-right corner of a fenced code block. The
  **Copied** popup appears for 1.5 seconds after a successful clipboard write.
- Left-click a rendered Mermaid diagram to select it and reveal its resize
  handles. Hold the left button on the diagram or a handle to show horizontal
  and vertical lines that follow the pointer. Drag a handle and release to save
  the width in the Mermaid fence. Double-click the diagram to edit its source.
- Insert or turn a line into a Quote using the command menu. The caret lands
  immediately after `TITLE`, ready for typing.

The changes are in the Mermaid preview and resize code in `src/features/diagrams`
and the Markdown live preview, editor styles and Quick Commands in
`src/features/editor`. Run the Code Copy, Markdown Editing and Phase 5 E2E specs
against the Windows Tauri build. See the [review](../reviews/T-241.md) for the
verification results.
