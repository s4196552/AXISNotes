# T-091 handoff: icon and image packs

## What was built
- **Rust (`packs.rs`)**: `list_packs`, `import_pack(kind, source)` (a folder or `.zip`) and
  `remove_pack(kind, name)`. Packs are flat folders of images in
  `.axisnotes/packs/{icons,images}/<Pack>/`, named after the source (`Name 2` if taken).
  Import keeps images only, SVGs only for an icon pack that has them, the shallowest copy
  of a repeated name; skips images over 25 MB; refuses packs over 10,000 images or 500 MB.
  Zip entries use their base name only (no escapes) and are size-checked while reading.
  Staged in a hidden folder and renamed into place. One-colour icon packs are marked in
  `.pack.json`. The packs folder is added to the asset-protocol scope by name.
- **Icon picker**: a Packs tab with a section per icon pack (search by file name, paging),
  colour swatches, and "Add an icon pack: From folder… / From .zip…". One-colour icons are
  shown and saved in the text colour (`color: currentColor`) unless a colour is picked.
- **Cover gallery**: a section per image pack under Gradients and Colours, plus adding one.
  Covers point at pack images directly (they aren't in the file tree).
- **Image icons with a colour** are drawn as a tinted silhouette (CSS mask), so pack icons
  match the file tree and the page header.
- **Graph view** (T-092's canvas icons, `src/features/graph/nodeIcons.ts`): a coloured image
  icon is drawn as a tinted silhouette (offscreen canvas, cached per power-of-two size), with
  `currentColor` meaning the graph's icon colour.
- **Settings → Icon & image packs**: lists packs with a preview and count, Remove (to the
  trash), and adding packs.
- The in-memory backend offers sample packs in the browser preview.

## How to test
Icon picker → Packs → From folder… (choose a folder of SVGs) → pick an icon, with and
without a colour. Add cover → Gallery → From .zip… → pick a picture. Settings → Icon &
image packs → Remove. `cargo test packs`, `pnpm exec vitest run src/features/packs`,
`pnpm e2e --spec e2e/specs/packs.e2e.ts`.

## Known gaps
- Covers that use a pack image don't show in Obsidian (it ignores dot-folders).
- Packs can't be renamed or edited in the app; edit `.axisnotes/packs/` directly. Changes
  made there outside the app show the next time a picker opens.
- Removing a pack leaves icons and covers that used it blank (the default icon shows).
- Multi-colour SVG packs can't be recoloured (they keep their own colours).
