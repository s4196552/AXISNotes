# T-082 handoff: every Lucide icon in the icon picker, in any colour

## What was built
- `icons/lucideAll.ts` re-exports lucide-react's `icons` namespace; `loadAllIcons()` in
  `iconSet.ts` imports it once on demand (its own ~594 kB / 157 kB gzip chunk) and can be
  retried after a failure. `lucideFor` resolves curated icons at once and the rest once
  loaded; curated aliases (`Home`, `DollarSign`) keep working.
- Word search: `iconWords` (`FlaskConical` → `flask conical`, `Grid2x2Check` →
  `grid 2x2 check`) and `matchesIcon` (every typed word starts a name word).
- Icon picker: "Suggested" (the curated 44) then "All icons" in pages of 240 with
  "Show more (N left)"; loading text; an error with "Try again". A custom colour input
  (rainbow swatch) beside the preset swatches; any hex is stored as before.
- `EntryIcon` loads the full set for a non-curated name and takes a `fallback`; the file
  tree passes its default file/folder icon, used while loading or for an unknown name.

`src/features/icons/{lucideAll.ts,iconSet.ts,iconSet.test.ts,IconPicker.tsx,EntryIcon.tsx,

## How to test
- `pnpm lint && pnpm typecheck && pnpm test`: passed (399 tests). New: name splitting and
  matching, curated vs full-set lookup (loaded once), picker shows 240 + "Show more",
  word search finds `Rabbit`, custom colour saved, unknown name falls back.
- Build: main chunk 700.30 kB → 699.63 kB; `lucideAll` 594.01 kB (gzip 156.53 kB).
- Preview: right-click a folder → Change icon… → search "fish" → five Lucide fish icons;
  custom colour #ff8a00 → choose Fish → the folder shows an orange fish.

## Known gaps
