# T-025 handoff: Offline spellcheck

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-025`

## What was built
- `src/lib/spelling.ts`: picks the prose words in a line. It skips code, links, tags, URLs, emails, block ids, math, template variables, paths, CamelCase, ACRONYMS and words glued to digits.
- `src/features/spellcheck/`:
  - `engine.ts`: the `Speller` interface, `createEngine` (nspell) and a worker-backed singleton. Without a Worker (in tests) it uses `noSpeller`.
  - `speller.worker.ts`: loads the bundled `dictionary-en` files, reached through the Vite alias `dictionary-en-files`.
  - `spellcheck.ts`: the CodeMirror plugin. It checks visible ranges only, caches results, skips syntax nodes and frontmatter, and underlines with `.cm-misspelled`. The quick-fix tooltip menu (suggestions / Add to dictionary / Ignore) opens on right-click or Ctrl+.
  - `index.ts`: `configuredSpellcheck()` reads `.axis/config.json` → `spellcheck`.
- Editor: added a compartment that follows the on/off setting, and re-checks when the personal dictionary changes.
- Settings: a new Spelling section with the on/off toggle and the personal dictionary list (remove words).

## How to test
- `pnpm test`: new tests in `src/lib/spelling.test.ts` and `src/features/spellcheck/spellcheck.test.ts`. They run against the real en_US dictionary.
- `pnpm dev`: type a misspelling, right-click it and choose a suggestion.

## Known gaps
- English (US) only.
- Words in the personal dictionary are matched case-insensitively.
