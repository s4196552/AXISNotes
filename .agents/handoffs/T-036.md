# T-036 handoff: Phase 6 E2E and polish

**Built by:** Claude. **Branch:** `agent/claude/T-036`

## What was built
- `e2e/specs/phase6.e2e.ts` (5 tests) plus the `phase6` seed in `wdio.conf.ts`. The seed creates a sibling Obsidian vault in `AXIS_E2E_OBSIDIAN` and uses clipper port 38499.
- `e2e/tsconfig.json` has `allowJs`, so the spec can import `extension/lib/queue.js`.
- Escape reaches the open dialog even after focus has been lost (`Modals.tsx` `useEscapeWithoutFocus`), with a unit test.
- Spellcheck parses the visible range first and re-checks when the syntax tree updates.
- JSON Canvas import: text and link nodes become cards with bound text, and arrows are bound to both ends.
- Image files have an icon in the file tree.
- Test hardening: the Mermaid preload, the spellcheck wait and the graph-count selector.
