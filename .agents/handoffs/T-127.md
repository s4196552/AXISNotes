## Built

- A visible pencil button in the left sidebar toolbar renames the selected file or folder. F2 and the context menu remain available. The button is disabled when no valid item is selected or a rename is already active. Existing Enter/blur commit and Escape cancellation, extension preservation, backend validation and safe rename/link updates remain in charge.

## How to use / reproduce

Select a file or folder and click the pencil button (or F2 / right-click Rename). Drag a row to the middle of another folder to move it, to a row edge to reorder, or to the empty space below the tree to move it to the vault root. Escape cancels. Run pnpm lint, pnpm typecheck, pnpm test -- --maxWorkers=4, cargo test --manifest-path src-tauri/Cargo.toml, then the real desktop build and WDIO --spec e2e/specs/sidebar.e2e.ts.
