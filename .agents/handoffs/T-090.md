# T-090 handoff: Turn into, toggle headings and descriptions

## What was built
- **Descriptions:** every command has one line under its label (`description` on each
  command; custom commands show the text they insert). Each row is a grid: an icon tile, the
  label (plus "Turn into"), the description, and the Markdown hint on the right.
- **New blocks and Turn into:** commands with a `block` (Text, Heading 1–3, lists, Task,
  Toggle list, Quote, Callout, Code block, Toggle heading 1–3) start a new line under a line
  with text, or replace an empty line (a bare `- ` counts as empty). While a query is typed on
  a line with text, each is followed by "Heading 1 · Turn into" etc., which rewrites the line
  keeping its text (block Markdown such as `#`, `- [ ]`, `>` or a toggle head is swapped).
- **New commands:** Text, Toggle list, Toggle heading 1–3 (Basic blocks).
- **Toggles** (`toggles.ts`): `> [!toggle|hN]± Title`. A view plugin draws the ▸ arrow (it
  rotates when open), the heading size and the indented inside; the Markdown shows only on a
  focused title line. Clicking the arrow flips `+`/`-` in the note. A state field hides a
  closed toggle's inside (atomic for the cursor) unless the selection is in it. Ordinary
  callouts can now carry `|metadata` too, and toggles are left out of callout styling.
- `lucideSvg()` takes a size, for the small arrow in toggle-heading icons.

## How to test
Ctrl+/ on an empty line: sections with descriptions. On a line with text, type `head`:
Heading 1, Heading 1 · Turn into, Heading 2, … Pick a toggle heading, type a title, press
Enter for a line inside, then click the arrow to close and reopen it.

## Known gaps
- Toggles are drawn only in the editor; hover previews and embeds that render Markdown
  elsewhere show them as plain quotes.
- A closed toggle hides its inside only while it's closed in the file: it can't be closed
  for one viewer without changing the note.
- No keyboard shortcut to open or close a toggle yet (click the arrow, or edit `+`/`-`).
