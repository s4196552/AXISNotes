# T-223 — AI skill result destinations

Human-requested 2026-11-10; verified 2026-11-11 (Sydney). Implemented in `.worktrees/T-223` on `agent/codex/T-223`, based on `9978504`. Status: **approved** by the assigned builder's own verification. No merge, release or installation is included.

## What changed

- Every AI skill offers **Results in: Note / Sidebar / Side view**, independently of Markdown/HTML/Both. The last destination is remembered per vault on this device. Ordinary AI prompts retain their existing interface.
- Note retains explicit Insert/Replace/Review controls. Saved HTML now has an interactive preview using the existing vault-page protocol, opaque-origin sandbox and native network policy; raw generated HTML is never inserted into the app DOM.
- Sidebar has a lazy-loaded Skill results tab, live Markdown/conversation output and HTML preview, saved page/lesson actions, copy and source navigation. Multiple runs remain selectable across note navigation. Returning to the source activates its existing tab or opens a new one without replacing another note. Source/model selection, follow-up prompts and insertion stay in the source AI block. Changing away from Sidebar closes that result tab; direct editor AI-chat actions switch correctly to chat.
- Side view saves Markdown as a unique, AI-marked, privacy-marked note, or uses the existing saved HTML/lesson/conversation, and opens it beside the source. Repeated opens reuse the file and pane. Conversation replies reuse their saved transcript and pane. A pane the user navigated elsewhere is preserved; the next reply gets another pane. The source editor and its unsaved text remain mounted.
- Save failures retain results and existing retry controls. Late completed requests cannot save/open results after a vault switch. The existing native backend remains responsible for source/model access. No dependencies, native commands, permissions, AI providers, background workers, vault formats or release manifests were added.

## Limits and decisions

Sidebar results/unfinished AI blocks are session state, retained while navigating notes; they are not a new durable chat store. Existing HTML, lesson and transcript saves remain durable, and side-view Markdown is saved explicitly as a separate result. Discarding/closing a source block discards its transient result state. HTML uses the existing local-page restrictions and Open page/Open in browser fallbacks; browser-demo previews remain subject to the existing page support. Follow-up controls stay with the source block. No live provider quality, mobile/macOS/Linux UI or hosted CI is claimed. No source-library changes, user vault/settings edits, installation, push, merge or publication. No lead decision is required for this scoped implementation.
