# T-088 handoff: icons and Markdown hints in the command menu

## What was built
- Every command in the Ctrl+/ menu has a Lucide icon (Heading 1–3, list, numbered list,
  task, quote, code, table, divider, callout, link, embed, template, diagram, Mermaid,
  handwriting, date, due date, priorities, time, page styles; custom commands get a bolt).
  The options use a new `command` completion type whose CodeMirror glyph (the key) is hidden.
- The Markdown equivalent shows on the right in monospace: `#`, `##`, `###`, `-`, `1.`,
  `- [ ]`, `>`, ```` ``` ````, `|`, `---`, `> [!note]`, `[[`, `![[`, ```` ```mermaid ````,
  `📅`, `⏫`, `🔼`, `🔽`. Descriptions such as "AI or outline" stay next to the label.
- `lucideSvg()` renders a Lucide icon once into a detached React root and clones the SVG
  after that, so CodeMirror's plain-DOM menu can show the same icons as the rest of the app.

## Files
`src/features/editor/quickCommands.ts`, `src/features/editor/lucideSvg.ts` (new),
`src/features/editor/theme.ts`, `src/features/editor/Editor.tsx`,
`src/features/editor/triggers.test.ts`

## How to test
Open a note, press Ctrl+/ and look at the menu; type `hea` to see Heading 1–3 with `#`,
`##`, `###` on the right. `pnpm exec vitest run src/features/editor/triggers.test.ts`.

## Known gaps
- The menu's order is unchanged (CodeMirror's alphabetical order when nothing is typed);
  there is no Notion-style "Filtered results" header or grouping.
- In the preview's browser automation, a synthesised Ctrl+/ key press didn't reach the
  editor, so the menu was opened with a dispatched keydown; the shortcut itself is unchanged.
