## Behaviour and ownership

- The same per-vault logo now updates the running main window's native icon, which Windows uses for window/taskbar branding. Applies on startup/reload, vault changes and logo changes; reset and missing-image fallback use AXIS Original. Includes both bundled designs and uploaded images. The settings description now explains both surfaces.
- `src/app/windowLogo.ts` decodes only a declared bundled asset or validated vault image into a proportion-preserving, padded **256×256 RGBA** bitmap. Stale decodes are ignored on cleanup; missing/unreadable images fall back to the original. Native failures are reported through the app's existing notice mechanism. The browser demo skips native updates.
- `src/App.tsx` owns one effect keyed by logo and vault root. No polling, watcher, worker or model is introduced.
- `src/ipc/{types,tauriBackend,memoryBackend}.ts` expose the operation through the existing Backend interface. The desktop implementation validates the fixed pixel count, uses Tauri's `Image.new` and window `setIcon`, and closes the temporary native image resource in `finally`. Existing core image/resource permissions already support allocation/cleanup, without image-decoder features or dependencies.
- `src-tauri/capabilities/default.json` adds only `core:window:allow-set-icon` to the existing main-window local capability. No remote access, filesystem capability or Rust command is added.
- `src/app/windowLogo.test.ts` covers bounded conversion, stale completion suppression, missing-image fallback and native error reporting. `e2e/specs/logos.e2e.ts` and the read-only `e2e/window-icon.ps1` probe verify the actual Windows icon bitmap, using WM_GETICON and window-class fallback handles. The probe never destroys the app-owned HICON.

This updates running-window branding. It preserves the application identifier, executable resources, installed shortcut files and package icons. Windows may keep pinned/static shortcut artwork cached from the installer; no claim is made that existing `.lnk` files are rewritten. Other platforms' native icon behaviour is unverified; their in-app logo support remains T-218's.
