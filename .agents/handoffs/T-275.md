# T-275 handoff: Customizable sidebars and Favorites

## What was built

- **Panel placement** (`src/app/sidebarLayout.ts`): every sidebar panel has a stable id (`favorites`, `files`, `search`, `tags`, `hub`, `calendar`, `outline`, `graph`, `backlinks`). The vault config keeps `sidebars: { left, right, hidden }`; `normalize` drops unknown or repeated ids and puts any panel missing from all three lists (one a later version adds) at its default place. Pure helpers move, place and remove panels; `updatePlacement` saves through `useConfig.update`. Section fold state stays a device preference under the old `axisnotes:right-panel-sections` key, now for every section.
- **Sidebars** (`src/features/panels/Sidebars.tsx`): the left sidebar keeps its tab strip for the full-height panels placed there (Files, Search, Tags, Hub) and shows any stacked panels placed there as folding sections between the tabs and the tab's body (Favorites by default). The right sidebar's Note details shows every panel placed there as a folding section, in order; a full-height panel placed there grows into the free space. The rules for when a panel shows are unchanged (no calendar on Home, outline and graph for notes, links for notes/grids/canvases, Hub when enabled). Backlinks now has its own folding heading.
- **Customizing** (`panelCustomize.ts`, `PanelMenus.tsx`): drag a tab or section heading to reorder it or drop it on the other sidebar (pointer drag through `usePointerDrag`, as the ribbon does; both sidebars draw the drop mark from one shared store). Keyboard: Alt+←/→ on tabs, Alt+↑/↓ on section headings; Shift+F10, the menu key, right-click or the ⋯ button open the panel's menu (Move up/down, Move to the other sidebar, Remove panel). Focus follows a moved panel, also across sidebars. Each sidebar has an Add panel button (left: in the header; right: after its tabs) listing removed panels, the other sidebar's panels ("Move X here") and Reset sidebar layout.
- **Commands that show a panel** (`store.setLeftPanel`, `store.search`) now call `showPanel`, which finds the panel wherever it sits, opens and unfolds it, and brings a removed panel back to its default sidebar.
- **Favorites** (`favorites.ts`, `favoriteActions.ts`, `FavoritesPanel.tsx`): `favorites: string[]` in the vault config. File-tree context menu: Add to favorites / Remove from favorites (and "Add N items to favorites" for a multi-selection). Palette: "Add open file to favorites", "Remove open file from favorites", "Show favorites". A click opens a file (Ctrl+click in a new tab); a folder opens in the file tree, expanded (`revealPath`, which also waits for a tree that is just being shown). Drag or Alt+↑/↓ reorders; × removes. Renames and moves made in the app carry favorites along (`remapIcons`); a deleted favorite stays listed as missing, so undoing the delete restores it, and it can be removed.

## Known gaps

- Renames made outside the app (another editor) don't update favorites, like icons and colours today; such favorites show as missing.
- The demo (browser) backend keeps the config in memory, so the preview resets on reload; the desktop app saves it to `.axisnotes/config.json`.
- The right sidebar's own AXIS Hub tab is unchanged; the Hub panel can also be placed as a section.
