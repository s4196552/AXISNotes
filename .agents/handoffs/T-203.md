# T-203 handoff: Middle-click opens in a new tab everywhere

## What was built
- `openOnClick` (`src/lib/openClick.ts`): a click opens here, while Ctrl/Cmd+click or a middle-click opens a new tab, with no auto-scroll.
- Applied to:
  - search results, backlinks and unlinked mentions;
  - the tasks view, canvas note cards, the timer chip, calendar days and dashboard source lines;
  - `[[links]]` in rendered text (including AI answers);
  - graph nodes (auxclick on the hovered node);
  - folders that have a dashboard.

## Files
- `src/lib/openClick.ts` and `openClick.test.tsx` (new)
- Panels: `SearchPanel`, `BacklinksPanel`
- Views: `TasksView`, `InlineText`, `NoteCard`, `TimerControls`, `Calendar`, `Dashboard`
- `FileTree`, `graph/useSigma.ts`, `graph/GraphView.tsx`

## How to test
- `pnpm exec vitest run src/lib/openClick.test.tsx`
- In the app: middle-click a search result, a backlink or a graph node; each opens in a new tab.

## Known gaps
- The quick switcher and the command palette use Ctrl+Enter, not the mouse.
- Outline headings jump within the same note, so they don't open new tabs.
