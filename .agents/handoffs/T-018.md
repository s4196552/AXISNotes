# T-018 handoff: tasks

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-018`

## What was built
- **Rust** (`index/tasks.rs`): a task parser for the Obsidian Tasks emoji format and a `tasks` table (index schema v2), exposed by the `list_tasks` command.
- **`src/lib/tasks.ts`**: a TS mirror of the parser, `findTasks`, and `setTaskDone`, which adds or removes the `✅` date. The in-memory backend implements `listTasks` with it.
- **`src/features/tasks/`**: the vault-wide tasks view.
  - Tasks are grouped as Overdue / Today / Next 7 days / Later / No date / Done.
  - Filter by text, `tag:` or `path:`.
  - Priority and due badges.
  - Clicking a task's note opens the note at the task's line.
- **Toggle**: checking a task edits its note through `editNote`. It refuses to edit a line that changed since the list loaded.
- **Entry points**: a sidebar button, "Open tasks" (Ctrl+Shift+T), and the `/` commands "Due date" and "Priority: high/medium/low".

## How to test
- `pnpm test`: 156 tests, including lib tasks (4) and TasksView (5).
- `cargo test`: 40 tests, including task parsing (2) and task indexing (1).
- Manual: in `pnpm dev`, open Tasks from the sidebar (the demo `Personal/Todo`).

## Known gaps
- There are no recurring tasks, start or scheduled dates, or custom statuses (`[-]`).
- Due dates are entered as text; there is no date picker.
