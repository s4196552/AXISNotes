## Reproduction and final correction
The first native run had 3 passes / 1 failure: the narrow table expanded CodeMirror's flex content to 748px in a 720px viewport; scrolling occurred on the entire note. Diagnostic widths and the before screenshot confirmed this. Inline-size containment on the table widget prevents its minimum width from contributing to the editor's intrinsic width. The rebuilt app passes the original strict layout assertions, including editor scrollWidth <= clientWidth + 1. The earlier failure is retained as evidence rather than waived.

To reproduce: use the installed local tools for pnpm lint/typecheck/test (four workers), cargo test --manifest-path src-tauri/Cargo.toml, build the desktop shell, and run WDIO with --spec e2e/specs/media-tables.e2e.ts.
