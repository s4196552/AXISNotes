# T-089 handoff: Notion-style sections in the command menu

## What was built
- `COMMAND_GROUPS` in `quickCommands.ts` puts every built-in command in one section, in
  order: Basic blocks (headings, lists, task, quote, code, table, divider, callout), Links,
  Insert (date, time, due date, priorities, template), Diagrams and pen, Page style, and
  Custom for the user's own commands. Within a section the set order is kept (a `boost`).
- With text typed, every match goes under "Filtered results", ranked by match quality.
  `validFor` only reuses a result while "something is typed" stays the same, so the layout
  switches on the first letter and back when the text is deleted.
- Section headers are styled as small muted labels without CodeMirror's default rule.

## How to test
Ctrl+/ in a note: headers and order as above. Type `head`: "Filtered results" with
Heading 1–3. Backspace to empty: the sections return.

## Known gaps
- A command missing from `COMMAND_GROUPS` falls into Custom; a test checks every built-in
  command is listed exactly once.
