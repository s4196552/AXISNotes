# T-243 handoff — Remaining review findings

## What was built

- **Folder/file copy** (`src-tauri/src/vault/mod.rs`): the destination is made
  with `create_dir` / `create_new` first, so anything that appears there meanwhile
  is never overwritten or removed; only a half-made copy this call created is
  cleaned up. The copy-into-itself check compares canonical paths
  (`same_or_inside`), with a lower-case fallback on Windows/macOS.
- **Claude search** (`mcp/tools.rs`, `index/search.rs`): `search_notes` reads
  500 hits, then 2,000, 8,000 and at most 32,000 until it has enough notes Claude
  may see or the index has no more. `Index::search_up_to` is `search` without the
  500 cap; the app's own search keeps the cap.
- **Skills on picked files** (`skillOnFiles.ts`): notes' own `ai-access` marks
  count when leaving out "never" notes (as `folderScope` does), and whether a
  picked path is a folder comes from the file tree (name-based guess only for
  paths not in it). This also decides Teach me's eligibility and the run's label.
- **Files skills** (`skills.ts`): picking Markdown or HTML for a files skill with
  no `## Format:` section adds an instruction about which kinds of file to write
  and to keep replying with the JSON object.

## How to test

`cargo test` (new: `search_finds_shared_notes_ranked_below_many_hidden_ones`;
the copy test covers `school/Week 1`) and `pnpm test` (new skills tests).
In the preview: create `School/Biology 2.0/Week 1.md`, right-click the folder,
run Practice test; the note is saved in `School/Biology 2.0`.

## Known gaps

The copy race fix is structural; there is no automated test that injects a
folder between the name check and creation.
