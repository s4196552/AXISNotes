# T-146 - Zen mode

Built by Claude on agent/claude/T-146 from main b6cce79, at the human's request: a Zen mode that makes the note page full screen and closes all bars and the top bar unless the pointer hovers near the top, left or right, like Zen Browser.

## Behaviour

- Turn on with F11, the command palette ("Zen mode"), or the expand button left of the right-panel button in the tab row. The window goes full screen; only the note shows.
- Pointer at the left/right edge → that side panel slides in over the note; at the top → the tab row and window buttons slide down, with a Leave Zen mode button. Each hides 350 ms after the pointer leaves (32 px slack), but stays while a menu/dialog is open or while typing in it.
- Leave with F11, the palette, or the button on the revealed tab row. Panels come back docked as before.

`pnpm vitest run src/app/zen.test.tsx`. In the app: F11, then move the pointer to each edge.

## Known gaps

Native full screen (Tauri `setFullscreen` + the new capability) is only exercised by the release build and the installed app, not by the browser preview, which blocks full screen. No WDIO run. F11 is a default shortcut; it can be remapped in Settings → Keyboard shortcuts.
