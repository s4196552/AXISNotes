## Behaviour

- Inline backtick and fenced Markdown stay ordinary editable, autosaved Markdown.
- Ctrl+/ offers Inline code, Code block and 13 common language choices (including Python, Java, JavaScript, TypeScript, C/C++/C#, Rust, HTML/CSS, JSON, SQL and Bash). Turn into preserves current-line text for blocks.
- Command palette has Insert inline code and Insert code block. Selections are preserved inside the wrappers, fence lengths escape embedded backticks, empty insertion places the cursor inside, and undo is one edit.
- Opening backtick/tilde fences offer language suggestions using the existing lazy CodeMirror catalogue. Closing fences and fence-looking text inside code do not suggest languages. Typed language aliases and uppercase names use the existing parser matching.
- Syntax colours distinguish keywords, strings, comments, numbers, functions and types. CSS variables support custom themes and light/dark/high-contrast defaults. No dependencies added.
