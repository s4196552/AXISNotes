# T-140 - Obsidian-style code blocks; one Code block command

Built by Claude on agent/claude/T-140 from main a3bb20d, at the human's request: remove every code command but Inline code and Code block, fix the two Code block rows in the command menu, and highlight code like their Obsidian screenshot.

## Behaviour

- Command menu: only **Inline code** and **Code block** (plus Mermaid diagram) for code. Code block shows once (no Turn into row), and leaves the cursor after the opening fence for the language; Enter then goes into the block.
- Syntax colours work (they never rendered before: class-only highlight rules had no CSS). One Dark / One Light palette: purple keywords, green strings, grey italic comments, orange numbers, blue functions and variables, red defined functions/classes, yellow types/builtins, cyan operators.
- Away from the cursor a code block is a rounded box with its language name top-right, hidden fence lines and indent guides; with the cursor inside, the fences show for editing.

## Known gaps

Java class names (`public class Foo`) colour as variables, not red as in the screenshot: the Java grammar tags them like any declared name. Python builtins such as `print` and `str` colour as ordinary calls/names. The updated native WDIO spec was not run. Vault configs that disabled a removed `code-<language>` command keep the harmless id.
