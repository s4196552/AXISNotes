# T-064 handoff: Hide/show side panels from the main area

**Built by:** Claude. **Branch:** `agent/claude/T-064` (from `main` at 9a9baaa). **Requested by:** the human ("add a button on the middle main section to hide section on the left and right side").

## What was built
- **The button:** a small button at the top right of the main area (`SidePanelsButton` in `src/App.tsx`).
  - With either side panel showing, it hides both. With both hidden, it brings both back.
  - Its tooltip shows the current shortcut. While the panels are hidden it is highlighted (`aria-pressed`).
- **Commands:**
  - `toggle-side-panels` (`Ctrl+\`, remappable).
  - `toggle-left-panel` and `toggle-right-panel`, with no default shortcut.
- **`src/app/layout.ts`:** which panels show. It's a per-device preference kept in local storage (`axisnotes.layout`), like zoom; it's not stored in the vault.
- **Shell:**
  - The grid columns follow the visible panels.
  - The left panel is hidden, not unmounted, so the file tree and search keep their state.
  - The right panel (calendar, live local graph, backlinks) is unmounted while hidden, so it does no work.
- **Store:** `setLeftPanel` and `search` bring the left panel back, so Ctrl+Shift+F, "Show files" and similar commands are never invisible.
- **Graph redraw:** `src/features/graph/useSigma.ts` now watches its container with a `ResizeObserver`, at most one redraw per frame. Before, the full graph only refit on window resizes, so toggling the panels left it the wrong width. This came from Codex review finding 1.
- **Tooltip:** the button re-renders when hotkeys are remapped, so its tooltip always shows the current shortcut, or none if the shortcut is removed. This came from Codex review finding 2.
- **CSS:** headers in the main area (`.editor-header` and `.graph-toolbar`, which also covers the canvas, grid, tasks and time views) leave 52 px on the right for the button.
