# T-139 - Marks close as you type; Ctrl+B, Ctrl+I and formatting commands

Built by Claude on agent/claude/T-139 from main 049ff76, at the human's request: typing `` ` `` should add the closer with the cursor between, the same for bold, italic and code; Ctrl+I italic and Ctrl+B bold by default; the cursor between `*`, `**`, `` ` `` and ``` ``` ```.

## Behaviour

- Typing `` ` `` or `*` gives `` `|` `` / `*|*`. Again in an empty pair: `**|**`, ``` ``|`` ```, then `***|***`/``` ```|``` ```. ``` ``` ``` alone on a line becomes a code block with the cursor after the opening fence (for the language).
- Typing the mark at the closer steps over it (all of `**`). With a selection, `` ` `` or `*` wraps it and keeps it selected.
- Out of the way of ordinary text: nothing pairs touching a letter/digit, after `\`, or in code, frontmatter, HTML, comments or math. A space in an empty `*` pair drops the closer (`* ` bullet, `2 * 3`), and Enter on a lone `***` keeps a rule. Backspace in an empty pair removes a mark from each side.
- Commands: Bold (Ctrl+B), Italic (Ctrl+I), Strikethrough (Ctrl+Shift+S), Insert inline code (Ctrl+E, the existing command). All are remappable, in the palette, and act only with focus in a note editor, so the grid keeps its own Ctrl+B. Bold/Italic/Strikethrough are also in the command menu (Text style). They wrap/unwrap a selection, or leave an empty cursor between an empty pair; `***x***` toggles bold and italic separately.
