Implemented at the human's request on 2026-11-10 in `.worktrees/T-216`, branch `agent/codex/T-216`, based on main `20d14fb`. Status: **approved** after Codex's own verification. No merge, remote push, release or installation was performed.

## What changed

- **Teach the AI** (`teach-the-ai`) is a built-in conversation skill, with a School icon, available through the existing Skills command menu and eligible picked-file actions. It reads the current note or selected sources through the existing backend and provider/model permission paths.
- The user teaches; the AI plays a curious beginner, asks at most one relevant question per turn, paraphrases or applies the user's explanation, and invites correction. Attached notes are reference material, not evidence that the user already explained them. The instructions avoid lectures, blind agreement, confident fabricated mistakes, questions about note organization, and claims of model training or guaranteed future memory.
- **Wrap up** requests brief feedback grounded in the user's actual explanation: clear points, gaps/inaccuracies and a useful next practice step.
- Uses the existing conversation history, locked sources, privacy floor and automatic Markdown/HTML transcript saving. HTML is a locally rendered transcript, not a model-generated chat page. Existing save/open/discard controls work without a new UI or storage mechanism.
- Chat starts now use the neutral **Start the conversation.** Shared `skillPrompt` makes the dispatched prompt and saved history agree; Grill me keeps its interviewer role through its own instructions. Explicit user prompts remain unchanged apart from existing trimming.
- Vault exports and overrides use the existing SKILL.md mechanism. No dependencies, model runners, background work, scheduling or permission changes were added.

The initial request was misinterpreted as a personal Codex skill. After the human clarified AXISNotes, the two unchanged personal skill files created by this chat were hash-checked and removed. They are not part of this implementation.
