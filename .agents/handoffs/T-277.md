# T-277 handoff: Styles and a main text color

## What was built

- **Styles** (Settings → Appearance → Styles, the first tab). A Style sets the theme, note and interface fonts, text size, letter spacing, line height, heading colors, text colors and app colors in one click. Settings a Style leaves out go back to the defaults, so it always gives the same look; nothing else in the config changes. Undo restores the look from before.
  - 9 built-in Styles: AXIS Default, Paper & Ink, Midnight, Deep Teal, Coffeehouse, Plum, High Contrast, Focus and Studio. Each card shows a preview: background, text, heading colors and the note font.
  - **Your styles:** save the current look under a name (the same name replaces it, after asking), then rename or delete it (delete asks first). Saved in `styles` in the vault config and cleaned when it loads (`sanitizeStyles`).
  - The card matching the current settings is marked (`aria-pressed`).
- **Main text color** (Typography → Text colors, first row). One color for light themes and one for dark, used for the main text of notes and of the interface (sidebars, status bar, Settings). It takes priority over the text colors under Theme & layout → Colors. Unset sides use a neutral. Muted text keeps the theme's colors.
- **Color readers:** the graph, the welcome backdrop and the color picker now read colors through `src/lib/cssColor.ts`, which resolves `light-dark(…)` tokens. Without this, turning on Main text blanked the local graph's labels.

## How to test

Settings → Appearance → Styles: click a card, Undo, then save, rename and delete one of your own. Typography → Text colors → Main text: pick a color for light and for dark themes.

## Known gaps

- Settings still opens on Theme & layout; Styles is the first tab of the Appearance page.
- Applying a Style turns Main text off unless that Style has it on (Styles include text colors). This is by design.
- A Style that names a font this computer lacks falls back to the default font.
- The native WDIO e2e tests weren't run.
