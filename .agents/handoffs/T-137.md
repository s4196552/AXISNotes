# T-137 - A lone `1` stays text; digits pick headings in the command menu

Built by Claude on agent/claude/T-137 from main dce0393, at the human's request ("Typing 1 automatically sets it to 1." and "make typing 1–6 open the heading command in the quick command menu").

## Behaviour

- Typing `1` on an empty line no longer becomes `1. `. A numbered list still starts once `.` follows a number (`1.` → `1. `, `3.` → `3. `); a digit right after that gives a decimal (`3.5`), and Backspace right after puts back just the `.`.
- In the command menu (Ctrl+/, or a typed trigger such as `/`), a query of just `1`…`6` lists Heading N then Toggle heading N, so Enter makes that heading. On a line with text each also has its Turn into row. Before, `1` was turned into `1. ` (closing the menu) and `2`–`6` matched nothing, because CodeMirror matches a one-character query only against a label's first letter.
- Other numbers and longer queries filter as before; disabled heading commands stay hidden; custom commands are not listed for a heading digit.
