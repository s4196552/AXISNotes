# T-147 - Zen mode slides; file tree folder drop-down and turning arrow

Built by Claude on agent/claude/T-147 from main 5acb18f, at the human's requests: a sliding animation for the header bar and both sidebars in Zen mode, and (mid-task) a sliding drop-down when opening a folder in the sidebar, with the arrow turning.

## Behaviour

- Zen mode: the left and right panels slide in from their edges and back out; the tab row and window buttons slide down from the top and back up. They now play with Windows animations off (`prefers-reduced-motion: reduce`, which was suppressing them).
- File tree: opening a folder turns its arrow to point down and drops its rows in one after another; closing turns the arrow back.

## Files

src/styles/app.css, src/features/filetree/{FileTree.tsx,FileTree.test.tsx,filetree.css}, docs/DECISIONS.md, task coordination.

## How to test

`pnpm vitest run src/features/filetree/FileTree.test.tsx`. In the app: open a folder in the sidebar; press F11 and point at each window edge.

## Known gaps

Closing a folder isn't animated (its rows unmount at once). Timing samples of the Zen slides were taken in a hidden, throttled preview page, so they were checked by the running animations and transitions rather than by frame positions. No WDIO run.
