# T-283 handoff: repo hygiene

## What was built

- **Ignore lists:** `.worktrees/` and `test-vaults/` are ignored by ESLint (`eslint.config.js`), Prettier (`.prettierignore`), Vite's dev-server watcher (`vite.config.ts`) and git (`test-vaults/`).
- **`scripts/agents/prune-worktrees.ps1`** reports:
  - merged worktrees with no local changes (removable)
  - merged worktrees with local changes (kept)
  - unmerged worktrees and branches
  - unmerged branches with no row on the board
  - merged branches with no worktree (deletable)

  It never counts the primary checkout, or a branch still at `main`'s tip (a task just started). `-Apply` runs `git worktree remove` (never `--force`) and `git branch -d` (never `-D`), then `git worktree prune`. `-Sizes` measures sizes. The 2026-11-25 report: 145 removable worktrees, 2 merged with local changes (`axis-release-0.3.0` on T-079, `axis-T-075`), 10 unmerged worktrees plus 3 unmerged branches without one, and 97 deletable merged branches. **Not applied: that's the human's call.**
- **`scripts/agents/launch-config.ps1`** rebuilds the `axis-T-###` entries in `.claude/launch.json` from the existing worktrees, on port 1700 + ###. Other entries are kept.
- **TASKS.md:** the 245 finished rows moved to `.agents/TASKS-archive-2026.md`. The board keeps the header, T-283, and a list of the 13 unmerged branches without a row. The other Wave 1 sessions add their own rows.
- **`docs/research/improvements-2026-11-25.md`:** the research behind the four waves.
- **AGENTS.md:** a "Current state — 2026-11-25" section above the September handoff.
