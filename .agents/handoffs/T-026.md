# T-026 handoff: Fix grammar and clarity

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-026`

## What was built
- `src/features/ai/FixText.tsx` + `fixPrompt.ts`: the "Fix writing" dialog.
  - Two modes: grammar only, or also clarity.
  - Shows the destination and token estimate before sending, streams the draft, then shows the result as a word diff. Clicking a change keeps the original. Also has accept all / reject all, apply and copy.
  - Applying goes into the editor when the range is unchanged; otherwise it replaces the original text only if it appears exactly once, and refuses if not.
- `src/lib/diff.ts`: a line-then-word diff with `applySegments(segments, rejected)`.
- `src/lib/aiJson.ts`: `extractJson`, a small `Schema` + `validate`, `parseAnswer`, `InvalidAnswer`.
- `src/features/ai/runAi.ts`: `AiRun` (cancel), `runAi`, and `askValidated` (retries once, quoting the validation problems).
- Wiring: the palette command "Fix grammar and clarity (AI)" (Ctrl+Shift+G), a wand button in the editor header, and the modal kind `fix`.
- `memoryAi.setAiResponder` for scripted answers.

## How to test
