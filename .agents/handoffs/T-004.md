# T-004 handoff: Markdown editor

**Built by:** Claude (fallback — Codex's Windows sandbox could not run commands).
**Branch:** `agent/claude/T-004`

## What was built
- `livePreview.ts`: Obsidian-style live preview as a `ViewPlugin` over visible ranges, built by a pure `buildDecorations(state, ranges)`:
  headings (sized line classes; `#` hidden off the cursor line), bold/italic/strike/inline code (marks hidden), inline links `[text](url)` (only the text shown),
  blockquotes, `•` bullets, horizontal rules, clickable task checkboxes (`toggleTask`), fenced code blocks (styled lines, dimmed fences).
- `Editor.tsx`: CodeMirror 6 with GFM + code-language highlighting, history, search (Ctrl+F), line wrapping, readable column, title + save status.
  Autosave 500 ms after the last edit, flush on blur and unmount, `expectedModifiedMs` on every write.
  Conflict banner (Reload from disk / Keep my version) on a `Conflict` save or an external edit while dirty; silent reload (cursor kept) when not dirty;
  "moved or deleted" banner with Save here anyway. Autosave pauses while a banner shows.
- `theme.ts`, `editor.css`: CSS-variable-only theme.

## Changes outside `src/features/editor/`
- `src/ipc/memoryBackend.ts`: `externalRemove(path)` to simulate outside deletes in tests.

## How to test
- `pnpm test`: 8 decoration tests + 9 editor tests (autosave timing, unmount flush, reload, both conflict paths, delete banner, missing file).
- `pnpm dev` → open a note in the demo vault.
