# T-031 handoff: Browser extension

**Built by:** Claude. **Branch:** `agent/claude/T-031`

## What was built
- `extension/` (MV3):
  - `manifest.json`, `background.js` (clip / pair / status / retry messages, context menu, alarm-driven flush, badge with the queue count), and the popup files `popup.html`, `popup.js` and `popup.css`.
  - `lib/extract.js`: page and selection extraction to Markdown, injected with `executeScript({ func })`.
  - `lib/queue.js`: `sendClip`, `deliver`, `flush`, `status` and `pair`. It has no browser APIs, so it's testable.
- `scripts/build-extension.mjs` (`pnpm build:extension`): copies Readability, Turndown and the GFM plugin into `extension/vendor/` and the app icons into `extension/icons/`.
- ESLint covers `extension/**/*.js`, and Vitest runs `extension/**/*.test.js`.

## How to test
- `pnpm test`: `extension/lib/extension.test.js` runs real Readability and Turndown under jsdom, plus the queue against a fake AXIS.
- Manual: `pnpm build:extension`, then in Chrome go to `chrome://extensions` → Developer mode → Load unpacked → `extension/`. Pair from Settings → Web clipper, then clip a page.

## Known gaps
- Not published to the Chrome Web Store or Firefox Add-ons (that needs developer accounts), so it's loaded unpacked for now.
- The Phase 6 E2E drives the real app's endpoint with `lib/queue.js`. The extension's popup UI itself isn't automated.
