# T-234 — AXISNotes 0.3.89 Windows update

The 0.3.89 candidate combines the two tasks based on the live 0.3.88 release.

- T-233 adds drag and drop for moving and ordering shortcuts and groups in
  AXIS Hub. The dashboard and sidebars share the saved layout.
- T-232 adds wrapped-row keyboard navigation, smart lists, persistent Mermaid
  sizing and the Quote command in Markdown live preview.

The release increments the application, Tauri and Cargo versions. The
existing CodeMirror tests wait for parsing and highlighting. The Mermaid
suite allows its real parser more time to initialize under jsdom.

The NSIS archive contains AXISNotes 0.3.89 and the browser extension.
`AXISNotes_0.3.89_x64-setup.exe` is 23,159,819 bytes with SHA-256
`d3b3fe85066d71e69cfebee9aa11f15c7454acd6c5b7e1e6d23cbec7c96d932e`.

Run `e2e/specs/hub.e2e.ts` and `e2e/specs/markdown-editing.e2e.ts` with
WebdriverIO against the extracted executable. Verification logs, the preview
manifest and the installed-app discovery screenshot are in
`.agents/qa/T-234/`.
