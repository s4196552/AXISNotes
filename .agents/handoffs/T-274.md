# T-274 handoff: AI notes, Summary and Tutor skills

## What was built

Three new built-in AI skills, written as SKILL.md text in `builtinSkills.ts` (so "Copy the built-in skills into the vault" exports them as editable notes):

- **AI notes** (`/ai-notes`, default Markdown): rewrites a lecture, reading, transcript, clip or rough notes as organized study notes (overview, sections by topic, key terms, check questions with hidden answers). Keeps the source's facts, numbers and terms; flags gaps instead of inventing. Markdown uses callouts and folded answers; HTML is a page with a table of contents, glossary, `<details>` answers and print CSS.
- **Summary** (`/summary`, default Markdown): the gist, 3–7 key points, and any decisions, open questions or action items, only from the notes. Markdown uses an `[!abstract]` callout and `- [ ]` tasks; HTML is a page with labelled sections and tickable action items.
- **Tutor** (`/tutor`, conversation): a one-to-one tutor that checks what the learner knows, explains one idea at a time, hints before solving, corrects kindly and wraps up on request. Grounded in the notes, saying when it goes beyond them. Like Grill me and Teach the AI, the conversation is kept as a Markdown note or an HTML transcript.

Menu: new "Notes & summaries" category (AI notes, Summary) at the top of the Skills tab, with its own section icon; Tutor heads "Learn & understand". Distinct icons for each skill.

## How to test

`/` → Skills tab → AI notes or Summary → pick Markdown or HTML → Run on a note. `/tutor` starts a conversation; Wrap up ends it.
