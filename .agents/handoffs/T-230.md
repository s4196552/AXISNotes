# T-230 — Embedded AXIS Hub Windows update

AXISNotes 0.3.87 exposes AXIS Hub as a built-in plugin. Use the AXIS Hub tab
in the left sidebar or add the AXIS Hub widget through a dashboard's Customize
controls. Settings → Plugins controls availability for the vault and opens
shortcut pack management.

- `src/features/hub/` mounts the launcher on demand in a scoped DOM. The sidebar,
  dashboard, and pack manager share changes and dispose their subscriptions
  when closed. Dashboard placement uses the existing saved widget layout.
- `src-tauri/src/hub/` handles validated shortcut and pack data, Windows app
  discovery and icons, launch, and atomic, revision-checked library saves.
  The plugin reuses the device-local library from the earlier prototype.
- `e2e/specs/hub.e2e.ts` uses a temporary profile and checks both embedded
  views, an executable shortcut, shared edits, pack creation, and disabling
  and re-enabling the plugin.

The earlier T-229 standalone-window update was stopped before publication.
This installer is an ordinary AXISNotes NSIS package containing the embedded
plugin. Windows app discovery and local launches use the Windows Shell. Hub
packs contain shortcut and icon data in the validated JSON format.

Local test, artifact, discovery and screenshot evidence is in the ignored
`.agents/qa/T-230/` folder in this worktree.
