# T-195 handoff: AI output keeps its sources' privacy, allowed models per folder, prompt caching

## What was built

- **Note-level mark.** A note can carry `ai-access: any|local|never` in its frontmatter (HTML pages use `<meta name="ai-access">`). The Rust layer holds each note a request reads to the stricter of its folder rule and its own mark. Unknown, non-string or unparseable marks count as `never`.
- **Provenance.**
  - `RunResult.rule` is the strictest rule of everything a request read.
  - These are all written with the mark: drafts, Ask AI's "Save as note", skill pages and files, Quick Chat drafts, and AI-block and chat drafts.
  - Inserting or appending an answer into a looser note raises its mark, with a notice.
  - Folder questions and the Claude connector leave marked notes out.
- **Allowed models** (`ai.models` in the vault config) per folder or note.
  - Fallbacks are filtered too.
  - A request that no allowed model can take is refused and logged.
  - Set from the file tree: right-click → "Allowed models…".
- **Prompt caching.**
  - Anthropic requests mark the system prompt and the end of everything before the newest message.
  - Every provider's cached-token count is parsed, logged and shown in Settings → AI → Request log.

## How to test

- `cargo test ai:: mcp::`
- `pnpm exec vitest run src/lib/aiAccess.test.ts src/features/ai`
- In the app: right-click a folder → "Allowed models…", tick a model and save; the menu then shows the count. Settings → AI → Request log → "Show recent requests" shows "(N cached)" for cached requests.

## Known gaps

- The model picker next to AI prompts doesn't yet grey out models a folder's allowlist excludes. The Rust layer refuses them, with a message naming the folder.
- Allowlists are per folder or note only; a note's own mark doesn't carry an allowlist.
- In the index (lists, search, folder scope), a mark inside YAML that doesn't parse isn't visible. The AI layer and the connector's reads and writes check the file itself, so it's still enforced at send time.
- The cost estimate before sending assumes no cache hit.
