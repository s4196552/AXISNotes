# T-027 handoff: Handwriting to text

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-027`

## What was built
- `src/features/handwriting/`:
  - `recognize.ts`:
    - Builds the request (task `handwriting`, JSON mode, image and instructions) and defines `RECOGNITION_SCHEMA`.
    - `recognize()` validates the answer and retries once if it's invalid.
    - `flagWords()` combines the model's uncertain words (by occurrence) with local spellcheck flags.
    - `joinPieces()` builds the final text.
  - `pad.ts`: strokes → PNG (cropped, white background, ≤1600 px), plus `blobToBase64`.
  - `HandwritingPad.tsx`: the pen/touch/mouse surface.
  - `HandwritingDialog.tsx`: pad or image → shows the destination → reading (Stop) → review. Underlined words open a quick-fix menu (alternatives / Keep / type a correction). Then Insert.
  - `NoteHandwriting.tsx`: inserts the text at the cursor, or appends it to the note if it isn't open.
- Canvas: a "Convert to text" button. It exports the selection, or all freedraw strokes, and adds a text element below them or in their place.
- Commands: "Handwriting to text (pen)" in the palette and the `/handwriting` slash command. `QuickCommandConfig.runCommand` was added.
- Rust: a two-provider handwriting test with recorded SSE answers (`openai_handwriting.sse`, `anthropic_handwriting.sse`).
- `src/ipc/demoAi.ts`: canned answers for the browser preview only.

## How to test
- `pnpm test`: `recognize.test.ts`, `HandwritingDialog.test.tsx`, and `Canvas.test.tsx` ("turns pen strokes into a text element").
- `cargo test`: `handwriting_reads_an_image_on_two_vision_providers`.
- `pnpm dev`: add Ollama in Settings → AI, then type `/handwriting` in a note (demo answer).

## Known gaps
- Flags exist only in the review dialog. Once inserted, the text is plain editable text, with spellcheck still active.
- The pad doesn't support an eraser tool yet (only Undo and Clear).
