# T-285 handoff

## What changed

- `scripts/publish-update.ps1` runs the tests as `pnpm exec vitest run --maxWorkers=50% --retry=1` instead of `pnpm test`.
- Lint and typecheck are unchanged.
- The script's description now says how the tests run.

## Evidence

- Three loaded full runs: 3–6 timeouts each, all in heavy UI tests (Mermaid, media, folder icons, settings search, note title, page header, skills).
- Each passed on its own.
- The same commit passed in 105 s (fresh checkout) and in 60 s (main checkout) once the load passed.

## Known gaps

- `pnpm test` on its own still uses every core, so it can still time out under heavy load. Use `npx vitest run --maxWorkers=50%` on a busy machine.
- The 20 s per-test limit is unchanged.
