# T-239 — Copy code blocks

Use **Copy code** in the top-right of a fenced code block in a note. The
button is available in live preview and while editing the Markdown. It
copies the code text with its indentation and blank lines.

The live preview uses the Markdown parser's code text and keeps the copy
action independent of the language label. The control leaves the document
and cursor in place and uses the existing status messages for feedback.

Run `e2e/specs/code-copy.e2e.ts` against the Windows development build.
The test checks position, whitespace, a backtick line inside a longer
fence, coloured code, quoted code and copying while the fence is visible.
It captures the clipboard request without writing to the system clipboard.
