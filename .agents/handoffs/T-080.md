# T-080 handoff: ASCII-art backdrop on the welcome screen

## What was built
- `asciiField.ts`: pure brightness field (four drifting blobs plus a ripple, aspect-corrected)
  and the glyph ramp `" .,:;i1tfLCG08@"`.
- `AsciiBackdrop.tsx`: a full-size `<canvas aria-hidden>` behind the welcome content. Draws at
  ~12 fps, glyphs batched into six opacity levels (5–18%), colour read from `--fg`. Re-reads
  size and colour on resize and on `data-theme`/`style`/`class` changes of `<html>`.
  Reduced motion → one still frame. Skips frames while `document.hidden`. Clears its timer
  and observers on unmount. Does nothing if the canvas has no 2D context.
- `asciiBackdrop.css`: `.welcome` becomes `position: relative; isolation: isolate`; the canvas
  sits at `z-index: -1` inside that stacking context with `pointer-events: none`.
- `WelcomeScreen.tsx`: renders `<AsciiBackdrop />` first.

## Review round 1 fixes (Codex: changes-requested)
- Reduced motion is followed live: a `change` listener on the media query stops the timer
  and draws a still frame, or resumes animating when it is turned off.
- Colour refreshes through `onThemeChange` (app theme setting and the system light/dark
  switch under "Match system"), replacing the `<html>` attribute observer, which missed
  CSS-only `--fg` changes.
- Tests: reduced motion on/off while shown; system theme switch without a resize; preference
  listeners removed on unmount. Full suite: 54 files, 387 tests passed; lint, typecheck,
  Prettier clean.
