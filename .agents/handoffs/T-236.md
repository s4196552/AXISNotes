# T-236 — Markdown line controls

Hover over a Markdown line or place the caret on it to see **+** and the
six-dot grip. **+** inserts a new line and opens the same command menu as
**Ctrl+/**. A Setext title or callout keeps its Markdown intact.

Drag the grip to the insertion marker between lines. Double-click it
to select the line or block. Heading selections follow the heading fold
range, so lower-level headings and their contents are included. List
items include their children and callouts include their quoted body.
Line controls share the margin with the existing fold arrow and are
available with Outline view on or off.

The Markdown desktop smoke spec checks hover and caret visibility,
folding, insertion, block selection and pointer dragging. The preview
screenshot and test logs are under `.agents/qa/T-236/`.
