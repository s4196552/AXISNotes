## Storage and compatibility

Normal dimensions retain Obsidian's `|width` or `|widthxheight` syntax. Crop edges (percentages left/top/right/bottom) are saved after the embed as `<!-- axis-image {"crop":[10,0,10,0]} -->`. Other Markdown clients ignore this comment and show the original image. Nonnumeric wiki captions are preserved, using comment metadata for dimensions when needed. This is a display crop, not a destructive image export.

Current rendered-image controls apply to standalone embed lines (the existing media renderer's scope). Tables support normal pipe-table Markdown, including the supplied example; this does not add spreadsheet formulas, merged HTML cells or table widgets inside quoted callouts. No dependencies, AI calls, credentials, backend/database changes or suite-phase advancement.
