# T-092 handoff: icons in the graph view

## What was built
- **Setting:** `display.icons` in the graph settings (default on; settings saved before this
  keep it on). An "Icons" switch in the Display section of the graph settings panel and an
  "Icons" checkbox in the Tree toolbar change the same value.
- **Icon choice** (`nodeIcons.ts`, `nodeIcon`): the custom icon from `folderIcons` (folder
  ids drop their trailing `/`), else FileText / Sheet / Shapes / Folder, or File for an
  unresolved link.
- **Tree layout:** a 14 px icon before each box's label (a `foreignObject`, so emoji and image
  icons work through `EntryIcon`); the label moves along and is shortened to fit. Lit nodes
  draw kind icons in the accent text colour.
- **Force graph and local graph:** a sigma label drawer paints the icon between the node and
  its label, and the hover label makes room for it. Lucide icons are rasterized once per
  icon and colour (64 px SVG data URLs) and image icons loaded from the vault; the graph
  redraws (once a frame) when one finishes loading. Emoji are drawn as text. Icons follow the
  text fade threshold, since they're part of the label.

## How to test
Open the graph (sidebar graph button). Labels have icons. Give a note an emoji or coloured
Lucide icon with "Change icon…": the graph shows it. Graph settings → Display → Icons turns
them off. Switch to Tree (try Folders): icons on every box; untick Icons in the toolbar.

## Known gaps
- The local graph reads the setting when it mounts; a change in the main graph shows there
  the next time it's opened (or the app reloads).
- Loaded icon images are cached for the session: an image icon whose file is replaced keeps
  its old picture in the graph until reload.
- Icons show only on nodes whose labels show (text fade threshold), not on unlabelled dots.
