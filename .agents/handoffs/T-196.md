# T-196 handoff: Follow-up questions

## What was built
- Ask AI and plain-prompt AI blocks keep a conversation:
  - after an answer, the box empties and asks for a follow-up;
  - each follow-up sends the same notes plus earlier exchanges, trimmed oldest-first past ~8k tokens;
  - what the conversation reads is locked until "New question";
  - "Save conversation" writes a Markdown draft;
  - Retry (in blocks) re-asks the latest question with the history before it.
- Answers render as light Markdown with clickable `[[links]]` (`AnswerText`), never as HTML.

## Files
- New: `src/features/ai/{conversation.ts,AnswerText.tsx,conversation.test.tsx}`.
- Changed: `src/features/ai/{AskAi.tsx,AiBlockView.tsx,aiBlockStore.ts,ai.css}`, `src/features/skills/skillRun.ts` (`Turn` and the transcript now come from `conversation.ts`).

## How to test
- `pnpm exec vitest run src/features/ai/conversation.test.tsx`
- In the app: Ask AI about a note, then ask a follow-up. The earlier exchange shows above, and "Include note" is greyed out until "New question".

## Known gaps
- Quick Chat (the Agent) still answers one question at a time.
- The ~8k-token history budget is fixed; it isn't tied to the model's context size.
