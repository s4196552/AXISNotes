# T-231 — AXIS Hub in the right sidebar

AXISNotes 0.3.88 adds an AXIS Hub tab alongside Note details and AI chat.
Show the right panel and select **AXIS Hub**. For a dashboard, choose
**Customize → AXIS Hub → Done**. The dashboard and both sidebars use the
existing launcher library and see each other's edits.

- The shared sidebar launcher in `src/features/panels/Sidebars.tsx` is
  loaded on demand. The right sidebar waits for the plugin setting at startup.
- `src/app/layout.ts` remembers the last Note details or AXIS Hub selection
  on this device. AI chat can still take over when opened. If the plugin is
  disabled, the sidebar displays Note details and preserves the Hub library.
- The Windows smoke test in `e2e/specs/hub.e2e.ts` checks that a shortcut
  created on the right appears and launches from the dashboard, the left
  sidebar shares the same data, and the dashboard and right sidebar placements
  survive a WebView reload.
