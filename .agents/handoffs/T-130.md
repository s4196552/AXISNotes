# T-130 — Reliable sidebar file/folder dragging

## Built

- File and folder drags retain their active pointer, suppress competing native text/image dragging, and ignore unrelated pointers. A held gesture survives capture loss while its primary button remains down; actual cancellation, a released mouse button, Escape, window blur, vault switch and unmount clean up the gesture and its animation/hover work.
- A frame loop scrolls continuously at the file-list edges without requiring further pointer movement. Hit testing follows scrolling and hover-open folders, with scroll distance adjusted for regional zoom.
- A drag-only **Move to vault root** target covers the toolbar without shifting the file list. Empty-space root drops and between-row reordering remain. Release coordinates are checked before removing the drag-only target.
- Successful moves open the destination ancestors and keep the moved item visible and selected. Existing backend moves, link/tab/settings remapping, collision refusal and self/descendant protection remain responsible for the actual mutations.
- Version manifests advance to 0.3.26 to deliver the fix through the existing Windows update workflow. No dependencies, AI policy, source formats, native file-mutation code or theme palettes changed. Scope is in-sidebar dragging, as clarified by the human; external Explorer import is not part of this task.
