# T-193 handoff: Claude Desktop / Claude Code connector (MCP)

## What was built

The human asked to use their Claude plan with AXISNotes. Anthropic has no plan sign-in for other apps, so the direction is reversed: Claude Desktop or Claude Code (on the plan) start AXISNotes as a local MCP server and call it.

- `AXISNotes --mcp --vault <folder>` runs a stdio MCP server (JSON-RPC, one message per line, protocol 2025-06-18; also accepts 2025-11-25, 2025-03-26 and 2024-11-05). No window, no network listener, no new dependency.
- Tools: `vault_info`, `list_notes`, `search_notes` (the app's FTS and operators), `read_note` (path or wikilink name), `backlinks`, `list_tasks`. With "Allow changes": `create_note`, `edit_note` (revision-checked), `replace_in_note` (unique match), `append_to_note`, `append_to_daily_note` (the vault's daily folder and format). Nothing deletes, moves or renames.
- Access is off by default. Settings → Claude has two switches, saved as `claude.enabled` / `claude.allowChanges` in the vault config and re-read on every request. Paths whose AI rule isn't "any" are hidden everywhere, and every failure refuses access (fail closed). The panel also has a copyable Claude Code command, a Claude Desktop config entry and the recent activity log.
- Metadata-only activity log: `.axisnotes/claude-activity.jsonl`.

## How to test

- `cargo test mcp::` runs 13 tests: the protocol, access off/invalid config, read-only, hidden folders under every spelling (case, `..`, `:stream`, trailing dot, 8.3 names), revision conflicts, CRLF, the daily-note format and the log.
- `pnpm exec vitest run src/features/claude`
- Real client: `claude mcp add --scope local axisnotes -- "<exe>" --mcp --vault "<vault>"`, then `claude mcp list` should show `√ Connected`.

## Known gaps

- The daily template isn't applied when the connector creates a daily note; templates are expanded in the UI.
- An AXISNotes update closes running connectors, so Claude needs a restart afterwards.
- Folder links (symlinked folders) are followed as the app follows them.
- The connector does not add itself to Claude Desktop's config automatically; the user pastes the entry. A one-click "Add to Claude Desktop" could follow.
