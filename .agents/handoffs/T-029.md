# T-029 handoff: Phase 5 E2E + polish

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-029`

## What was built
- `e2e/specs/phase5.e2e.ts` (9 tests) runs against the real Tauri build. The spec starts a mock server on 127.0.0.1 that speaks **two** provider formats: OpenAI-compatible Chat Completions and Anthropic Messages. The tests cover:
  - Offline spellcheck: the underline, then the quick-fix menu, then the file is saved. No network traffic.
  - AI "fix grammar": the diff review, then apply, then the file on disk.
  - Handwriting on the note pad through the **OpenAI-compatible** vision provider (a PNG in `image_url`), then through **Anthropic** (an `image` block). Uncertain words are flagged and fixed through quick fixes.
  - Canvas pen strokes → "Convert to text" → a text element that replaces the strokes.
  - A prompt → Mermaid preview → an editable ```` ```mermaid ```` block that renders in the note.
  - An outline → mind map without AI (the server receives nothing).
  - A prompt → canvas shapes with bound arrows.
  - "AI: never" notes are refused by the fix and handwriting features.
- A `phase5` seed in `wdio.conf.ts`. Failed tests save a screenshot to `.agents/qa/phase-5/`.
- Polish found by the E2E run:
  - Spelling suggestions now put adjacent-letter swaps first ("teh" → "the"; nspell alone didn't offer it).
  - Canvas diagrams are placed beside existing content, and arrows run between box borders.
