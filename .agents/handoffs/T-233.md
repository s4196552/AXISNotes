# T-233 — AXIS Hub drag and drop

In the Hub library, drag a group or shortcut by its grip. With **Manual
order**, drop beside another item to insert it there. Drop on the middle of
a group card to move the shortcut or nest the group. Inside a group, drop on
the back button to move an item up. On desktop, the group name, shortcut
name, and preview tiles also accept mouse drags.

- `src/features/hub/launcher.js` resolves pointer targets inside the embedded
  launcher and saves through the existing revision-checked library API.
- `src/features/hub/launcher.css` provides grips, insertion markers, and
  destination outlines.
- `e2e/specs/hub.e2e.ts` drives real Windows WebView2 pointer actions and checks
  shortcut ordering, group ordering, nesting, moving up, cancellation, and
  the saved library.

Drag within a single Hub view. The dashboard and both sidebars read the saved
library. The edit dialogs provide keyboard controls for order and location.
