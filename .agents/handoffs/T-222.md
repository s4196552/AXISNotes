Implemented in `.worktrees/T-222`, branch `agent/codex/T-222`, based on main `9978504` (0.3.85).

## Result

Open a note → **Ctrl+/** → **Skills**. One parent tab contains these category headings and ordered skills:

| Category | Skills |
| --- | --- |
| Learn & understand | Teach me, Teach the AI, Example |
| Practice & remember | Practice test, Flash cards, Mnemonic, Make it stick |
| Visualize & present | Mind map, Infographic, Slide Deck |
| Plan & collaborate | Grill me, Handoff |

Vault overrides remain in their ID's category even when renamed. Unknown/custom skills remain available under Other skills. Typing filters across all skills using the existing ranked results; the jump bar stays one Skills tab. Arrow navigation and the existing skill actions are preserved.
