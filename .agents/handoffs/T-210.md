Implemented at the human's direct request on 2026-11-10 in `.worktrees/T-210`, branch `agent/codex/T-210`, based on `4164a05`. Status: **in-review**, pending Claude verification and lead merge. No merge or publication was requested or performed.

## What changed

- **Mnemonic** (`mnemonic`): accurate memory aids, explicit mappings, limitations and recall prompts.
- **Make it stick** (`make-it-stick`): closed-notes recall, mixed practice, application, explanation, self-assessment and suggested revisit intervals. It does not create reminders, Calendar events or Deck scheduling/history.
- **Example** (`example`): worked examples, explained steps, illustrative scenarios clearly separated from sourced facts, common mistakes and a practice problem with a hidden solution.
- **Slide Deck** (`slide-deck`): an offline HTML presentation by default, with navigation, readable mobile and print layouts; Markdown produces a slide outline.
- **Infographic** (`infographic`): an offline HTML visual summary by default; Markdown produces a structured infographic brief. Quantities and charts require supporting source data.

All five read notes, offer both Markdown and HTML, have individual icons and use the existing command menu, picked-file actions, provider/source permission checks, result saving, vault overrides and editable SKILL.md export. Existing built-ins are unchanged. The three new learning skills use the shared subject-focused study rules. No dependencies, storage formats or backend changes were added.

## Limits and lead decisions

Generation tests use deterministic local replies; they validate discovery, request routing, format handling and saved results, not the quality of a live model's mnemonic, lesson, slide design or chart. Slide Deck is HTML/Markdown, not a PowerPoint exporter. Infographic is HTML/a Markdown brief, not a PNG exporter, consistent with the existing format selector. Existing vault copies can still override built-ins by ID; copying built-ins adds missing skills without overwriting custom copies.
