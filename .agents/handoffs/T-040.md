# T-040 handoff: Zoom, text size, fonts, editor width

**Built by:** Claude. **Branch:** `agent/claude/T-040`

## What was built
- **`src/app/zoom.ts`:** zoom steps, stored per device.
  - Commands `zoom-in` (Ctrl+=), `zoom-out` (Ctrl+-) and `zoom-reset` (Ctrl+0).
  - Ctrl + wheel and number-pad +.
  - `Command.ignoreIn` keeps these shortcuts out of the canvas and the graph.
- **`backend.setZoom`:** the webview zoom in Tauri, CSS `zoom` in the browser preview.
- **`backend.listFonts`:** the Rust `list_fonts` command, using fontdb and cached.
- **Config `appearance`:** `{ noteFontSize, noteFont, uiFont, editorWidth }`, applied by `applyTypography` as CSS variables. The editor theme and CSS use them.
- **Settings → Appearance:** Zoom, Note text size, Note font, Interface font and Editor width.

## How to test
- `pnpm test`: 270, including `appearance.test.tsx`.
- `cargo test`: 97, including the font listing.
- E2E: vault.e2e checks Ctrl+= and Ctrl+0 against the real webview (devicePixelRatio) and `list_fonts`. perf.e2e now waits for indexing.
- Browser preview checked: Ctrl+= gave 110%, the note text went from 15 px to 22 px, Georgia applied, full width applied.
