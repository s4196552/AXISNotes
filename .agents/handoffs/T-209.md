# T-209 — Minimize the AI sidebar selection

The selection preview starts as a single expandable row showing the source note. Expand it with a mouse or keyboard to inspect the exact passage and access “Use whole note.” Asking and suggesting edits continue to use the selected passage while the preview is collapsed.

The implementation is in `src/features/ai/SidebarChat.tsx` and `sidebarChat.css`. The component regression in `SidebarChat.test.tsx` and the Windows regression in `e2e/specs/sidebar-chat.e2e.ts` cover initial visibility, expansion, collapse and sending the selection.
