# T-021 handoff: Rust AI layer

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-021`

## What was built
`src-tauri/src/ai/`:
- `mod.rs`: provider-independent types, the `AiProvider` trait, `is_local_url`, and the token estimate.
- `sse.rs`: an incremental SSE parser.
- `transport.rs`: the `Transport` trait, `ReqwestTransport` (rustls/ring), and `Fixture` for tests.
- `codec/`: OpenAI Responses, OpenAI-compatible Chat, Anthropic Messages, and Gemini. Also HTTP error mapping and the unsupported-parameter detection.
- `adapter.rs`: the `AiProvider` implementation, which drops a rejected parameter and retries once.
- `registry.rs`: loads `ai-models.json` (bundled, then the user's copy), supplies capabilities and task defaults (Gemini's picked from the live list), and prices.
- `keys.rs`: the keychain (`keyring`) and an in-memory store.
- `settings.rs`: per-user settings, which never hold keys.
- `privacy.rs`: per-folder rules from `.axis/config.json`.
- `log.rs`: the request log (metadata only).
- `service.rs`: provider/model resolution, privacy and token-cap enforcement, fallback chain, streaming with cancellation, and logging.

`src-tauri/src/ai_commands.rs` holds the commands: `ai_settings`, `ai_save_settings`, `ai_set_key`, `ai_delete_key`, `ai_test_provider`, `ai_list_models`, `ai_plan`, `ai_run` (emits `ai://delta`), `ai_cancel` and `ai_log`. The env vars `AXIS_CONFIG_DIR` and `AXIS_AI_MEMORY_KEYS` isolate the E2E tests.

## How to test
`cargo test`: 75 tests. That includes the same prompt through all four formats, parameter drop and retry, error mapping, cancellation, images in each format, model lists, and service tests for blocking, local-only routing, fallback, the token cap and key handling. With keys set in the environment, the live test also calls the real providers.

## Known gaps
- Text the UI puts into a prompt counts toward privacy rules only if the UI declares it in `sources`. Notes passed through `attach` are always enforced, because Rust reads them itself.
- Streaming deltas are emitted one event per chunk (not batched).
