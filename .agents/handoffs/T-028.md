# T-028 handoff: Smart diagram maker

**Built by:** Claude. Codex's Windows sandbox is unavailable, so a cross-review is owed. **Branch:** `agent/claude/T-028`

## What was built
- `src/lib/diagram.ts`:
  - Graph model, `GRAPH_SCHEMA`, `checkGraph`/`parseGraph` and `graphToMermaid`.
  - `outlineToGraph`, `linksToGraph`, `layoutGraph` (layered flowcharts, tree mind maps) and `graphToSkeleton` (Excalidraw).
- `src/features/diagrams/`:
  - `mermaid.ts`: lazy loader, `renderMermaid`, `mermaidProblem`, `extractMermaid`.
  - `mermaidBlocks.ts`: renders ```` ```mermaid ```` blocks in the editor.
  - `diagramPrompt.ts`: the Mermaid and graph prompts, and `parseMermaidAnswer`.
  - `DiagramMaker.tsx`: "Describe it (AI)" and "From notes (no AI)" tabs, a live preview, and editable Mermaid code.
  - `NoteDiagram.tsx`: inserts the ```` ```mermaid ```` block after the cursor or selection.
- Canvas: a "Diagram" button that adds shapes and arrows centered in the view.
- Commands: "Make a diagram" in the palette, plus `/diagram` and `/mermaid`.
- Demo answers for the browser preview.

## How to test
- `pnpm test`: `diagram.test.ts`, which validates generated Mermaid with the real parser; `DiagramMaker.test.tsx`; `mermaidBlocks.test.ts`.
- `pnpm dev`: type `/diagram` in a note, then "From notes" → Insert.

## Known gaps
- The canvas layout is simple: no edge-crossing minimization beyond one barycenter pass.
- Mermaid's `mindmap` labels lose `()[]{}` characters.
