# T-091: Icon and image packs

The user asked to let users upload icon and image packs. Decisions from the user:
packs are kept hidden in the vault (`.axisnotes/packs/`), and can be uploaded from a
folder or a `.zip`.

- Icon packs appear in the icon picker (a Packs tab); image packs in the cover gallery.
- Settings lists packs and removes them (to the OS trash).
- Icons from one-colour packs take the text colour or any colour picked.
