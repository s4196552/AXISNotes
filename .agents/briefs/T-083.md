# T-083: Notion-style page icons and cover banners on notes

**Goal:** a note can show a large page icon and a cover banner above its title, set and
changed in place, like Notion. Builds on T-082 (branch is stacked on it).

**Requirements:**
- **Page icon** is the note's existing custom icon (`.axis/config.json` → `folderIcons`),
  so the file tree, the header and renames stay in step. Shown large above the title;
  hover shows "Add icon" when there is none; click opens the icon picker.
- **Custom image icons:** the picker gains an Image tab: choose an image already in the
  vault, or upload one from the computer (copied into the vault). Stored as
  `image:<vault path>`; a missing image falls back to the default icon.
- **Cover banner** lives in the note's frontmatter, compatible with the Obsidian Banners
  plugin: `banner` (a vault image as `"[[path]]"` or a path, a built-in gradient as
  `gradient:<name>`, or a `#rrggbb` colour) and `banner_y` (0–1 vertical focus).
  Hover actions: Change cover (gallery of gradients and colours, vault images, upload),
  Reposition (drag, then Save / Cancel; keyboard arrows too), Remove.
- Remote `http(s)` banners are not fetched (local-first); show a short explanation instead.
- `banner` and `banner_y` are hidden from the properties chip (they're edited on the cover).
- **Upload** goes through a new Rust command that copies one image file into
  `<note folder>/attachments/` under a unique name: image extensions only, 25 MB cap,
  destination resolved inside the vault, and the index/file tree told about the new file.
