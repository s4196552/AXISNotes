# T-082: Every Lucide icon in the icon picker, in any colour

**Goal:** folders and notes can use any of Lucide's ~1,900 icons, not only the 44 curated
ones, and any colour, without making the app slower to start.

**Requirements:**
- The full set loads on demand (first time the picker or a non-curated icon needs it) as
  its own chunk. The curated icons keep rendering synchronously, and the startup bundle
  must not grow by more than a few kB (check `pnpm build` output before and after).
- Stored values stay `lucide:<Name>`, so existing settings keep working, including curated
  names that are aliases in Lucide 1.x (`Home`, `DollarSign`).
- Picker: suggested (curated) icons first; search matches names as words
  (`flask` finds `FlaskConical`); results render in pages so typing stays responsive; a
  loading state and a recoverable error if the chunk fails.
- Colour: the existing swatches plus a custom colour input (any hex).
- File tree icons for non-curated names appear once the set has loaded; nothing breaks
  for an unknown name (falls back to the default icon).
- No new dependency (lucide-react 1.48 already exports the `icons` namespace).

**Files:** `src/features/icons/**`, `src/features/filetree/FileTree.tsx` (pass the default
icon as the fallback), `src/features/settings/customization.test.tsx`,
`docs/DECISIONS.md` (icons note), `.agents/**` for T-082.

**Tests:** `pnpm lint && pnpm typecheck && pnpm test`; picker search, full set, custom
colour and file tree checked in the preview; build sizes compared.
