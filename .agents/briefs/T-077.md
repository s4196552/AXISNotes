# T-077: Separate left and right side-panel buttons

**Goal:** replace the single "hide both side panels" button with one button per side,
each with a mirrored sidebar icon (Lucide `PanelLeft` / `PanelRight`):

- Right: top right of the main area; hides/shows only the right panel.
- Left: in the left panel's header (next to Settings) while it shows; top left of the
  main area while it's hidden; hides/shows only the left panel.
- Pressed (accent tint) while that side is hidden. Tooltips show the side's own
  shortcut (`toggle-left-panel` / `toggle-right-panel`) when one is set.
- Ctrl+\ still hides/shows both. Headers leave room for the left button when needed.

**Files:** `src/features/panels/{PanelToggle.tsx,Sidebars.tsx}`, `src/App.tsx`,
`src/styles/app.css`, `src/app/layout.test.tsx`, `.agents/TASKS.md`.

**Tests:** `pnpm lint && pnpm typecheck && pnpm test` (`src/app/layout.test.tsx` covers both sides).
