# T-279 + T-280: only real changes reload panels; keep the UI thread free

Wave 1 of the improvement plan the human approved on 2026-11-25 (`docs/research/improvements-2026-11-25.md`). One branch, `agent/claude/T-279`, covers both tasks.

## T-279: only real changes reload panels

Every 500 ms autosave called `bumpIndex()`, which bumped `indexVersion` and re-listed the notes (always a new array). Everything keyed on `indexVersion` reloaded on each save: the graph (full vault), backlinks and unlinked mentions (read from disk), search, tags, outline, the dashboard, canvas note cards, time report and tasks. Each editor also rebuilt its link styles.

- Rust: `write_file` reports whether the note's structure changed (title, headings, links, tags, aliases, block IDs, tasks, properties), by comparing the old and new parse in the index upsert.
- TS: keep the `Backend` interface, `tauriBackend.ts` and `memoryBackend.ts` in step.
- Store: a `structureVersion` that panels subscribe to, and a per-note content signal. Replace `notes` only when the list differs.
- Views of one note's text (outline, canvas card, dashboard note) key on that note, not every save.

## T-280: keep the UI thread free

- Make blocking Tauri commands async: at least `list_tree`, `write_file`, `list_notes`, `list_tasks`, `resolve_link`, `time_entries`, `updates_check` and the keyring commands.
- A folder change re-syncs only that folder (`sync_subtree`), not the whole vault.
- Watcher batches dedupe with a `HashSet`, not `Vec::contains`.
- The tree sorts with `sort_by_cached_key`.

Avoid the files of parallel tasks: `src/app/config.ts` (T-278), `src-tauri/src/ai/` (T-281), `src-tauri/src/updates*.rs` and `scripts/publish-update.ps1` (T-282; only the `updates_check` attribute changes here), eslint/vite config and test infrastructure (T-283/T-284).

## Done when

- A Vitest test counts backend calls while typing plain text: no `graph`, `backlinks`/`unlinkedMentions`, `search` or tag calls unless a link or tag changes.
- A cargo test covers `sync_subtree` and the structure-changed flag.
- `pnpm lint && pnpm typecheck && pnpm test` and `cargo test` pass in the worktree.
- Typing and the side panels are checked in the vite preview (port 1979).
- Merged into `main` with `--no-ff`. No release: the lead ships one patch after Wave 1.
