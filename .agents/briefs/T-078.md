# T-078: New main logo (pearl three-point mark)

**Goal:** the user's new logo (a solid three-point symbol in pearl white with a warm
sheen, transparent background) replaces the red/blue/green T-037 mark everywhere:
`src/assets/logo.svg` (master: welcome screen, Settings → About, favicon), the desktop
icons regenerated with `pnpm tauri icon src/assets/logo.svg`, and the extension icons
via `pnpm build:extension`. In the app the mark gets a soft drop shadow so its edge stays
visible on light themes.

**Files:** `src/assets/logo.svg`, `src-tauri/icons/*` (generated; mobile folders not kept),
`src/app/Logo.tsx`, `src/styles/app.css`, `docs/DECISIONS.md`, `.agents/TASKS.md`.

**Tests:** `pnpm lint && pnpm test`; check About and the welcome screen in light and dark.
