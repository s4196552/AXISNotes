# T-085: Notes as tabs, like Obsidian

**Goal:** the main area shows a row of tabs. Each tab holds a note (or the graph, tasks or
time report) with its own back/forward history, and the tabs come back the next time the
vault opens on this device.

**Requirements:**
- **Model:** the app store keeps `tabs` (id, path, view, pinned, back/forward history) and
  the active tab. `activePath` and `mainView` stay and always mirror the active tab, so
  existing callers keep working. `openFile` opens in the active tab (pushing history),
  or in a new tab when asked or when the active tab is pinned. `setMainView` changes the
  active tab's view.
- **Tab bar:** icon (the note's custom icon or its file kind) + title; close button; a pin
  instead of the close button on pinned tabs; middle-click closes; "+" opens a new tab;
  drag to reorder; context menu with Close, Close others, Close tabs to the right,
  Pin/Unpin. Scrolls sideways when full. A `tablist` with `tab`s for screen readers.
  Leaves room for the side-panel buttons.
- **New tab** (empty): says so, with Create note, Open note (quick switcher) and Close.
- **Opening in a new tab:** Ctrl/Cmd+click or middle-click in the file tree, middle-click
  on a link in the editor, Ctrl+Enter in the quick switcher.
- **Commands** (remappable): New tab Ctrl+T, Close tab Ctrl+W (not pinned tabs), Next /
  Previous tab Ctrl+Tab / Ctrl+Shift+Tab, Go to tab 1–8 Ctrl+1–8, Last tab Ctrl+9, Back /
  Forward Ctrl+Alt+← / →, Reopen closed tab (no default: Ctrl+Shift+T is Open tasks), Pin
  tab, Close other tabs.
- **Closing** the last tab leaves one empty tab. Closing activates the tab to the right,
  else the left. Unsaved edits are flushed as when switching notes today.
- **Files:** a rename or move updates every tab and its history; trashing closes the tabs
  showing it. On restore, tabs whose file no longer exists are dropped.
- **Persistence:** per vault and device (local storage): open tabs, pinned state and the
  active tab (not history).
- **Editor:** returning to a tab puts the cursor and scroll back where they were.
