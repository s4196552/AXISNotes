# T-284: faster, steadier tests

Wave 1 of the improvement plan the human approved on 2026-11-25.

## Problem

- Full Vitest runs took 60–236 s on this machine, with random 20 s timeouts.
- Every test file built jsdom and loaded formulajs (2 MB), though few need either.
- ESLint had 13 `react-refresh/only-export-components` warnings.

## Done when

- Formulas load only where tests evaluate them.
- DOM-free test files run in Node.
- The warnings are fixed without changing behaviour.
- The default `pnpm test` passes reliably.
