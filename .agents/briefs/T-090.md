# T-090: Turn into, toggle headings and descriptions in the command menu

Follow-up to T-088/T-089, asked for by the user: make the Ctrl+/ menu more like Notion.

- **Turn into:** while filtering on a line that has text, block commands also offer
  "Turn into", which changes the current line and keeps its text. Plain block commands start
  a new line under a line with text (Notion's behaviour) and replace an empty line.
- **Toggle headings** (and a toggle list): stored as Obsidian foldable callouts,
  `> [!toggle|h1]- Title` (the user chose this format over plain headings with folding or
  HTML `<details>`). The editor draws an arrow that opens and closes them by flipping
  `+`/`-` in the note, a heading-sized title, and hides a closed toggle's inside.
- **Descriptions:** a short line under each command's label.
