# T-088: Icons and Markdown hints in the command menu

The command menu (Ctrl+/) shows CodeMirror's key glyph next to every command. Replace it
with a Lucide icon per command and show the Markdown that does the same thing on the right,
like Notion's `/` menu (`#`, `##`, `-`, `![[`, …). Commands with no Markdown equivalent show
no hint. Other menus (`[[`, `@@`, `((`, `::`, `{{`, emoji) keep their look.

Files: `src/features/editor/{quickCommands.ts,lucideSvg.ts,theme.ts,Editor.tsx,triggers.test.ts}`

Done when: every built-in and custom command has an icon, the key glyph is gone, Markdown
hints are right-aligned, the checks pass and the menu is checked in the preview.
