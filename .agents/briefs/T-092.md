# T-092: Icons in the graph view's Graph and Tree layouts

Asked for by the user: "Add icons in tree and graph view by default and can be changed with a
checkbox tick."

The sidebar file tree already shows icons, so this covers the graph view: its force graph
(and the local graph in the right sidebar) and its Tree layout.

- Each node shows its custom icon (the one set with "Change icon…", shared with the file tree
  and page header: Lucide, emoji or image, with its colour), else an icon for its kind (note,
  grid, canvas, folder, unresolved link).
- On by default. A checkbox turns them off: "Icons" in the graph settings' Display section
  and in the Tree layout's toolbar, one shared setting saved on the device with the other
  graph settings.

Files: `src/features/graph/**`
