# T-003: File tree (Phase 0)

**Owner:** codex · **Branch:** `agent/codex/T-003` · **Base:** `main`

## File ownership

You may create or edit **only** `src/features/filetree/**`. Everything else is read-only for you. If you need a change elsewhere (store, IPC, styles), describe it in your handoff note instead of making it.

## Contract you build against (read these first)
- `src/ipc/types.ts`: the `Backend` interface. Use `backend` from `src/ipc` for `createFile`, `createDir`, `renameEntry` and `trashEntry`. All paths are vault-relative with forward slashes, and the root is `""`.
- `src/app/store.ts`: `useAppStore` provides `tree`, `activePath`, `openFile`, `refreshTree`, `onEntryRenamed`, `onEntryRemoved` and `setError`.
- `src/App.tsx` renders `<FileTree />` (no props) inside `.sidebar`. Export `FileTree` from `src/features/filetree/index.tsx`, replacing the current stub.
- `src/styles/theme.css` defines the CSS variables. Use them only, with no raw colors. Put your styles in `src/features/filetree/filetree.css` and import that file from your component.

## Requirements
1. **Nested tree** of `tree.children`, with folders collapsible (chevron + lucide folder/file icons). Show `.md` files **without** the extension. Highlight the active note. Persist the expanded folders per vault in `localStorage`, wrapped in try/catch, since storage may be unavailable.
2. **Opening**: clicking a `.md` or `.txt` file calls `openFile(path)`. Show other files dimmed and don't open them.
3. **Toolbar** at the top: *New note*, *New folder*, *Collapse all*. New items go into the selected folder (or the folder of the selected file), falling back to the root.
4. **New note** creates `Untitled.md` (or `Untitled 1.md`, `Untitled 2.md`, ... if taken), opens it, and starts inline rename. **New folder** works the same way with `Untitled folder`.
5. **Inline rename**: F2 or the context menu. Enter commits and Esc cancels. Keep the `.md` extension if the user leaves it out. Renaming a folder moves its contents.
6. **Context menu** (right-click): New note here, New folder here (folders only), Rename, Delete. Delete asks for confirmation (`window.confirm` is fine for now), then calls `trashEntry`.
7. **Drag and drop**: dropping a file or folder onto a folder, or onto empty space (the root), moves it with `renameEntry`. Reject dropping a folder into itself or its descendants, and ignore dropping an item where it already is.
8. **Keyboard**: Up/Down moves the selection; Left collapses or jumps to the parent; Right expands; Enter opens; F2 renames; Delete trashes. Use proper ARIA: `role="tree"`, `role="treeitem"`, `aria-expanded`, `aria-selected`, `aria-level`.
9. **After every change**: `await refreshTree()`. Then call `onEntryRenamed(from, to)` or `onEntryRemoved(path)`. Report errors with `setError(e.message)`. `BackendError` has `{ code, message }`.
10. Keep it fast with 5,000 entries: don't re-render the whole tree on selection changes. Memoize rows.
