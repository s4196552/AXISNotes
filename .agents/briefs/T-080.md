# T-080: ASCII-art backdrop on the welcome screen

**Goal:** a faint, slowly drifting ASCII-art background behind the welcome screen
(characters chosen by the brightness of a few soft blobs), like the Claude desktop
new-session screen. Decorative only.

**Requirements:**
- Hidden from assistive technology; ignores the pointer; never covers welcome content.
- Colour follows the theme (`--fg`), including a theme change while the screen is up.
- `prefers-reduced-motion: reduce` draws one still frame; no timers.
- Pauses drawing while the window is hidden; all timers/observers disposed on unmount.
- No new dependencies. Does not touch `src/styles/app.css` (T-079 has it open).

**Files:** `src/features/vault/{AsciiBackdrop.tsx,asciiField.ts,asciiBackdrop.css,asciiBackdrop.test.tsx}`,
`src/features/vault/WelcomeScreen.tsx`, `.agents/TASKS.md`.

**Tests:** `pnpm lint && pnpm typecheck && pnpm test`; check the welcome screen in the preview
on a dark and a light theme.
