# T-277: Styles and a main text color

The human asked (2026-11-25): "Add Styles. Pre set: Fonts, Theme, colors, heading colors, typography, and custom main font colors (add that)". Clarified: the main text color covers note and interface text; users can save their current look as their own Style, plus built-in Styles. Plan approved in plan mode.

## Scope

`src/app/{styles,config,appearance}.ts`, Settings (`StylesSettings`, `Settings`, `TextColorSettings`, `Typography`), `settings.css`, and readers of colour tokens that need resolved colours (graph, welcome backdrop, color picker via `src/lib/cssColor.ts`). Tests and task coordination.

## Behaviour

- A Style is a theme plus note/interface fonts, size, letter spacing, line height, heading colors, text colors and app colors. Applying one sets all of them (left-out settings go to the defaults); nothing else in the config changes. Undo restores the look before.
- Built-in Styles use existing themes, app color presets and heading presets, with fonts Windows includes. No product or brand names.
- Own Styles: save the current look under a name (same name replaces, after asking), rename, delete (after asking). Stored in `styles` in the vault config; cleaned when it loads (hex-only colors, clamped numbers, known heading presets, removed themes mapped).
- Main text: a light and a dark color for the main text of notes and the interface, over the theme and the Colors text colors; unset sides use a neutral.
