# T-086: Obsidian-style graph and a tree layout

**Goal:** the graph view behaves like Obsidian's (live physics you can drag, a settings
panel with filters, groups, display and forces), and offers a second **Tree** layout that
draws a note's links as a left-to-right tree with elbow connectors, like a decision tree.

**Requirements:**

- **Graph mode (Obsidian-like):**
  - Live force simulation (d3-force: repel, link force and distance, centre force). It
    cools down and stops on its own (no idle CPU) and is stopped on unmount.
  - Drag a node: its neighbours follow; releasing lets it settle again.
  - Settings panel (gear button), sections like Obsidian: **Filters** (search, orphans,
    unresolved), **Groups** (query → colour, add/remove), **Display** (arrows, text fade
    threshold, node size, link thickness), **Forces** (centre, repel, link force, link
    distance), plus **Animate** (re-run the layout from scratch).
  - Display and group changes apply without re-running the layout; force changes reheat
    the simulation. Filter changes keep the positions nodes already had.
  - Settings persist per device (local storage) and survive bad stored values.
- **Tree mode:**
  - Toolbar toggle Graph | Tree (remembered per device).
  - Root: the open note by default (else the most-linked note); pick another from a
    list, "use current note", or right-click a node to make it the root.
  - Follow **Links** (outgoing), **Backlinks** or **Folders** (vault hierarchy); depth 1–6.
  - Each note appears once (shallowest level); links to notes already in the tree are
    counted, not drawn. Large trees are capped with a visible note.
  - Layout: columns per level with headers and alternating bands; boxes; elbow
    connectors with arrowheads; the path from the root to the hovered/focused note (or the
    open note) is highlighted in the accent colour.
  - Collapse/expand subtrees; click opens the note; pan (drag), zoom (wheel, buttons) and
    fit. Keyboard: tree items are focusable, Enter opens, ←/→ collapse/expand, ↑/↓ move.
- Theme colours throughout; works in every theme.
