# T-084: Welcome-screen ASCII art from the user's three-cusp star design

**Goal:** replace T-080's drifting-blob ASCII backdrop with the user's design
(`T-084-reference.svg`, from `gemini-svg.svg`): a field of letters and digits, visible only
inside a softly feathered three-cusp star (the AXIS mark's shape), tinted warm (top left)
to cool (bottom right).

**Requirements:**
- Same geometry as the reference: star tips (960,110), (1410,880), (510,880) with all
  three curves through the control point (960,620) in a 1920×1080 frame, scaled to cover
  the screen; radial fade centred at 58 % of the star's height (stops 1 / 0.85 / 0.35 / 0);
  soft edges (the reference's 6 px blur).
- Glyphs: random lowercase letters and digits with some capitals, 12.5 px monospace,
  16 px rows, as in the reference. Tint `#d6c7b2` → `#b5ada2` → `#94a0b8` at 22–28 %
  opacity on dark themes; a darker version of the same tint on light themes (decided by
  the theme's `--fg`).
- Keeps T-080's behaviour: decorative (hidden from assistive technology, no pointer),
  follows theme changes live, one still frame under reduced motion (following changes
  live), pauses while the window is hidden, everything disposed on unmount. Motion is
  a slow shimmer: a few glyphs change each frame; the star doesn't move.
- The theme's own background stays (the reference's `#111110` fill is not copied).
- No new dependencies.

**Files:** `src/features/vault/{AsciiBackdrop.tsx,asciiField.ts,asciiBackdrop.test.tsx}`,
`.agents/**` for T-084.

**Tests:** `pnpm lint && pnpm typecheck && pnpm test`; welcome screen checked in the preview
on a dark and a light theme.
