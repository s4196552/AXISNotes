# T-275: Customizable sidebars and Favorites

Requested 2026-11-23 (via the lead session): let users customize the sidebars, and add a Favorites section that folds open and closed.

## Scope

`src/features/panels/**` (Sidebars, new layout model, Favorites panel, CSS, tests), `src/app/config.ts` (new `sidebars` and `favorites` keys), `src/app/store.ts` (`setLeftPanel` finds a panel wherever it now lives), `src/features/files/renameEntry.ts` (favorites follow renames and moves), `src/features/filetree/{FileTree.tsx,reveal.ts}` (context-menu item; reveal any path), palette commands registered from the Favorites panel, `src/app/{layout,sidebarLayout}.ts`, task coordination.

## Behaviour

1. **Customizable sidebars.** Every sidebar panel has a stable id: `favorites`, `files`, `search`, `tags`, `hub`, `calendar`, `outline`, `graph`, `backlinks`. The vault config keeps `sidebars: { left, right, hidden }` (ordered ids). Defaults reproduce today's layout plus Favorites at the top of the left sidebar.
   - The left sidebar keeps its tab strip for the full-height panels (Files, Search, Tags, Hub). Stacked panels (Favorites, Calendar, Outline, Local graph, Backlinks) placed on the left show as folding sections above the selected tab.
   - The right sidebar's Note details shows every panel placed there as a folding section, in order (a full-height panel placed there grows to fill the space).
   - Drag a tab or section heading to reorder it, or drop it on the other sidebar to move it there (pointer drag, `usePointerDrag`, like the ribbon). Keyboard: Alt+Arrow keys move the focused tab or heading; the panel's menu (⋯ button, right-click, Shift+F10 or the context-menu key) offers Move up/down, Move to the other sidebar and Remove panel.
   - Each sidebar has an "Add panel" menu listing removed panels (and a Reset layout item), so a removed panel can always come back. Unknown ids in a hand-edited config are ignored; panels added by later versions appear at their default place.
   - Commands that show a panel (Show search, Show files…) find it wherever it lives, and bring a removed panel back.
2. **Favorites.** `favorites: string[]` of vault paths (notes, other files, folders) in the config. A Favorites section with a folding heading; items open on click (files open as a tab; folders reveal and open in the file tree). Add/remove from the file tree's context menu and with "Add/Remove open file from favorites" palette commands; each item has a remove button. Reorder by dragging or Alt+↑/↓. Favorites follow in-app renames and moves (`remapIcons`); a trashed favorite stays listed as missing so an undo brings it back, and can be removed.
3. Fold state of sections stays a device preference in local storage (the existing `axisnotes:right-panel-sections` key, now for every section).

No new dependencies.

## Done when

Layout and favorites persist in `.axisnotes/config.json`; Vitest + Testing Library tests cover reorder, add/remove, collapse and favorites persistence; `pnpm lint && pnpm typecheck && pnpm test` pass; checked in the vite preview with screenshots.
