## Scenarios and acceptance criteria

1. **Biology continuity.** Create project Biology in Hub; attach `School/Biology.md` from the
   Notes badge menu; rename it in Notes to `School/Cell Biology.md`; close Notes, delete
   `.axisnotes/index.db`, restart Notes. Hub search "mitochondria" (project filter Biology)
   returns the note with the **same** ResourceRef recorded before the rename; Open focuses Notes
   on that note (assert Notes' active editor title).
2. **Gaming.** Section Gaming with Spotify (website → fixture page in a Hub session tab),
   Discord and a game (application items pointing at launch-probe with args including spaces,
   quotes, `&`, `%PATH%`) → probe JSON shows exact argv; Hub closed afterwards leaves the probe
   process unaffected.
3. **Two website sessions + fallback.** Two shortcuts to the fixture login page with sessions A
   and B: cookie set in A absent in B; Clear A removes it; Open in browser with a registered
   fake browser (launch-probe) receives the profile-directory and URL arguments exactly.
4. **Standalone survival.** With Hub closed and Connect killed (`taskkill /F`), Notes creates,
   edits, saves and searches notes; suite status shows unavailable; restarting Connect →
   Notes re-registers within 15 s. With `AXIS_CONNECT_EXE` pointing to a missing file, Notes
   shows not-installed and works.
5. **Denials (raw HTTP, `e2e/support/suite` client).** Against Connect and the Notes adapter:
   no signature → 401; `Origin: https://evil.example` → 403 before auth; `Host: localhost:<p>`
   and `Host: evil.example` → 403; `OPTIONS` → 403 with no CORS headers; replayed nonce → 401;
   skewed timestamp → 401; revoked client → 401; stale instance → 409; Hub-originated
   `notes.set-task-completed` → blocked.
6. **Remote tab.** Fixture hostile page in a Hub site tab tries `__TAURI_INTERNALS__.invoke`
   for `launch`, `project_mutate`, `set_device_mapping`, and `fetch` to Connect/adapter ports:
   all fail; probe records no launch; project list unchanged. Extended per S2-D39:
   - **Sibling children.** The test opens `main` plus two sibling site webviews (sessions A and
     B) in `hub-window`. Both hostile pages invoke every Hub command in the manifest list and
     representative plugin/core commands, and all calls are denied. The main UI keeps working.
   - **Custom invoke.** The hostile pages send raw IPC `POST`s to `http://ipc.localhost/<cmd>`
     with forged `Tauri-*` headers. All fail. Library, device mappings and the launch log are
     unchanged.
   - **Reserved origins.** Each hostile page tries to navigate or redirect to
     `tauri://localhost`, `http(s)://tauri.localhost`, `http://asset.localhost`, the `devUrl`
     origin and `file:`/`data:`/`javascript:` URLs, including through `window.open`. All are
     refused; the site webview URL stays on the fixture origin, and no bundled Hub page ever
     loads in a site webview.
7. **Protected files and legacy rules.** From the Notes webview, `write_file` to
   `.axisnotes/ai-policy.json`, `.axisnotes/suite/identity.json` and
   `.axisnotes/suite/provenance.json` is rejected. With `Medical: never` in `config.json`, a
   webview `write_file` of the config that drops `ai.folders.Medical` and changes a hotkey
   leaves `never` on disk and the hotkey changed; Ask AI on a Medical note stays blocked
   (mock AI servers: zero requests). Removing the rule from the file tree menu needs the
   second confirmation.
8. **Delete Biology.** Record SHA-256 manifests of every vault file (excluding
   `.axisnotes/index.db*`) and Hub `library.json` items (excluding `projectIds`) before and after
   deleting Biology in Hub: identical; Connect has a tombstone; Notes badge disappears after the
   next change poll; recreating the same project ID is rejected.
9. **Restart restore.** Quit all three; restart; projects (other than deleted), memberships,
   identity map, Hub sections/items/mappings and sessions all present.
10. **Invalid privacy files.** Seed malformed `.axisnotes/config.json`; then a valid config with
    `ai-policy.json` version 2; then an unknown legacy value. Each: AI dialogs show blocked with
    the reason; mock AI servers receive zero requests.
11. **Medical never reaches cloud.** Policy: Medical on-device-only exact model on the mock
    runner (recorded Ollama probe fixtures); School allows the mock cloud provider. Ask AI with
    both notes: the plan lists the cloud candidate as blocked; the mock cloud server receives
    zero requests; the mock runner receives the request. Repeat with the mock runner advertising
    a cloud-proxied model → blocked with unverified-execution; mock cloud still zero.
12. **Partial search.** Kill Notes mid-session: Hub search shows `notes` unavailable and `hub`
    group ready within 2.6 s; semantic mode shows unsupported for Notes.
13. **Pairing lifecycle.** First install: empty `AXIS_CONNECT_HOME`, start Notes → Connect
    starts, Notes pairs and registers. Start Hub while Connect runs → Hub pairs without a
    second `serve` (assert one `axis-connect.exe` process). Revoke AXISNotes in Hub → Notes
    shows unpaired (revoked), and its pairing record stays `revoked` with an unchanged
    `generation` for 60 s (read via `axis-connect status --json`) until the user clicks
    "Pair again"; a second Notes installation ID appears pending-approval. Quit
    all, `axis-connect restore --from <backup>`, restart → both apps re-pair automatically
    and a revocation made after the backup is still in force.
14. **Derivative provenance.** Apply an Ask AI answer over a Medical note into
    `Local/Summary.md` (local-only; notice shown). Widen `Local` to cloud with confirmation.
    Ask AI with `Summary.md` and the mock cloud model → blocked with reason provenance; mock
    cloud receives zero requests. Cap boundary (S2-D33): a fixture vault with notes
    `S001`–`S257` (each cloud-allowed); apply into `Summary.md` until it records exactly 256
    unique sources (all preserved); an apply adding `S257` shows the `ProvenanceLimit`
    message, the editor text is unchanged, and `provenance.json`/`identity.json` bytes are
    unchanged; tighten `S001` to never → Ask AI with `Summary.md` blocked (reason
    provenance); restore it and tighten `S256` → blocked again; mock cloud receives zero
    requests.
15. **Offline replacement.** Close Notes; delete `School/Cell Biology.md` and create a new file
    at the same path with unrelated content; restart Notes. Hub resolve of the recorded
    Biology ref shows `ambiguous` (not `ready`); the Notes relink dialog offers "Same note" /
    "Different note"; "Different note" leaves the old ref missing and the new file gets a new
    ID when attached.

Each scenario asserts results, saves a screenshot to `.agents/qa/S2/<n>-<name>.png`, and the
spec fails on any unmet criterion. Lead visual QA (computer use) then clicks through 1–3, 8
and 11 on the real apps, including the real Spotify/Discord/VALORANT shortcuts on this machine
