## Behaviour

- Add **Teach the AI** (`teach-the-ai`) as a built-in, note-reading conversation skill with its own icon, available through existing skill commands and picked-file actions, editable vault exports and overrides.
- The user explains; the AI is a curious beginner, asks one relevant question at a time, paraphrases or applies the explanation, and invites correction. Attached notes are reference material, not evidence the user already explained them. Avoid lecturing, blind agreement, manufactured confident errors, quizzes about file organization, or claims of model training.
- Wrap up with specific feedback on the user's demonstrated explanation, gaps, and a useful next practice step.
- Reuse provider/model selection, source restrictions, conversation history, automatic Markdown/HTML transcript saving and existing discard controls. A neutral conversation start must be the same in the request and the saved history.
- Add no dependencies or new storage, scheduling, permissions or startup activity. No merge, release or installation is authorized by this task.
