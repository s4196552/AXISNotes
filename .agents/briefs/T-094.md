# T-094: Shared dialog styles load with the app

**Goal:** the Import dialog (`src/features/import/ImportDialog.tsx`) and the Handwriting dialog
(`src/features/handwriting/HandwritingDialog.tsx`) use the Ask AI dialog's `ask-ai-header`,
`ask-ai-footer`, `ask-ai-spacer` and `ai-icon` classes, but those rules live in
`src/features/ai/ai.css`, which only loads with an AI feature (Ask AI, Fix text, AI settings,
Diagram maker) or Getting Started. On a fresh start these dialogs have no header/footer borders
or padding and the close button is not right-aligned. T-079 patched Getting Started alone by
importing `ai.css`; fix it for every dialog by moving the shared rules into the global
`src/styles/app.css`, keeping `ai.css` for AI-only styles.

**Files:** `src/styles/app.css`, `src/features/ai/ai.css`, `src/features/vault/GettingStarted.tsx`
(drop its now-redundant `ai.css` import), a regression test under `src/styles/`, `.agents/TASKS.md`.

**Acceptance:** on a fresh load (no AI feature opened), Ctrl+P → "Import from Obsidian…" and
"Handwriting to text (pen)" show header and footer borders, padding and a right-aligned close
button; Getting Started and Ask AI look as before.

**Tests:** `pnpm lint && pnpm typecheck && pnpm test`; check the four dialogs in the preview.
